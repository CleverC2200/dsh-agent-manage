# Agent note: Received mock business resources

Status: implemented

This complements [business resource ownership](../architecture/2026-10-01-business-resource-ownership.md). It adds no second resource registry, credential store or Consumer grant. UI filters and pagination belong to the current page and Session; transient local report tasks retain their original reset policy.

The regional page also retains its existing `gea-regional-plan` identifier and original `plan-regional` persona, Skill and empty MCP declaration. The current author owns its model, visible filter catalog and simulation context. Its UI intent and unfinished rhythm edits restore within the same Core Session; derived context is published after restoration. Resource selection and withdrawal use the existing Manage owner. No old conversation adapter is installed.
