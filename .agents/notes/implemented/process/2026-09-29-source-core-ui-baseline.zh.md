# Agent Note: 插件拆分的源码核心 UI 基线

Status: implemented

## 问题

隔离迁移工作区面向 DSH 0.2.0-rc.1，而原 UI 开发依赖导出旧图标名。渲染测试必须使用与目标运行时相同的 UI 库。

## 决定

UI primitives 开发依赖链接到同级核心 checkout。客户端使用其 Regular 图标导出，运行时 peer 声明选定的 DSH 版本，Vitest 对跨链接的 React 去重。核心提交由工作区另行记录；这是本地开发配置，不是 registry 发布。

## 考虑过的替代方案

**在测试中模拟缺失图标。** 这会掩盖实际运行兼容问题，无法验证目标库。

**授予运行版本豁免。** 豁免不能证明已删除导出仍然可用。客户端需要针对选定库完成适配和渲染验证。

## 影响

同级核心必须先安装并构建。现有目录与登录归属不变；本决定不替代 GEA MCP 登录归属决定。完整本地测试覆盖更新后的渲染和既有资源行为。
