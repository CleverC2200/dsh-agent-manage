# Agent Note: Manage CI scope

Status: implemented

## Problem

CI 路由回归反复复制并解析完整仓库，即使用例只验证真实策略的一条路由规则。已禁用的上游 npm 与 Pages 工作流仍留在可执行目录，而当前交付已归 GEA。

## Decision

策略路由夹具读取真实策略，发现当前测试文件名。实际脚本消费者和传递 Host 回归保留完整源码快照。断言、测试池与生产选择器保持。

上游 npm 与 Pages 工作流按原字节移入[历史目录](../../../../docs/history/upstream-workflows/README.md)。质量与兼容性工作流继续执行，当前插件交付归 GEA。

按用户明确的移除要求，CodeQL 退出源码、联合质量及兼容性工作流，一并删除每周定时扫描、适用性输出及最终门禁输入。历史扫描、告警与失败证据保留。其他安全检查沿用原有适用条件与失败处理。

本决定替代[发版版本模式](2026-09-10-release-version-modes.zh.md)中的可执行发行入口，原版本选择原因保留为历史。

## Alternatives considered

**删除慢的选择断言。** 这些断言仍保护当前策略和执行归属，缩小夹具即可保留它们。

**把旧工作流继续禁用在原位。** 它们不服务当前交付，历史目录已能保留原件。

**保留 CodeQL 并复用结果。** 这样可以在减少重复扫描时保留源码数据流分析，但不符合用户移除这项检查的决定。

## Consequences

路由夹具不再解析无关实现，完整快照仍覆盖真实导入传播。CodeQL 的源码数据流覆盖与扫描成本一并移除。业务、资源与 Session 测试、源码准入、SDK 完整性、适用平台及依赖安全门禁和发布授权沿用原有行为。[干净 CI](../../../../docs/clean-ci.md)持有当前入口。
