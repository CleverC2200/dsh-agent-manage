# Agent Note: MPS成型机约束进入实际求解

Status: implemented

由[纯隧道纠正](2026-11-13-mps-tunnel-default.zh.md)部分替代。当前业务不以成型机为前提，以下仅保留原显式配置的占用路径。

## 问题

人工成型机资源和月度批准分配进入了参考计算，却在实际计划中被过滤。配置看似齐全，成型机能力仍未限制产量。

## 决定

[计算合同](../../../../docs/design/mps-compute.md)持有联合求解约定。同一份实际产量同时占用候选隧道和按批准份额分配的成型机。连续线性求解保留公平满足率及替代隧道；成型机份额沿用业务输入。缺成型机配置时，仅隔离受影响的正补产记录；零补产和外部ODM不依赖内部成型机。

## 考虑过的方案

把两种设备当替代供应会虚增能力。先按隧道求解再裁剪成型机用量可能浪费其他路径，不能保持联合公平。推定设备能力或分配比例会制造业务数据。

## 影响

固定javascript-lp-solver作为浏览器可用的线性求解实现。Workbench负责配置、装配、缺项CSV及占用显示；Manage只做纯计算，不读取来源或写业务。已有评估与源事实保留。夹具验证设备联合瓶颈及调拨；真实设备可行性仍需真实成型机台账和月度批准份额。
