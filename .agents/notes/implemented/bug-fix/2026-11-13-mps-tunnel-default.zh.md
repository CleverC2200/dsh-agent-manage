# Agent Note: MPS纯隧道输入不要求成型机

Status: implemented

## 问题

可选配置路径被扩大为所有内部生产的前置条件。用户确认当前业务不使用成型机。给通用夹具补机台掩盖了回归，没有覆盖真实业务输入。

## 决定

[计算合同](../../../../docs/design/mps-compute.md)接受当前纯隧道业务输入。未配置成型机不新增资源要求，也不要求补机台或份额。实际求解、参考计算、页面缺项和助手资源遵循同一边界，纯单资源选项复用已有公平分配算法。

本决定部分替代[成型机求解决定](2026-11-12-mps-forming-solve.zh.md)，撤销其默认必需条件。保留原有显式配置及联合占用能力，避免纠正默认行为时丢失用户配置；保留的路径不构成当前业务使用成型机的要求。

## 考虑过的方案

补造能力或份额会掩盖错误前提并制造业务数据。删除已有显式配置会丢失用户输入。只改最后的异常标签仍会阻断生产，并留下参考计算的矛盾。

## 影响

通用夹具采用纯隧道输入，显式成型机用例单独维护。回归需验证未使用成型机时不生成相关补数要求，并保留隧道上限、库存平衡及调拨守恒。原评估和源事实保留。源码检查、开发窗口验收与正式发布分阶段记录。
