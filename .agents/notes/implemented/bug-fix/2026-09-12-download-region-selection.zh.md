# Agent Note: 已保存下载区域决定选中状态

Status: implemented

## Problem

设置卡保存手动区域后，首次后端查询仍让旧区域保持高亮。重复点击看似无效，直到重新打开卡片。

## Decision

显式保存的global/china决定选中项，仅auto使用实际线路查询结果。按钮提供aria-pressed。保存失败保持原选择并显示已有错误；后端线路规则不变。

## Alternatives considered

**每次保存后重新查询。** 旧响应或延迟响应仍可能覆盖保存值，并让已确认选择的显示依赖额外网络请求。

**关闭重开设置。** 能更新查询，但没有修复正常切换。

## Consequences

组件测试验证旧查询不变时的双向连续切换和失败重试。已检索活动笔记，未发现该选择规则的既有归属；运行时协调调度决策不变。
