# 米面冻品基地库存洞察分析

## 任务目标
对基地成品库存开展“现状—趋势—风险—原因—行动”诊断，回答库存是否合理、哪些产品将出问题、何时发生、影响多大、应该如何处理。兼顾订单保障、效期安全、仓容和库存成本，不以单纯降低库存为目标。

默认分析成品及其自有、外租仓库存；在途单列，原料、包材和在制品仅按需关联归因。输出必须有数据证据、风险优先级和可执行建议。

## 所需知识、数据
通过当前运行时已注册、获授权的工具获取，不猜测工具名、表名或字段名。

| 类别 | 所需内容 |
|---|---|
| 业务规则 | 库存指标口径、安全库存及上下限、货龄分级、大日期/临期标准、客户收货剩余保质期要求、先到期先出规则、调拨限制、节庆与促销计划；记录适用范围、生效日期和版本。 |
| 库存明细 | 基地、仓库、SKU、批次、数量、单位及换算、成本金额、生产/入库/到期日期、质量状态、冻结/预留数量，以及同口径历史快照和出入库流水。 |
| 需求与供给 | 未交订单及交期、需求预测、历史发货与退货、排产和完工计划、调入调出及在途、预计到货和质检放行时间。 |
| 约束与补充 | 有效仓容、托盘/库位占用、温区、吞吐能力、运输时效、盘点差异、质检与温控记录、仓储运输费用；跨基地及渠道库存按权限获取。 |

## 输入内容
基地/仓库范围、诊断日期、产品范围、回溯与预测周期、重点问题。优先从上下文和主数据补全。

未指定时，使用授权范围内基地、最新完整库存快照、近90天历史和未来30天预测；关键生产或调拨提前期超过30天时延长。明确披露默认参数、实际可得数据范围和快照日期，不把默认窗口当作企业风险阈值。

## 工作步骤

### 1. 确认范围与取数
先读取适用于诊断日期的企业规则，再查询全范围聚合结果，随后下钻异常基地、SKU和批次，最后补充归因证据。全量扫描采用聚合或分页，不以抽样明细代替整体结论。

### 2. 校验数据与口径
统一快照时间、产品单位、金额口径和关联粒度；检查缺失、重复、负库存、日期倒置、数据延迟及一对多关联造成的金额膨胀。核对“期初实物库存＋入库－出库±调整＝期末实物库存”。

区分实物库存、质量合格库存、客户可售库存和扣除预留后的订单可用量；识别系统字段是否已经扣除冻结或预留，交叉状态按并集处理，避免重复扣减。冻结、待检和不合格实物仍计入仓容。基地发货不等于终端动销，没有渠道数据时不得据此声称终端滞销。

### 3. 完成九维诊断
每个维度均给出“正常 / 预警 / 严重 / 无法判断”，标明依据及是否采用企业定级；没有可验证依据时标记“无法判断”。重点下钻异常，不用总体均值掩盖SKU或批次问题。

| 维度 | 必须检查的问题 |
|---|---|
| 总量与结构 | 库存数量、重量、金额及变化；按基地、仓库、品类、SKU、状态拆解增量贡献，识别集中占用和结构失衡。 |
| 动销与周转 | 出库频率、无出库时长、历史周转及未来需求覆盖；区分常规品、新品、退市品和节庆备货，避免将季节性备货直接判为积压。 |
| 供需与缺货 | 结合到期订单、预测净需求、有效供给和安全库存，定位缺货首日、缺口量及受影响订单；区分安全缓冲不足与实际无法履约。 |
| 货龄与效期 | 区分本仓库龄、生产货龄和剩余保质期；识别大日期、临期、过期及先到期先出偏离，推算客户可售窗口结束后的残余库存。 |
| 生产与库存协同 | 检查高库存仍持续生产、低库存补产不及时、排产与需求错配、完工或放行延迟；结合产能和批量约束解释原因。 |
| 跨库供需匹配 | 识别一处积压、另一处缺货；评估同SKU合格批次的调拨机会，检查调出承诺、调入真实需求、收货效期、时效、仓容和费用。 |
| 仓容与物流 | 分温区检查当前占用、未来入库高峰及出库能力，推演峰值占用和爆仓时点；不能以总仓容宽裕替代局部库区判断。 |
| 质量与账实 | 检查待检、冻结、不合格、退货、异常温控和盘点差异；区分业务风险与数据问题，缺少温控或质检数据不能认定质量正常。 |
| 资金与损失暴露 | 识别高金额、低周转库存及仓储费用负担；分别呈现风险库存成本、潜在处置损失和已确认损失，不相互替代。 |

### 4. 统一计算与前瞻推演
优先使用企业已认证指标、模型和计算工具；没有工具时只做数据充分且可复核的计算，不编造模型结果。

- **周转与覆盖：**历史周转优先用企业指标；否则可用期间平均库存成本÷同期可比口径净出库成本×期间天数，标为“出库周转口径”，不冒充财务周转天数；分母非正不计算。未来覆盖按逐日需求累计消耗可售库存推算；期内未耗尽标记“超过预测窗口”，需求为零或缺失时标记“不适用/无法计算”，不得当作库存健康。
- **供需平衡：**以质量合格且未过期的期初现货（含预留）为起点，逐日加上届时可到货并放行的供给，减去不重复计量的需求、调出及失效残量。订单与预测按企业冲减规则合并；无规则则分别测算订单情景与预测情景，不直接相加。已预留对应的订单只扣一次，未确认供给单列情景。
- **效期推演：**按客户收货最低剩余保质期、运输时效及企业缓冲倒推最后可发运日。优先满足有效订单绑定，再按先到期先出分配合规批次；一份需求不能被多个批次重复消化，到期仅扣尚未消耗的残量。缺货和积压以批次可匹配性为准，不能只看SKU总量平衡。
- **仓容与金额：**仓容占用率＝实物占用÷同温区、同单位的有效容量；未来占用按实际入出库时点推演，不以质检放行代表实物出库。风险金额按批次风险数量×相应单位成本计算；多风险重叠按实物明细去重，不能可靠去重时不合计。

### 5. 解释原因并排序
用“异常事实→变化来源→业务事件→影响”组织证据链。检查需求变化、备货节奏、排产调整、调拨执行、质量放行等因素；库存高不能直接证明预测不准，库存低不能直接证明生产不足。

每个原因标注“已验证 / 待验证”，列出证据或待补证据。风险按企业规则定级；缺少规则时，仅给出基于影响、发生时间和处置窗口的分析优先级，并说明依据，不自设行业阈值、风险概率或综合健康分。

食品安全与质量疑点优先提交质量负责人复核，其次处理即将影响履约、失去可售窗口或超过仓容的风险。数据覆盖不足时，不得给出“整体健康”的结论。

### 6. 形成行动并复算
建议必须落实到对象、数量、时间和责任角色。缺货评估调拨、补产及交期协同；积压评估减产/缓产、合规批次优先出库和需求匹配；爆仓评估调整入出库节奏或合格外仓；质量异常提交隔离、复核和处置审批建议。

调拨和促销不得仅把库存风险转移给分仓或经销商；减产不能制造关键SKU缺货。校验产能、最小批量、运输、仓容、质量和客户接收约束；资料不足的建议标记“条件建议”。

对关键动作复算实施后的缺口、过窗残量、仓容和增量费用，优先采用约束可满足且净收益更好的方案；成本或效果数据不足时不声称最优。最迟行动日由风险时点倒扣生产、运输和审批等所需时间，另列复查时间、验收指标和升级条件。

## 输出规范
按以下顺序输出，不逐项复述取数过程：

1. **结论摘要：**说明范围、快照日期和数据覆盖；用3—5条结论回答主要矛盾、紧迫风险和优先动作，区分事实与预测。
2. **九维诊断表：**维度、状态、关键指标/比较基准、证据编号；无法判断的维度写明缺口。
3. **风险—行动清单：**每项包含优先级、基地/仓库/SKU/批次、风险与发生时间、影响数量/金额、原因及验证状态、建议动作与数量、建议责任角色、最迟行动日、执行前提、预期效果和复查指标。全部严重风险必须列出；未知字段写“待确认/待测算”及原因，不填虚构数值。
4. **证据与缺口：**证据编号对应数据源或工具结果、快照/查询时间、筛选范围、指标口径和规则版本；说明缺失数据对结论的影响及最小补数需求。

风险不必凑数；“加强监控、优化库存、推动销售”不能单独作为行动建议。明确区分风险发生日、最迟行动日和复查日。

## 异常与约束
缺少关键范围且上下文无法确定时集中澄清；其他缺数仅暂停受影响判断，继续完成可验证部分。工具失败、权限不足或空结果按真实情况报告，不把无数据解释为无库存、无需求或无风险，不绕过权限。

本技能只进行分析和建议，不自动下发排产、调拨、促销、解冻或报废指令；不得建议销售过期、未放行或未经质量确认的异常产品。任何执行均需另行授权与审批。
