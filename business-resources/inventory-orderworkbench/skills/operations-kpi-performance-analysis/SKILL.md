# 指标分析流程

六指标（作废率、改单率、订单满足率、准交率、货龄占比、可发货天数/周转天数）统一使用 gea_order_kpi。该工具与本地看板共用查询、计算和口径合同；不需要先打开页面。其他订单、库存和业务知识问题继续按相关 Skill 使用已授权 Cube 和知识库，不强行转成卡片指标。

1. 点击卡片时读取 metricDetails.current、contract、queries、version 和实际周期；本期、本周分别说明，不根据周标签改写主周期。
2. 独立问数使用 gea_order_kpi(metric,start,endExclusive,base,view)，日期为含开始、不含结束。先明确范围，未指定范围时只使用已有明确上下文。view=contract 返回当前定义；view=summary 返回当前计算结果；view=details 读取已发布分页明细；按基地＋品项分组使用 view=groups，展示 groups.rows 的分子、分母、值、待判定和状态，本期、环比、同比分别使用各自时间窗。率值比较以百分点标示差值，天数比较用天；不同周期应沿同一口径比较，不得将可比较误判为不可比较。groups.total 为同范围合计，不平均百分比；准交率跨品项合计使用重新去重后的 total，不能相加各组张数。detailsQueryId 为空只表示原始明细未发布，不代表品项分组不可用。不得自行拼 SQL、回退旧 Cube 度量或用知识库公式重算这六项指标。
3. 数值、公式、周期归属、字段映射、筛选、单位、目标和状态都读取 current/contract，不在 Skill 固定另一套业务规则。回答保留 version/revision，版本不一致时刷新，不能把旧快照当当前结果。
4. 分子、分母、待判定及单位直接展示返回值；未返回的计数写未提供，不能由百分率反推或把 pending 当剔除。样本、暂算、完整集合分别按返回标记说明。率值为0不等于无订单；0分母不适用，查询失败与空集合分开。
5. 明细仅代表返回的页；没有同口径明细接口不等于底表没历史数据。未取得全量排序/分组统计时，不宣称集中于某基地、客户或SKU。知识库只补业务背景，不覆盖当前代码合同；无依据的原因、建议和责任人不补写。

## 同比查询要求

同比必须读取当前期、同长度上期和同长度去年同期；月报使用 `yearMonth`，周报使用 `yearWeek`。分维度输出时先过滤维度再判断有效性，未映射分组单独列示，不能让一条异常行使全部大区同比变成“不可计算”。

## 比较和输出

先直接给当前值及适用目标；比较期间分别调用同一版本的固定入口，不平均百分率，不混用不同范围、粒度或版本。目标、边界、时间口径及字段来自运行时合同，缺对比数据保留未知。

按需输出：指标｜周期｜范围｜分子｜分母｜值及单位｜目标/状态｜样本/待判定｜版本。解释仅引用已读证据；没有依据不添加原因、集中分布或改善动作。其他业务分析继续走相应领域 Skill、Cube 和知识库。

## 输出前核对

逐项核对表格与工具返回的分子、分母、待判定、样本和候选总数；样本总数只原样引用 current.sample.total，不能另编或从记忆转述。仅输出用户所需表格与已返回的适用范围说明，不新增跨品项张数相加值等工具未提供的计数。准交率直接引用 groups.total，不自行推导跨品项合计。

## 维度与分页

分组前读取 contract.grouping.supported、unsupported 和 labels，使用 view=groups 与 dimensions。可用维度包括基地、品项、品类、应责总监、SKU、客户、大区、省区；以当前指标声明为准，不从其他指标推断。总监和SKU会自动带基地，最多三个分组字段。salesRegion 是看板销售区域表的省区优先、大区兜底展示，不能与单独的大区或省区混用。

unsupported-dimension 表示该指标没有这个可核验归属粒度，不是整个指标未发布，也不是权限拒绝；unavailable 是查询或归属映射读取失败；可用且 pagination.totalGroups 为0才说明当前范围没有该集合；rows 为空但 totalGroups 大于0只是所请求页越界，不是全量无数据；NO_COMPLETED_DATES 表示暂无已结束日期。明细未发布时仍检查分组能力，不自换公式。未映射分组保留，不能说维度未发布。

分组每页100项，读取 pagination.totalGroups 和 hasMore；当前页不能冒充全量或全量排名。汇总引用 groups.total；应责总监可能共同归属，准交率跨组去重，不能相加。可发货天数的品项和基地有不同计划日均范围，读取 calculationScope 和 scopeNote，不能强行让它们等于同一张卡片。

货龄分组的 presentation.highestAge 与 highlights 是全量分组的最高占比提示，不是超过目标阈值，也不能把黄色最高项写成业务未达标。

分组回答使用 groups.contract 的公式、筛选和单位，以及每行 current.target/status；顶层 contract/current 属于原卡片汇总。不要拿基地的计划范围或目标覆盖品项、品类分组；仅比较同维度、同范围的结果。

自然语言“从A日至B日”“截至B日”默认包含B日，工具endExclusive必须传B日的次日；用户已明确结束不含时才原样使用。回答区分工具返回页项数与实际展示项数，摘取两行不能称工具该页只有两项。
