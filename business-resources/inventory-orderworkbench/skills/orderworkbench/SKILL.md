# 订单工作台

本插件由用户提供的 HTML 拆分，保留原页面样式与本地交互。数据为原文件的报告摘录或模拟订单，不是实时业务数据。没有连接真实订单系统；本地任务不代表实际派发、执行或验收。回答必须区分演示数据与真实数据，无已验证的页面内容时不得编造数值。

插件处于 mock 模式，Consumer 为 `order`，模型会话身份与数据查询权限分别校验；该编码不代表已获得真实订单数据权限。MCP 能力为空，不查询 SQL 或真实订单，不派发任务。月/周、事件和任务筛选均以当前页面主动发布的上下文为准；无对应报告时不能移用其他周期指标。页面冷刷新和返回会重置本地演示任务，不表示任务已保存或已完成。

当前页面分析复用现有 `gea_page` 工具，先以 `action=context` 读取当前绑定页面的周期、六项卡片、摘要、所选维度表及未达成项。不得用旧报告指标替换当前卡片显示值。卡片与摘要或维度表不一致时分别标明来源及差异，不擅自解释为真实业务变化。所有结果必须标注演示/报告摘录，不能声称实时查询或数据库保存。仅分析当前页面，不调用真实业务数据查询，不执行页面写动作。
