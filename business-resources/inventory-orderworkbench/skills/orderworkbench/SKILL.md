# 订单工作台

本插件由用户提供的 HTML 拆分，保留原页面样式与本地交互。数据为原文件的报告摘录或模拟订单，不是实时业务数据。没有连接真实订单系统；本地任务不代表实际派发、执行或验收。回答必须区分演示数据与真实数据，无已验证的页面内容时不得编造数值。

插件处于 mock 模式，consumerCode 仅为本地标识，不代表真实业务授权。MCP 能力为空，不查询 SQL 或真实订单，不派发任务。月/周、事件和任务筛选均以当前页面主动发布的上下文为准；无对应报告时不能移用其他周期指标。页面冷刷新和返回会重置本地演示任务，不表示任务已保存或已完成。
