# 历史业务场景参考

本文件综合 2026 年 8 月截至 8.16、8.23、8.30 的三份计划运营报告。它用于提醒分析者现实中出现过哪些分支，不代表当前期间事实，也不固化报告中的责任人、阈值、措施或结论。

## 反复出现的场景

| 场景 | 可提出的候选假设 | 可核查的证据示例 |
|---|---|---|
| 高库存与低满足率并存 | 热销与滞销 SKU、基地、渠道、客户专供或效期结构错配 | 订单分配时点的仓库×SKU×批次可用/占用及订单关系 |
| 冷鲜肉水饺质量问题、封存、降机速 | 质量事件同时造成库存不可用和生产少产 | 检验批、封存量、降速时段、生产单和缺口订单 |
| 规划双班但人员不足 | 班次能力未兑现 | 计划/实到人数、岗位技能、班次产量和生产单 |
| 新旧配方切换、效率下降 | 工艺版本导致单位时间产能下降 | 配方版本、生效时间、标准/实际速度、合格率和影响 SKU |
| 定制品与常规品资源冲突 | 共享设备、产线或人员的优先级挤出其他 SKU | 资源占用计划、优先级批准、被挤出排产与损失量 |
| ODM 月产能低于报单 | 外协锁定能力本身不足 | 月度锁定/承诺、日排产、实产、交付和转可用 |
| 备选代工厂尚未稳定量产 | 计划中的增量供给未实际兑现 | 验厂、试产、量产爬坡、质量和每日交付 |
| 看见缺货后才调拨 | 调拨触发滞后 | 安全库存预警、建议生成、审批、出库及订单需要时间 |
| 调出基地自身也缺货 | 规划外调拨不可兑现或引发跨基地冲突 | 两端库存/需求、计划内外标识、优先级和责任边界 |
| 外协品等待卸货、入账变慢 | 供给已到场但未转可用 | 到场、卸货、收货、质检、上架时间与排队原因 |
| 单日开单量超过仓储峰值 | 日/小时峰值造成仓内积压 | 订单下发、开单、波次、拣装、出库和资源能力时序 |
| 客户提前占用安全库存但拉货慢 | 库存被占用，其他需求不可满足 | 占用/释放、客户提货计划、实际提货及重分配记录 |
| 系统交期约束销售选择 | 承诺时间开始基于能力计算 | 交期规则版本、SKU交付用时构成、人工改期和实际兑现 |

## 报告信息如何定级

按[证据契约](evidence-and-output-contract.md)评估实际支持程度，不根据场景名称或原报告措辞直接定级。历史汇总先核对范围；“已完成”等管理状态仅代表原报告时点记录，不等于当前执行状态或问题已解决。表中记录是取证示例，可由同等有效证据替代，不要求逐项收集。

历史报告中提到的冷鲜肉水饺、预制食材、火锅料、盒马定制品等对象，只能在当前数据再次命中时进入当前分析，不能默认长期成立。
