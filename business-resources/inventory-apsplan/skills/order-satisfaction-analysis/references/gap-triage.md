# 空值分诊

| 症状 | 顺序检查 | 停止条件 |
|---|---|---|
| 全国销售有值、组织无值 | 同月份/source_flag→成员源值/别名→组织分布/record_count→空组织/编码→完整组织×SKU及映射 | 原始页无匹配标empty_scope，度量NULL标source_null；一个查询空不等于企业无数据 |
| 品类空 | 原生值→本期SKU唯一映射→未映射/多映射数量→合计守恒 | 可映射部分继续，未映射单列，不按比例填补 |
| 准确率空/负 | 发布值→双版本分母→同销售源订单/发货→非线性计算所需源粒度/充分量 | 缺基础量保留NULL；负值可能合法，保留解释，不以非负为验收 |
| 分类量远大于总缺货 | 期间/订单池/单位/版本→源定义是否混计划池→同源细粒度复核条件 | 保留classificationAudit原值；分类NULL，总缺货独立定位，不改分母凑平 |
| 生产只有标签 | inspect可用实体字段→重点对象细粒度分页→日×SKU×原因→日×原因 | 说明可解释的工序机制及不能定位的实体，日期完整不等于实体完整 |
| 调拨/OE/OD空 | 可用模型/权限/定义→当期业务覆盖→计划兑现配对 | unsupported/empty_scope/query_failed分开，未取得不等于没发生 |
| 库存有总量无解释 | SKU仓库匹配→需要时点→占用/效期/质量 | 当前快照不能证明月内有货未发 |
| 调用失败 | 读错误，缩小单点或按限制分批，最多两次有针对性修正 | 保存错误标query_failed，继续独立分支，不循环同样请求 |

停止时写：证据文件、已完成检查、受限结论、补何种证据后恢复。没有凭据标pending；无权限不称源无记录。数据质量不是业务缺货原因量。
