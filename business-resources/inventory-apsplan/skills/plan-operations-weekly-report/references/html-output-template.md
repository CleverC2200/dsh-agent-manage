# HTML 输出模板使用规则

## 模板定位

HTML 周报必须以 [../assets/weekly-report-html-template.html](../assets/weekly-report-html-template.html) 为样式和交互母版。生成报告时复制模板到交付目录，再填充本期内容；不要直接修改 Skill 内的母版，也不要另建一套不一致的页面结构。

模板负责固定以下内容：

- 与工作台 V0.3 一致的品牌红、灰阶、状态色、字体层级和数据范围标签；
- 标题卡下方、`SECTION 01` 上方的横向五段式目录与滚动定位；
- 六项 KPI 卡片、状态颜色和变化信息层级；
- 全国摘要、基地、应责总监、品项、改善措施和下周重点的版式；
- 风险筛选、指标筛选、响应式布局及打印样式。

## 数据替换

模板内的日期、数值、总监代称、基地、品项、原因、行动和 `DEMO-V1` 都是演示内容，不是默认业务数据。每次生成正式周报必须：

1. 替换报告标题、月度累计、本周、数据截止、时区和版本；
2. 用本期六项指标替换全部 KPI 数值、阈值、状态和比较值；
3. 按实际成员重建基地、应责总监和品项的月度及周度表格，不保留演示成员凑数；
4. 用本期证据生成原因卡片、改善台账、长期机制和下周重点；
5. 保证卡片、表格和正文引用的同一指标数值完全一致；
6. 缺失值写 `—` 并说明原因，不用演示值、零值或估算值填空。

如果整份报告都来自已核验的正式数据，删除黄色“页面演示数据”提示并改为实际数据状态说明。如果仍混有样例或待补数据，必须保留醒目标识，并在对应字段注明范围，不能把混合数据包装成正式报告。

## 状态与交互

- 只有阈值、方向、单位和版本均已确认时才使用 `healthy`、`warning`、`severe` 判级。
- 口径待确认或无法判级时，用文字状态替代正式红黄绿灯，不凭常识补阈值。
- 风险对象行使用 `data-status-row="warning"` 或 `data-status-row="severe"`，确保“仅看风险”按钮可正确筛选。
- KPI 卡片使用 `data-status` 与同名状态类，状态文字必须与颜色一致。
- 保留本地单文件交付，不引用外网脚本、字体、图片或样式资源。
- 保留打印按钮、目录定位、响应式布局和打印 CSS；仅在用户明确要求时调整视觉主题。

## 视觉规范约束

HTML 模板遵循工作台既有视觉规范，生成时不得另建深蓝、亮蓝或近似红主题，也不要覆盖母版中的 Token：

- 字体栈固定为 `"Microsoft YaHei UI", "PingFang SC", "Noto Sans CJK SC", Arial, sans-serif`；正文 `12px`，模块标题 `18px`，指标主值 `23px`，表头 `9px`，表格正文 `10px`。
- 页面、内容面、文字和边框分别使用 `#f7f8fa`、`#ffffff`、`#20232a / #555d68 / #858c96`、`#e3e6ea`；品牌色使用 `#df1732`，Hover 使用 `#fffafb / #efabb4 / #df1732`。
- 风险状态必须使用统一语义色：健康/达标 `#168e58 / #eaf7ef`，预警 `#956900 / #fff4d9`，严重/未达 `#c8112a / #ffe9ec`。状态文字与颜色必须同时出现，通用 Hover 不得覆盖状态色。
- 面板和卡片圆角 `10px`，按钮 `8px`，状态胶囊 `999px`；普通卡片阴影 `0 2px 10px #20273308`。普通面板、KPI 和摘要卡不得增加粗品牌色或状态色顶边/侧边。
- 指标筛选使用文字加 `2px` 品牌色下划线的紧凑 Tab，不使用整块深色 Selected；按钮高度 `36px`，所有按钮和目录链接保留 `focus-visible`。
- 报告目录固定放在标题卡之后、第一章节之前，使用横向 Tab；桌面端尽量完整展示，窄屏横向滚动，不恢复为左侧栏或直接隐藏。
- 表头高度 `38px`、数据行约 `44px`；宽表保留横向滚动，不隐藏关键列。`≤900px` 转为单列主体，`≤520px` 的卡片和交叉观察项使用单列。

## 交付前验收

- 一级章节必须为五段，编号连续；基地、应责总监和品项均包含月度、周度及重点分析；
- 六项 KPI 与全国汇总、文字摘要和相关维度表相互一致；
- 页面中不存在未解释的演示姓名、演示日期、`DEMO-V1` 或演示结论；
- 未达成项有证据状态、数据缺口或核查动作，不能只给无依据原因；
- 行动台账包含对应问题、状态、责任角色、时间和验收证据；
- HTML、CSS 和 JavaScript 语法有效，页面可本地打开，筛选和打印按钮可用；
- 文件名包含报告周期，避免覆盖不同周次的报告。
