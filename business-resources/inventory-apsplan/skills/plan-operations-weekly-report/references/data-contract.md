# 数据与计算契约

## 1. 时间窗口

每份报告至少定义：

- `month_to_date`：本月1日至数据截止；
- `current_week`：本周开始日至结束日；
- `previous_period`：同口径上期；
- `previous_week`：上一完整可比周；
- `year_ago_period`：去年同截止进度；
- `year_ago_week`：去年可比周；
- `data_cutoff`：数据覆盖截止时刻；
- `timezone`：默认 `Asia/Shanghai`，以实际配置为准。

月度未结束时，环比与同比应使用同截止进度。自然日、工作日、财务入账日或业务日不一致时，以指标定义为准并披露。

## 2. 核心指标输入

不在 Skill 内固化公式。每项指标从生效指标定义取得：

| 属性 | 要求 |
|---|---|
| 标准名称 | 避免同义词混用 |
| 业务定义 | 指标回答什么问题 |
| 方向 | 越高越好、越低越好或区间最优 |
| 目标/挑战值 | 包含边界和适用版本 |
| 单位 | `%`、天、件、单等 |
| 分子/分母 | 比率必须取得基础量 |
| 时间口径 | 期间累计或时点快照 |
| 排除规则 | 作废、未到期、非当季、无效记录等 |
| 数据截止 | T+0、T+1或财务入账截止 |

默认报告指标为作废率、改单率、订单满足率、准交率、60天以上货龄占比、可发货天数。指标新增、删除或改名时，报告总览和相关维度表同步调整。

## 3. 维度输入

| 维度 | 最小要求 |
|---|---|
| 全国 | 同一范围、同一版本的总体基础量 |
| 基地 | 实际业务基地；组合基地和全国汇总不得混入明细求和 |
| 应责总监 | 人员、责任范围、生效时间和组织版本 |
| 品项 | 标准品项层级及历史映射 |

组织和品项映射必须按报告期间生效版本处理。名称变更或责任调整需说明，不能使用当前映射改写历史同比。

## 4. 计算规则

- 比率指标：`SUM(同口径分子)/SUM(同口径分母)`，不平均行级比率。
- 月环比：`本期值-上期可比值`；百分率使用百分点 `pct`。
- 月同比：`本期值-去年同期可比值`。
- 周环比：`本周值-上周值`。
- 周同比：`本周值-去年同周值`。
- 天数和数量：使用原单位差，不写成 `pct`。
- 快照指标：选择定义要求的快照日或采样规则，不跨日求和。
- 分母为零：结果为 `—` 并说明“分母为零”，不得输出0或无穷大。
- 空值、无记录、零值、查询失败和无权限分别表达。

## 5. 判级规则

按指标方向应用当前生效阈值：

- 越高越好：数值越大状态越优；
- 越低越好：数值越小状态越优；
- 区间最优：区间内健康，区间外分别按规则判定；
- 无阈值：只展示数值和趋势，不强制红黄绿。

阈值区间重叠、边界遗漏、单位不一致或与指标方向冲突时，状态为“口径待确认”。不要凭常识修复阈值。

## 6. 取数最小集合

每个指标和维度组合至少保留：

- 当前值或可重算的基础量；
- 当前期间、截止和版本；
- 比较值及其期间、截止和版本；
- 维度成员和稳定标识；
- 查询范围、分页完整性和数据覆盖说明。

原因分析还需要：异常对象、关联业务实体、事件名称、事件时间、影响量或估算方法、业务责任角色和原始记录位置。

改善台账至少需要：动作ID、对应问题、动作内容、责任角色、计划时间、当前状态、完成证据、验收指标和观察窗口。

## 7. 质量勾稽

- 全国总体与基地汇总使用同一基础量时应可解释差异；
- 应责总监汇总只在责任范围互斥且完整时才与全国勾稽；
- 品项汇总须排除重复层级和组合品项；
- 月度卡片、月度明细表和正文引用必须一致；
- 周度卡片、周度明细表和正文引用必须一致；
- 同一未满足量在基地、总监和品项维度只是不同切面，不得跨表相加。
