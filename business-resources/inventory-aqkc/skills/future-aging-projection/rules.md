# 未来 N 日预计超龄 — 规则与阈值

## 1. 定义

未来 N 日预计超龄：当前尚未超过 60 天货龄，但在未来 N 日窗口结束时预计会超过 60 天的批次库存。它是**新增风险预警**，不是当前 60 天以上库存总量，也不是既定事实。

## 2. 计算逻辑（批次级，先进先出）

```text
窗口结束货龄 = 当前货龄 + N
窗口内预计消耗 = 预计出库/订单量（优先）；无则 近 30 日日均动销 × N
扣减后剩余数量 = 批次数量 − 窗口内预计消耗（按先进先出，先扣最早批次）
若 扣减后剩余 > 0 且 窗口结束货龄 ≥ 60 → 计入未来 N 日预计超龄
```

口径要求：

| 项目 | 要求 |
|---|---|
| 粒度 | 基地 + SKU + 批次 |
| 扣减顺序 | 先进先出 |
| 动销取值 | 优先近 30 日日均动销，或业务确认的日均动销 |
| 生产入库 | **不扣减**未来生产入库 |
| 当前 60+ | **排除**，不重复计入 |
| 无动销数据 | 按未扣减测算，并标注「本次未扣减预计动销」 |

## 3. 参考区间（粗筛用，非精确判定）

| 窗口 | 当前货龄参考区间 | 说明 |
|---|---|---|
| 未来 7 日 | 53 - 60 天 | 窗口结束时跨过 60 天且预计仍未消化 |
| 未来 14 日 | 46 - 60 天 | 同上，窗口为 14 日 |

注意：有动销数据时必须按第 2 节逐批扣减测算，参考区间只用于快速定位候选批次。

## 4. 汇总结论

- 按基地 / 品类 / SKU / 批次汇总数量与占比
- 排序：预计超龄日期升序 → 数量降序
- 必须同时给出：当前 60 天以上数量（存量）与未来 N 日预计超龄数量（新增），并说明两者不可相加

## 5. 输出要求

必须在输出中出现：窗口（7 / 14 日）、是否扣减预计动销、是否排除当前 60+、批次与动销数据时间、不可判断项。结果标注为预警，不写成既定事实。

## 6. 数据完整性校验

必备字段：SKU 编码、基地、批次数量、入库日期、数据截止时间。缺入库日期 → 标「货龄未知」，不参与推演。

可选项缺失时：无动销 → 未扣减测算并标注；无预计出库 → 用日均动销替代；无批次 → 只做 SKU 级提示并说明精度受限。

## 7. 禁止事项

- 与当前 60+ 相加
- 扣减未来生产入库
- 输出 30 日窗口结论
- 把预警说成事实、自动创建专项或事件、定责

## 8. P2 承接

30 日窗口、推演结果转待办 / 事件、大日期专项台账与锁定。
