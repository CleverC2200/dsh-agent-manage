# 固定报告模板 Skill

## 触发场景

- 「生成今日库存运营日报」「出一份日报」
- 「生成大日期报告」「大日期专项报告」
- 看板或消息中的报告入口跳转

命中即调模板；模板段落不得删改；缺必需数据时提示缺失，不生成伪完整报告。

## 模板一：库存运营分析报告（每日）

```text
# {对象名称}库存运营分析报告（{报告日期}）

## 一、今日结论
## 二、核心指标
    当前库存 / 目标库存 / 库存差额 / 周转天数 / 平均货龄 / 大日期库存 / 卡点指标
## 三、货龄结构
    0-30 / 31-40 / 41-60 / 60 天以上（数量与占比）；未来 7 日 / 14 日预计超龄（单独列出，不与当前 60+ 相加）
## 四、重点风险
    高于目标、低于目标、大日期、动销偏慢对象
## 五、原因线索（标注证据状态）
## 六、建议动作（标注待人工确认）
## 七、需重点跟进清单
## 八、数据说明
    数据时间、目标版本（逐基地）、缺失字段、不可判断项
```

## 模板二：大日期报告

```text
# {对象名称}大日期报告（{报告日期}）

## 一、专项结论
## 二、范围与判定口径（当前货龄 60 天以上，按批次；未来 7 / 14 日预计超龄单独列出，不与本表相加）
## 三、大日期批次明细（基地 / 仓库 / SKU / 批次 / 数量 / 货龄）
## 四、重点对象排序（风险等级 → 货龄 → 库存量）
## 五、原因线索（标注证据状态）
## 六、消化方向建议（待业务确认）
## 七、数据说明
```

## 输出约束

- 必须带：分析范围、数据时间、目标版本、缺失说明
- 每段只写结论与关键数字，明细放表格
- 风险等级统一：高风险（红）/ 关注（橙）/ 正常（绿）
- 输出结构、语言、数字与呈现统一遵守 `inventory-policy` Skill 的 `rules/output-guide.md`（报告类按本文件模板段落，不得删改）
- 取数与知识查询遵守 `inventory-policy` Skill 的 `rules/data-access-contract.md`（只读、权限过滤、上卷铁律）
- 不使用金额口径；不使用动销率
- 周转天数按回顾口径（÷ 近 30 日日均发货量）；计划维度的可发货天数单独标注
- 推演类数字必须标注窗口与扣减口径，不与当前 60+ 相加
- 补货类内容只给 SKU 与建议补货量，不给到货时间
- 建议统一标注【待人工确认】，不写责任人与升级路径（P2）
- 缺必需数据时在对应段落写「数据不足，需人工确认」，不省略该段
