# 基地库存数据边界规范

所有库存分析必须遵守的数据边界和数据质量要求。

## 一、必须标注的信息

| 信息项 | 说明 | 示例 |
|---|---|---|
| 分析范围 | 基地、品类、SKU、仓库 | 郑州基地 / 调理肉制品 / 全 SKU |
| 数据截止时间 | 库存、订单、动销、计划各自的时间点 | 库存 2026-10-10 08:00；动销截至 2026-10-09 |
| 目标版本 | 版本名称 + 生效日期（按基地维度） | 当月纠偏版（生效 2026-10-15） |
| 数据完整性 | 是否有缺失，缺失在哪 | 基本完整 / 2 个 SKU 目标缺失 |
| 不可判断项 | 哪些结论因数据不足无法下 | 奶黄包 360g 偏差率无法计算 |

## 二、目标版本取值规则

| 日期区间 | 优先版本 | 次选版本 |
|---|---|---|
| 每月 1–20 日 | 当月纠偏版 | 当月月初版 |
| 每月 21 日–月末 | 次月月初版 | 次月滚动版 |

- 平台计划节奏：15–20 日纠偏当前月计划；20–25 日出 T+1 月初计划与 T+2 滚动计划；各基地完成时间不同步。
- **按 基地 + 月份 整体选版，不按 SKU 混用版本**；先按 组织（基地）+ 月份 + 版本 + SKU 去重取唯一版本，再汇总。
- Agent 不判断「是否最新版本」，只按日期区间与优先级取数并展示所选版本。
- 同一分析内各基地版本不同时，逐一标注；目标缺失的基地单列，不参与排名。
- 日均计划量为 0 的行：**分子（库存 / 目标库存）照常计入，分母不加**；汇总分母为 0 才标「无数据」。

## 三、数据缺失处理原则

### 3.1 缺数按 0，分母不强算
- 明细缺数：按 0 显示，不留空白；汇总按列求和，有值加、0 或无数不加
- 比率 / 天数：分母为 0 或无数时不计算，标「无数据」；不因个别行缺数把整行或整个品类置空
- 目标库存缺失：**库存有值即参与**，差额按「库存 − 0」计入，不算偏差率（分母 0），归入「目标缺失」单列清单
- 当前库存缺失：**目标有值即参与**，差额按「0 − 目标」计入，标注「库存记录缺失」
- 库存与目标都缺失的行：不参与差额计算，单列「数据缺失」清单
- 订单 / 占用 / 可用量缺失：按 0 参与缺口计算，缺口 = 需求量；订单量照常汇总
- 动销数据缺失：不判断滞库风险，只输出库存与货龄事实
- **结构类指标的排除要标个数**：库存结构符合率只纳入「库存 ≠ 0 且 日均发货 ≠ 0」的单品；真实为 0 被排除、与缺失按 0 后被排除，都要在数据说明里写「纳入 N 个 / 排除 M 个」，不静默丢弃
- **SKU 未命中（编码与名称都查不到记录）**：说明「当前数据未覆盖该 SKU」，给核对项（编码是否正确、是否属出口 / 定制、是否在监控范围），**不得直接回答「无库存 / 无数据」**；若属出口 / 定制，按订单触发口径说明不设目标库存

### 3.2 标准表述
- 「XX SKU 因目标库存缺失，不参与偏差率计算」
- 「因动销数据未接入，本次不判断滞库风险，以下仅输出库存差额与货龄」
- 「当前数据不足以判断原因，需补充 XX 数据」
- 「XX 系统数据延迟约 30 分钟，凌晨订单可能未完全计入」

## 四、目标库存特殊规则

- **目标为 0**：差额按「库存 − 0」计入，不算偏差率，只输出「目标库存为 0」的事实；若实际有库存，标注「有库存但目标为 0，需确认目标是否正确」，不判高低。
- **目标缺失**：差额按「库存 − 0」计入汇总，偏差率不计算（分母 0）；单列「目标缺失」清单，不参与偏差率排名与风险分层。
- **基地级全量缺失**：单个基地全部 SKU 的库存与目标都缺失（或全部无目标且有库存）时，判**数据异常**（目标版本未发布或数据未到），不输出该基地的差额与偏差率结论，标「数据异常，待核查目标版本」，不参与排名；其余基地照常输出。
- **版本不同步**：按第二节规则取数，并说明各基地所用版本。

## 五、数据时间不一致处理

1. 分别标注各数据源时间；
2. 说明时间差异可能带来的影响；
3. 以最接近分析时点的数据为主；
4. 建议用户在数据时间一致时再次确认。

## 六、数据质量分级

| 等级 | 含义 | 输出要求 |
|---|---|---|
| 完整 | 数据齐全，时效正常 | 可正常输出全部结论 |
| 基本完整 | 局部缺失，不影响整体判断 | 输出结论 + 标注缺失项与影响范围 |
| 不足 | 缺失较多，影响核心判断 | 只输出可判断部分并说明限制 |
| 不可用 | 关键数据完全缺失 | 说明不可用，无法分析 |

## 七、标准数据边界模板

```
数据边界：
- 分析范围：XX 基地 / XX 品类 / 共 XX 个 SKU
- 库存数据：2026-10-10 08:00（实时）
- 订单数据：2026-10-10 07:30（约 30 分钟延迟）
- 目标版本：当月纠偏版（生效 2026-10-15）
- 数据完整性：基本完整（2 个 SKU 目标缺失）
- 不可判断项：奶黄包 360g 偏差率、XX 品类滞库风险
```
