# 基地库存数据边界规范

所有库存分析必须遵守的数据边界和数据质量要求。

## 一、必须标注的信息

| 信息项 | 说明 | 示例 |
|---|---|---|
| 分析范围 | 基地、品类、SKU、仓库 | 郑州基地 / 调理肉制品 / 全 SKU |
| 数据截止时间 | 库存、订单、动销、计划各自的时间点 | 库存 2026-10-10 08:00；动销截至 2026-10-09 |
| 目标版本 | 版本名称 + 生效日期（按基地维度） | 当月纠偏版（生效 2026-10-15） |
| 数据完整性 | 是否有缺失，缺失在哪 | 基本完整 / 2 个 SKU 目标缺失 |
| 不可判断项 | 哪些结论因数据不足无法下 | 奶黄包 360g 偏差率无法计算 |

## 二、目标版本取值规则

| 日期区间 | 优先版本 | 次选版本 |
|---|---|---|
| 每月 1–20 日 | 当月纠偏版 | 当月月初版 |
| 每月 21 日–月末 | 次月月初版 | 次月滚动版 / 纠偏版 |

- 平台计划节奏：15–20 日纠偏当前月计划；20–25 日出 T+1 月初计划与 T+2 滚动计划；各基地完成时间不同步。
- Agent 不判断「是否最新版本」，只按日期区间与优先级取数并展示所选版本。
- 同一分析内各基地版本不同时，逐一标注；目标缺失的基地单列，不参与排名。

## 三、数据缺失处理原则

### 3.1 不填 0，不强算
- 目标库存缺失：不算偏差率，归入「目标缺失」，单列清单
- 订单 / 占用量缺失：不判断当前订单缺口，只说明数据不足
- 动销数据缺失：不判断滞库风险，只输出库存与货龄事实
- 计划量缺失或为 0：不输出周转天数与目标天数结论

### 3.2 标准表述
- 「XX SKU 因目标库存缺失，不参与偏差率计算」
- 「因动销数据未接入，本次不判断滞库风险，以下仅输出库存差额与货龄」
- 「当前数据不足以判断原因，需补充 XX 数据」
- 「XX 系统数据延迟约 30 分钟，凌晨订单可能未完全计入」

## 四、目标库存特殊规则

- **目标为 0**：不算偏差率，只输出「目标库存为 0」的事实；若实际有库存，标注「有库存但目标为 0，需确认目标是否正确」，不判高低。
- **目标缺失**：单列「目标缺失」清单，不参与偏差排名、风险分层与汇总偏差率。
- **版本不同步**：按第二节规则取数，并说明各基地所用版本。

## 五、数据时间不一致处理

1. 分别标注各数据源时间；
2. 说明时间差异可能带来的影响；
3. 以最接近分析时点的数据为主；
4. 建议用户在数据时间一致时再次确认。

## 六、数据质量分级

| 等级 | 含义 | 输出要求 |
|---|---|---|
| 完整 | 数据齐全，时效正常 | 可正常输出全部结论 |
| 基本完整 | 局部缺失，不影响整体判断 | 输出结论 + 标注缺失项与影响范围 |
| 不足 | 缺失较多，影响核心判断 | 只输出可判断部分并说明限制 |
| 不可用 | 关键数据完全缺失 | 说明不可用，无法分析 |

## 七、标准数据边界模板

```
数据边界：
- 分析范围：XX 基地 / XX 品类 / 共 XX 个 SKU
- 库存数据：2026-10-10 08:00（实时）
- 订单数据：2026-10-10 07:30（约 30 分钟延迟）
- 目标版本：当月纠偏版（生效 2026-10-15）
- 数据完整性：基本完整（2 个 SKU 目标缺失）
- 不可判断项：奶黄包 360g 偏差率、XX 品类滞库风险
```
