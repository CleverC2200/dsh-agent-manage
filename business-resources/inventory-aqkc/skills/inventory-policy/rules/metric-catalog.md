# 基地库存指标口径与问数路由（指标能力矩阵）

版本：V1.4-261023（新增库存结构符合率指标，口径按 2026-10-23 确认落地）
数据来源：产销协同数据指标表。基地库存口径以**谷圣磊（43 条）**为主，缺失项按**刘壮壮 → 李琳 → 张光照**优先级补充。本文件是 Agent 口径的唯一来源，不再引用固化规则包；业务确认口径以本文件为准。
P1 边界：做问数、口径解释、看板分析、固定报告、未来 7/14 日预计超龄推演、补货 SKU 与补货量测算；待办 / 事件 / 反馈 / 责任 / 升级 / 到货时间承诺属 P2。
本 Agent 只回答**基地口径**；分仓口径见第十一节，遇到分仓问题说明归属。

## 一、库存规模类

| 指标            | 定义与公式                                               | 支持维度                     | 时间  |
| ------------- | --------------------------------------------------- | ------------------------ | --- |
| 当前库存（同义词：库存量） | Σ明细库存数量；可加和量，逐级 SUM                                 | 全国/基地/分仓/品类/物料组/SKU/生产日期 | 日快照 |
| 可用库存          | 当前库存 − 占用量（**备单完成订单占用 + 未备单完成订单占用**）− 锁定 / 冻结 / 质检等不可用库存；Σ明细可用库存数量       | 同上                       | 日快照 |
| 占用库存          | 已被订单（**含备单完成与未备单完成两部分**）、调拨、质量、盘点等业务动作占用的库存；Σ明细占用库存数量                   | 同上                       | 日快照 |
| 目标库存          | 目标库存模型输出；按 基地+月份+版本+SKU 取值，禁止用过程字段替代最终目标            | 全国/基地/品类/物料组/SKU         | 月（版本） |
| 库存差额          | 当前库存 − 目标库存；汇总直接相减、允许正负抵消；**库存与目标任一有值即参与，缺的按 0**；两者都缺的行不参与、单列 | 同上                       | 日快照 |
| 超储库存          | 高于目标的正向差额部分（顶部指标与超储风险来源）                            | 同上                       | 日快照 |

**订单触发 / 出口 / 定制产品口径**：产品描述以 C 开头（如 CY）、或明确出口 / 外销 / 客户定制的 SKU，按订单生产，**不设目标库存**（安全库存 = 0、目标库存 = 0 或订单单列）。这类 SKU 只回答当前库存、可用库存、订单与在途；**不给目标库存、库存差额、偏差率、建议补货量**，并说明「按订单触发，不设目标库存」。在目标表查不到属正常，**不等于库存无数据**。

目标库存同义词（业务口语）：目标库存量、库存目标、库存水位目标、库存基准、库存定额、目标存量、库存规划量、理想库存水平、**安全库存**（业务口语中安全库存即目标库存，直接按目标库存输出值回答，不反问；技术口径的目标库存 = 周转库存 + 安全库存，仅在用户明确要求拆分时使用）。

## 二、周转与效率类

| 指标 | 定义与公式 | 说明 |
|---|---|---|
| 周转天数（= 回顾周转天数，看板与问数统一口径） | 当前库存 ÷ 近 30 日日均发货量；无发货时标「不可计算 / 待复核」 | **唯一主口径**，看板与问数一致；看历史消化速度，分母是实际发货 |
| 可发货天数（刘壮壮口径） | 当前可用库存 ÷ 基地月日均计划量 | 计划维度的补充口径，不替代周转天数；指标表曾用名「展望周转天数」，属定义重复，该名称已作废 |
| 目标周转天数（原「目标天数」） | 最终目标库存 ÷ 基地月日均计划量；分母为 0 或无数时不计算，标「无数据」 | 基地月日均计划量 = 基地月度需求计划 ÷ 当月自然天数（已含调拨 × 0.5，不再重复加）；版本按 基地+月份 整体选版，不按 SKU 混用 |
| 周转天数差额 | **只在两侧同为计划口径时输出**（用户明确要看展望周转天数）：当前库存 ÷ 计划日均 − 目标库存 ÷ 计划日均；默认回顾口径下不给差额 | 回顾口径（÷ 近 30 日发货）与目标天数分母不同，不得直接相减 |


汇总规则（天数类与比率类）：

1. 一律「汇总分子 ÷ 汇总分母」，禁止对下级比率或天数取简单平均。
2. 基地目标周转天数 = Σ(基地目标库存) ÷ Σ(基地月日均计划量)；**分子含全部有值行（含日均缺失的行），分母只加有值的行**；分母为 0 或无数才标「无数据」。
3. 先按 组织（基地）+ 月份 + 版本 + SKU 去重取唯一版本，再汇总；版本按 基地 + 月份 整体选取，**不得按 SKU 混用版本**。

## 三、货龄类

| 指标 | 定义与公式 | 阈值（业务默认） |
|---|---|---|
| 平均货龄天数 | Σ(批次库存数量 × 批次货龄) ÷ Σ批次库存数量；批次货龄 = 快照日期 − 生产/入库日期；无货龄的批次不计入分子分母，但必须标注未覆盖数量 | **只输出数值，不设阈值**（业务暂无平均货龄阈值规则） |
| 货龄分段 | 0-30 / 31-40 / 41-60 / 61 天以上（超过 60 天）（基地） | 与看板一致 |
| 超龄（大日期）库存量 | Σ(货龄 > 阈值的批次库存数量)，**不含阈值当天（阈值 60 → ≥61 天）** | **基地 ≥61 天（即超过 60 天，不含第 60 天）；分仓 ≥91 天** |
| 超龄 SKU 个数 | COUNT(DISTINCT SKU WHERE 货龄 > 阈值，即 ≥61 天)；**全国按 SKU 去重，严禁各基地相加** | 越低越好 |
| 大日期库存占比 | 大日期库存量 ÷ 当前库存量 × 100% | 阈值待业务确认 |
| 大日期（定义） | 基地货龄超过 60 天（≥61 天，不含第 60 天）；**不涉及保质期 / 效期**（公司产品保质期统一 12 个月） | — |
| 未来 7 日 / 14 日预计超龄 | 批次级推演：当前货龄 ≤ 60 天，按先进先出扣减窗口内预计动销后，窗口结束时货龄 ≥ 61 天的批次库存 | 排除当前大日期库存（≥61 天）；不扣减未来生产入库 |

## 四、订单类

| 指标 | 定义与公式 | 说明 |
|---|---|---|
| 备单量 | SUM(未备单完成订单量)，不含已备单完成未发货 | 原子/派生 |
| 当前订单量 | 备单量 + 已备单未发货占用量；剔除已作废 / 已取消订单 | 看板「当前订单」 |
| 当前订单缺口（看板「缺货量」） | ①**订单层**（只取未备单完成订单）：还需满足量 = `max(需求量 − 该订单自身占用量, 0)`；②**基地 + SKU 层**：缺口 = `max(Σ 还需满足量 − 可用库存, 0)`；③**基地层**：缺口 = Σ 各 SKU 缺口，不二次截零 | **可用库存只在基地+SKU 层减一次**，不能摊到订单层；占用量与需求量同源同状态；存在超额占用时不能再用「需求 + 备单完成占用 + 锁定 − 库存」的等价式 |
| 事后订单满足率 | 1 − ((OMS 原始需求量 − 发货数量) ÷ OMS 原始需求量)；当月已发货完成订单 | 事后指标，不判断当前交付风险 |
| 建议补货量 | 先按 基地/SKU 算 `max(0, max(当前订单缺口, 目标库存差额) − 在途量)`，再汇总 | 目标库存差额 = 目标库存 − 当前库存；不给到货时间 |
| 近 30 日日均发货量 | SUM(近 30 日发货量) ÷ 30 | 回顾周转天数的分母 |

## 五、计划类与目标版本

| 指标       | 定义                                                      |
| -------- | ------------------------------------------------------- |
| 基地月度需求计划 | 品类计划给出的基地月度**销售需求计划 + 月度调拨出库计划 × 0.5**（该合计已含调拨需求，下游不再重复加）；按基地 + 月份 + SKU，三个版本：纠偏版 / 月初版 / 滚动版 |
| 基地月日均计划量 | 基地月度需求计划 ÷ 当月自然天数（已含调拨 × 0.5） |
| 目标版本取值   | 1–20 日：优先**当月纠偏版** → 当月月初版；21 日–月末：优先**次月月初版** → 次月滚动版；**同月三版优先级：纠偏版 > 月初版 > 滚动版**；按 基地+月份 整体选版，不按 SKU 混用  |
| 版本去重      | 先按 组织（基地）+ 月份 + 版本 + SKU 去重取唯一版本，再汇总；同一基地同一月份内不得混用两个版本 |
| 平台计划节奏   | 15–20 日纠偏当前月计划；20–25 日出 T+1 月初计划与 T+2 滚动计划；各基地不同步，逐基地标注 |

> 业务已确认：1–20 日优先当月纠偏版 → 当月月初版；21 日–月末优先次月月初版 → 次月滚动版；按 基地 + 月份 整体选版，不按 SKU 混用版本。

### 库存结构符合率（V1.4 新增）

| 项 | 内容 |
|---|---|
| 定义 | 衡量基地/品类内各单品库存结构与需求（发货）结构的匹配程度，回答「备的货与卖出去的货结构是否一致」 |
| 公式 | 单品偏差 dᵢ = | 单品i库存 ÷ 总库存 − 单品i日均发货 ÷ 总日均发货 |（中间量，∈[0,1]）；汇总符合率 = 1 − Σdᵢ ÷ 2（∈[0,1]，对全部纳入单品求和） |
| 纳入范围 | 仅纳入 库存 ≠ 0 且 日均发货 ≠ 0 的单品；其余（库存=0 或 发货=0）行不参与计算、亦不进入分母 |
| 分母口径 | 总库存、总日均发货 = **纳入计算单品集合的合计**；排除行不进分母，否则 ΣP≠1、ΣQ≠1，归一化失效 |
| 上卷规则 | SKU 层先取绝对值 dᵢ，再按品类/基地求和；**禁止先聚合品类占比再算差**（品类内正负偏差相抵、指标虚高）；品类层提供两个值：品类内符合率（分母换品类总量重算，横向比较用）与品类错配贡献占比（Σd品类 ÷ Σd基地，下钻定位用） |
| 值域 | Σdᵢ ≤ 2 由三角不等式保证（与单品数无关）；排除规则下只能逼近 2、严格小于 2；实现时校验 ΣP=ΣQ=1，防分母口径混用 |
| 业务定位 | 补总量差额盲区（总量正常≠结构正常）；检验目标版本纠偏效果；基地/品类结构健康度排名与漂移监控；结构调整优先级 |
| 边界 | 不衡量总量合理性（库存差额承接）、库存新旧（货龄承接）、当前缺货（缺货监控承接）；高符合率≠库存合理（全品类同比例超配时结构匹配但总量冗余） |
| 使用注意 | 对断货/滞销单品失明（已排除），解读须配合缺货监控、货龄滞库；单品数为 1 时无评价意义（恒为 100%） |

## 七、上卷与汇总铁律（对齐本次指标梳理新增）

| # | 规则 |
|---|---|
| 1 | **可加和量**（库存、订单量、计划量）：逐级 SUM，批次 → SKU → 品类 → 基地/分仓 → 全国 |
| 2 | **比率 / 天数类**：汇总分子 ÷ 汇总分母，禁止对下级比率或天数取平均 |
| 3 | **差额类**：默认 Σ当前库存 − Σ目标库存，直接相减、允许正负抵消；缺失按 0 参与。用户明确要求或需说明结构风险时，再补分项「高于目标量 / 低于目标量 / 低于目标 SKU 数」，不作为默认必输出 |
| 4 | **去重计数类**（SKU 个数）：全国按 SKU 去重，严禁各基地相加 |
| 5 | **缺口 / 补货类**：先按 基地/分仓 + SKU（+ 订单交付范围）算 max(…, 0) 再 SUM，禁止先汇总总量再算 |
| 6 | **平均货龄**：Σ(数量 × 货龄) ÷ Σ数量，加权，禁止简单平均 |
| 7 | **版本一致性**：先按 组织（基地）+ 月份 + 版本 + SKU 去重取唯一版本，再汇总；版本按 基地 + 月份 整体选取，不得按 SKU 混用版本 |
| 8 | 「全国」= 用户权限范围内的基地集合，不等于各基地简单相加 |
| 9 | **明细取值同源**：目标库存 / 周转库存 / 安全库存按 基地 + 月份 + 版本 + SKU 取**同一版本、同一字段**；明细行不得留空，也不得用过程字段（计算目标库存）顶替目标库存输出值 |
| 10 | **明细缺数按 0**：明细行取不到数按 0 显示，不留空白；分母为 0 或无数时，该比率 / 天数不计算并标「无数据」，同行其他列照常输出 |
| 11 | **汇总 = 逐列求和**：可加和量有值即加、0 或无数不加；比率 / 天数先汇总分子分母再计算；仅当汇总后分母为 0 或无数才标「无数据」，不得因个别行缺数把整行或整个品类置空；汇总与明细必须同一套过滤与版本，对不上先查这两项 |
| 12 | **粒度不可拆**：目标库存只到 基地 + 月份 + 版本 + SKU。下钻到批次 / 生产日期 / 仓库 / 订单等更细粒度时，目标库存列按该 SKU 值回填并注明「目标库存不随批次拆分」，不得留空 |
| 13 | **天数类汇总**：目标周转天数 = Σ目标库存 ÷ Σ月日均计划量；**分子含全部有值行，分母只加有值行**（缺数当 0 不加，等价）；分母为 0 或无数才标「无数据」；单行分母为 0 或无数时该行天数不计算；不得对下级天数取平均 |
| 14 | **全量无目标 = 数据异常**：单个基地（或品类）全部 SKU 都无目标、目标合计为 0 且有库存时，判数据异常（目标版本未发布或数据未到），**不输出该基地的差额与偏差率结论**，标「目标数据异常，待核查目标版本」且不参与排名；只有个别 SKU 无目标才按 0 参与并标注个数 |
| 15 | **结构类比率**（库存结构符合率）：SKU 层偏差先取绝对值再按层级求和，禁止先聚合品类/基地占比再算差（正负抵消、指标虚高）；分母=纳入计算单品集合合计；实现校验 ΣP=ΣQ=1 |


## 八、支持与不支持问题（能力边界）

| 指标 | 支持问题 | 不支持问题 |
|---|---|---|
| 当前库存 / 可用库存 / 占用库存 | 当前值、排名、按对象拆解 | 历史趋势（除非有历史快照） |
| 目标库存 / 库存差额 / 超储 | 差额、高于 / 低于目标、目标版本说明、目标库存与周转 / 安全分项（用户明确要求拆分时） | 历史差额趋势；目标重算过程与设置合理性（替代答法见 8.1） |
| 周转天数（= 回顾）/ 目标周转天数 | 可消化天数、周转偏高对象；目标周转天数按 Σ目标库存 ÷ Σ月日均计划量（分子含全部有值行、分母只加有值行） | 用周转天数替代动销量排序；对下级天数取平均；混版本汇总；把回顾口径与目标天数直接相减 |
| 平均货龄 / 货龄分段 / 大日期 / 超龄 SKU 数 | 货龄分布、大日期对象与占比、超龄 SKU 个数 | 历史货龄趋势；效期比例判断；直接判定责任 |
| 未来 7 / 14 日预计超龄 | 窗口内新增超龄对象、批次、数量 | 与当前大日期（≥61 天）相加；30 日窗口；历史趋势 |
| 近 30 日动销量 / 日均动销 / 动销达成 | 动销最慢对象、高库存低动销、与计划比对 | 其他窗口动销（除已有数据）；用比率替代数量 |
| 当前订单量 / 备单量 / 当前订单缺口 | 当前缺口排行、影响对象、按品类拆解 | 按月份趋势、同比环比；用事后满足率替代 |
| 事后订单满足率 | 当月满足率、满足率低的基地 / 品类 | 当前未完成订单满足率；用当前缺口倒推 |
| 建议补货量 | 补货 SKU 清单、补货量、测算依据 | 到货时间；正式补货单；排产与调拨执行 |
| 库存结构符合率 | 当前结构符合率、偏差最大 SKU 排行、基地/品类间结构对比 | 历史趋势；用高符合率直接判库存合理；用符合率替代缺货/滞库判断 |

量级口径：单位默认件；「全国」= 权限范围内。

### 8.1 不支持问题的标准替代答法

| 用户请求 | 不做的原因 | 标准替代（结论 → 事实 → 边界 → 引导） |
|---|---|---|
| 重新测算目标库存 / 安全库存 | 目标是上游按月测算并落表锁定的结果，Agent 只读、不重算，也不给自算值 | 结论：目标库存由上游测算并锁定，我不重算。事实：给当前目标版本、目标库存、库存差额；用户明确要求拆分时再给周转库存 / 安全库存分项。边界：现场测算需要计划、服务水平、标准差等上游参数，Agent 无授权。引导：看目标缺失清单 / 看目标版本说明 / 看低于目标 SKU |
| 目标设置是否合理 / 偏高偏低 | 合理性判断依赖策略配置与上游测算参数，Agent 无授权、无依据 | 结论：是否合理需业务确认，我只给偏差事实。事实：高于 / 低于目标量、偏差率、目标为 0 或缺失的 SKU 数与清单。边界：不推断目标偏高偏低。引导：看偏差最大的 SKU / 看目标为 0 的 SKU / 看目标版本说明 |
| 历史趋势 / 同比环比 | 当前只有快照数据 | 说明不支持；改给当期分布、结构对比或基地间横向对比 |
| 出口 / 定制产品有没有目标库存、差额多少 | 按订单触发不设目标库存，目标与差额不成立 | 结论：该 SKU 按订单触发，不设目标库存。事实：给当前库存、可用库存、订单与在途。边界：不给目标库存、差额、偏差率、建议补货量。引导：看该 SKU 订单量与在途 / 看同品类常规备货 SKU 的目标 |

## 十一、分仓口径对照（仅供参考，分仓指标以分仓 Agent 自己的 Skill 为准）

| 指标 | 分仓口径 |
|---|---|
| 目标库存 | （生效补货周期 + 3 天缓冲）× 未来 30 日日均计划量（前台实时算） |
| 目标周转天数 | 前端配置（cube）；月日均计划量 = 分仓未来 30 日日均计划量 |
| 大日期 / 超龄 | 货龄 ≥91 天（分仓口径，以分仓 Skill 为准）（基地为 ≥61 天，即超过 60 天） |
| 平均货龄阈值 | 健康 < 20 天；预警 60-90 天；严重 > 90 天（20–60 天区间口径待业务确认） |
| 建议补货量 | max(0, max(缺货量, 目标库存差额) − 分仓调拨中量) |
| 调拨中量 | 调拨备单量 + 调拨在途量（调拨备单量 = 基地未备单完成量 + 已备单未发货占用量） |
| 未来 30 日计划量 | 本月剩余计划量 + 次月日均计划量 × 未来 30 日中落入次月的自然日天数 |
| 预计月末库存 | 当前可用库存 + 本月剩余调拨计划 − 本月剩余出货计划 |
| 仓库类 | 入库量、出库量、过仓量、仓储费、运输费、交付及时率、冷链符合率、准确交付率、库温符合率、回单确认及时率、新鲜度占比 |

## 十二、同义词与口语映射

| 业务口语 | 对应标准指标 | 处理 |
|---|---|---|
| 库存水位 / 库存量 / 现库存 | 当前库存 | 直接对应 |
| 安全库存 / 业务安全库存 | 目标库存输出值（业务口语默认口径，取最终目标库存） | **直接按目标库存回答，不反问、不展示技术拆分**；仅当用户明确说「专业安全库存」「波动安全库存」「拆分周转库存和安全库存」「目标库存计算值」时，才用周转库存 / 安全库存 / 计算值分项 |
| 周转天数 / 库存能卖多少天 | 周转天数 = 当前库存 ÷ 近 30 日日均发货量（回顾口径，唯一主口径） | 直接对应 |
| 转得慢 / 消化慢 | 动销偏慢（近 30 日动销量或日均动销低） | 不用周转天数替代排序 |
| 可发货天数 | 计划维度补充口径：当前可用库存 ÷ ((月度需求计划 + 月度调拨出库计划 × 0.5) ÷ 当月天数) | 与周转天数分开说明，不混称 |
| 大日期 / 超龄 | 基地货龄 61 天以上 | 分仓场景为 91 天及以上（超过 90 天），需区分 |
| 缺货量 | 当前订单缺口 | 不用「订单量 − 库存」近似 |
| 订单满足率 | 事后已发货完成口径 | 不用于当前风险 |
| 结构合不合理 / 备货结构对不对 / 库存结构匹配 | 库存结构符合率 | 直接对应；解释时说明纳入范围与上卷口径 |
