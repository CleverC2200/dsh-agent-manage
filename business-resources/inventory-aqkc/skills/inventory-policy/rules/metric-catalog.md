# 基地库存指标口径与问数路由（指标能力矩阵）

版本：V1.1-261010（已与《产销协同数据指标》对齐）
数据来源：产销协同数据指标表。基地库存口径以**谷圣磊（43 条）**为主，缺失项按**刘壮壮 → 李琳 → 张光照**优先级补充；与固化规则包 V2.2 冲突时以固化规则包为准。
P1 边界：做问数、口径解释、看板分析、固定报告、未来 7/14 日预计超龄推演、补货 SKU 与补货量测算；待办 / 事件 / 反馈 / 责任 / 升级 / 到货时间承诺属 P2。
本 Agent 只回答**基地口径**；分仓口径见第十一节，遇到分仓问题说明归属。

## 一、库存规模类

| 指标            | 定义与公式                                               | 支持维度                     | 时间  |
| ------------- | --------------------------------------------------- | ------------------------ | --- |
| 当前库存（同义词：库存量） | Σ明细库存数量；可加和量，逐级 SUM                                 | 全国/基地/分仓/品类/物料组/SKU/生产日期 | 日快照 |
| 可用库存          | 当前库存中可用于发货、调拨或订单满足的部分，不含占用、冻结、质检不可用；Σ明细可用库存数量       | 同上                       | 日快照 |
| 占用库存          | 已被订单、调拨、质量、盘点等业务动作占用的库存；Σ明细占用库存数量                   | 同上                       | 日快照 |
| 目标库存          | 目标库存模型输出；按 基地+月份+版本+SKU 取值，禁止用过程字段替代最终目标            | 全国/基地/品类/物料组/SKU         | 日   |
| 库存差额          | 当前库存 − 目标库存；先按 基地+SKU 算差再上卷，汇总必须**分项**输出高于目标量与低于目标量 | 同上                       | 日快照 |
| 超储库存          | 高于目标的正向差额部分（顶部指标与超储风险来源）                            | 同上                       | 日快照 |

目标库存同义词（业务口语）：目标库存量、库存目标、库存水位目标、库存基准、库存定额、目标存量、库存规划量、理想库存水平、**安全库存**（业务口语中常混用，回答时须说明二者区别）。

## 二、周转与效率类

| 指标 | 定义与公式 | 说明 |
|---|---|---|
| 周转天数（= 回顾周转天数，看板口径） | 当前库存 ÷ 近 30 日日均发货量；无发货时标「不可计算 / 待复核」 | **唯一主口径**；看历史消化速度，分母是实际发货 |
| 可发货天数（刘壮壮口径） | 当前可用库存 ÷ ((月度需求计划 + 月度调拨出库计划 × 0.5) ÷ 当月天数) | 计划维度的补充口径，不替代周转天数；指标表曾用名「展望周转天数」，属定义重复，该名称已作废 |
| 目标周转天数（原「目标天数」） | 目标库存 ÷ 月日均计划量；基地按产品标签配置（大数据），分仓前端配置 | 基地月日均计划量 = (月度需求计划 + 月度调拨出库计划 × 0.5) ÷ 当月自然天数 |
| 周转天数差额 | **周转天数 − 目标周转天数**；正数高于目标 | 与固化规则包一致；汇总用「上卷后周转天数 − 上卷后目标周转天数」 |

汇总规则：天数类与比率类一律「汇总分子 ÷ 汇总分母」，禁止对 SKU 天数取简单平均；先按 基地+月份+版本+SKU 去重取唯一版本再汇总。

## 三、货龄类

| 指标 | 定义与公式 | 阈值（业务默认） |
|---|---|---|
| 平均货龄天数 | Σ(批次库存数量 × 批次货龄) ÷ Σ批次库存数量；批次货龄 = 快照日期 − 生产/入库日期 | 基地：健康 12 天；预警 30-60 天；严重 >60 天（分仓：健康 <20 天；预警 60-90 天；严重 >90 天） |
| 货龄分段 | 0-30 / 31-40 / 41-60 / 60 天以上（基地） | 与看板一致 |
| 超龄（大日期）库存量 | Σ(货龄 > 阈值的批次库存数量) | **基地 >60 天；分仓 >90 天** |
| 超龄 SKU 个数 | COUNT(DISTINCT SKU WHERE 货龄 > 阈值)；**全国按 SKU 去重，严禁各基地相加** | 越低越好 |
| 大日期库存占比 | 大日期库存量 ÷ 当前库存量 × 100% | 阈值待业务确认 |
| 大日期（定义） | 基地货龄 60 天以上（含第 60 天）；**不涉及保质期 / 效期**（公司产品保质期统一 12 个月） | — |
| 未来 7 日 / 14 日预计超龄 | 批次级推演：当前货龄 < 60 天，按先进先出扣减窗口内预计动销后，窗口结束时货龄 ≥ 60 天的批次库存 | 排除当前 60+；不扣减未来生产入库 |

## 四、订单类

| 指标 | 定义与公式 | 说明 |
|---|---|---|
| 备单量 | SUM(未备单完成订单量)，不含已备单完成未发货 | 原子/派生 |
| 当前订单量 | 备单量 + 已备单未发货占用量；剔除已作废 / 已取消订单 | 看板「当前订单」 |
| 当前订单缺口（看板「缺货量」） | 先按 基地/SKU（+订单交付范围）算 `max(未备单完成订单量 − 已占用库存 − 当前可用库存, 0)`，再汇总 | **禁止先汇总总量再算缺口** |
| 事后订单满足率 | 1 − ((OMS 原始需求量 − 发货数量) ÷ OMS 原始需求量)；当月已发货完成订单 | 事后指标，不判断当前交付风险 |
| 建议补货量 | 先按 基地/SKU 算 `max(0, max(当前订单缺口, 目标库存差额) − 在途量)`，再汇总 | 目标库存差额 = 目标库存 − 当前库存；不给到货时间 |
| 近 30 日日均发货量 | SUM(近 30 日发货量) ÷ 30 | 回顾周转天数的分母 |

## 五、计划类与目标版本

| 指标       | 定义                                                      |
| -------- | ------------------------------------------------------- |
| 基地月度需求计划 | 品类计划给出的基地月度**销售需求计划 + 月度调拨出库计划 × 0.5**（含销售需求与调拨需求）；按基地 + 月份 + SKU，三个版本：纠偏版 / 月初版 / 滚动版 |
| 基地月日均计划量 | (月度需求计划 + 月度调拨出库计划 × 0.5) ÷ 当月自然天数 |
| 目标版本取值   | 1–20 日：优先**当月纠偏版** → 当月月初版；21 日–月末：优先**次月月初版** → 次月滚动版  |
| 平台计划节奏   | 15–20 日纠偏当前月计划；20–25 日出 T+1 月初计划与 T+2 滚动计划；各基地不同步，逐基地标注 |

> 业务已确认：1–20 日优先当月纠偏版 → 当月月初版；21 日–月末优先次月月初版 → 次月滚动版。

## 六、结构类计数指标

| 指标 | 公式 | 上卷要求 |
|---|---|---|
| 低库存 SKU 数 | COUNT(DISTINCT SKU WHERE 当前库存 < 目标下限) | 全国按 SKU 去重，严禁相加 |
| 高库存 SKU 数 | COUNT(DISTINCT SKU WHERE 当前库存 > 目标上限) | 全国按 SKU 去重，严禁相加 |
| 超龄 SKU 个数 | COUNT(DISTINCT SKU WHERE 货龄 > 阈值) | 全国按 SKU 去重，严禁相加 |
| SKU 数 | count(distinct SKU) | 同上 |

## 七、上卷与汇总铁律（对齐本次指标梳理新增）

| # | 规则 |
|---|---|
| 1 | **可加和量**（库存、订单量、计划量）：逐级 SUM，批次 → SKU → 品类 → 基地/分仓 → 全国 |
| 2 | **比率 / 天数类**：汇总分子 ÷ 汇总分母，禁止对下级比率或天数取平均 |
| 3 | **差额类**：先在下级（基地/分仓 + SKU）算差再上卷；全国 / 区域汇总必须分项输出「高于目标量」与「低于目标量」两条，禁止正负抵消 |
| 4 | **去重计数类**（SKU 个数）：全国按 SKU 去重，严禁各基地相加 |
| 5 | **缺口 / 补货类**：先按 基地/分仓 + SKU（+ 订单交付范围）算 max(…, 0) 再 SUM，禁止先汇总总量再算 |
| 6 | **平均货龄**：Σ(数量 × 货龄) ÷ Σ数量，加权，禁止简单平均 |
| 7 | **版本一致性**：先按 基地 + 月份 + 版本 + SKU 去重取唯一版本，再汇总 |
| 8 | 「全国」= 用户权限范围内的基地集合，不等于各基地简单相加 |

## 八、支持与不支持问题（能力边界）

| 指标 | 支持问题 | 不支持问题 |
|---|---|---|
| 当前库存 / 可用库存 / 占用库存 | 当前值、排名、按对象拆解 | 历史趋势（除非有历史快照） |
| 目标库存 / 库存差额 / 超储 | 差额、高于 / 低于目标、目标版本说明 | 历史差额趋势；目标重算过程与设置合理性 |
| 周转天数（= 回顾）/ 目标周转天数 | 可消化天数、周转偏高对象、天数差额 | 用周转天数替代动销量排序；对下级天数取平均 |
| 平均货龄 / 货龄分段 / 大日期 / 超龄 SKU 数 | 货龄分布、大日期对象与占比、超龄 SKU 个数 | 历史货龄趋势；效期比例判断；直接判定责任 |
| 未来 7 / 14 日预计超龄 | 窗口内新增超龄对象、批次、数量 | 与当前 60+ 相加；30 日窗口；历史趋势 |
| 近 30 日动销量 / 日均动销 / 动销达成 | 动销最慢对象、高库存低动销、与计划比对 | 其他窗口动销（除已有数据）；用比率替代数量 |
| 当前订单量 / 备单量 / 当前订单缺口 | 当前缺口排行、影响对象、按品类拆解 | 按月份趋势、同比环比；用事后满足率替代 |
| 事后订单满足率 | 当月满足率、满足率低的基地 / 品类 | 当前未完成订单满足率；用当前缺口倒推 |
| 建议补货量 | 补货 SKU 清单、补货量、测算依据 | 到货时间；正式补货单；排产与调拨执行 |

量级口径：单位默认件；「全国」= 权限范围内。

## 九、引导问题白名单

| 指标 | 允许引导 | 禁止引导 |
|---|---|---|
| 库存差额 / 偏差率 | 看低于目标的基地/品类/SKU；看高于目标对象；按品类拆解差额；看目标版本说明 | 看历史差额趋势；推断目标设置是否合理；直接建议调目标 |
| 周转天数 | 看周转最高对象；结合货龄与动销判断；看天数差额 | 用周转天数解释动销量最慢；对下级天数取平均 |
| 货龄 / 大日期 | 看 60 天以上明细；看 41-60 天重点对象；看超龄 SKU 个数与占比；结合动销判断消化压力 | 看历史货龄趋势；基于效期给结论；直接判定责任 |
| 未来 7 / 14 日预计超龄 | 看未来 7 日 / 14 日新增超龄批次；看是否扣减预计动销；与当前 60+ 一起看 | 把当前 60+ 与未来超龄相加；看历史趋势 |
| 动销 | 看这些对象的库存差额与货龄；看动销最低的 SKU；看是否存在高库存低动销 | 直接按周转天数继续解释；直接判定滞库责任；直接建议控产 / 促销 |
| 当前订单缺口 | 看缺口 SKU 明细；按品类拆解；看可用库存与占用量；看近期排产与在途 | 按月份看趋势；同比环比；承诺到货时间 |
| 事后订单满足率 | 看满足率低的基地 / 品类；看已发货订单量与发货量 | 用它解释当前是否缺货；用当前缺口倒推满足率 |
| 补货 | 看补货 SKU 清单与补货量测算；看缺口、在途与预计入库明细 | 承诺到货时间；自动生成补货单；替代计划员决策 |
| 通用 | 切换基地 / 品类 / SKU 范围；切换数据时间说明；生成日报 | 引导到 P2 能力（待办 / 事件 / 反馈 / 责任 / 升级）；编造趋势 |

引导数量：每次 2-4 个，只能取自本表。

## 十一、分仓口径对照（分仓平台专用，不并入基地口径）

| 指标 | 分仓口径 |
|---|---|
| 目标库存 | （生效补货周期 + 3 天缓冲）× 未来 30 日日均计划量（前台实时算） |
| 目标周转天数 | 前端配置（cube）；月日均计划量 = 分仓未来 30 日日均计划量 |
| 大日期 / 超龄 | 货龄 **> 90 天**（基地为 > 60 天） |
| 平均货龄阈值 | 健康 < 20 天；预警 60-90 天；严重 > 90 天 |
| 建议补货量 | max(0, max(缺货量, 目标库存差额) − 分仓调拨中量) |
| 调拨中量 | 调拨备单量 + 调拨在途量（调拨备单量 = 基地未备单完成量 + 已备单未发货占用量） |
| 未来 30 日计划量 | 本月剩余计划量 + 次月日均计划量 × 未来 30 日中落入次月的自然日天数 |
| 预计月末库存 | 当前可用库存 + 本月剩余调拨计划 − 本月剩余出货计划 |
| 仓库类 | 入库量、出库量、过仓量、仓储费、运输费、交付及时率、冷链符合率、准确交付率、库温符合率、回单确认及时率、新鲜度占比 |

## 十二、同义词与口语映射

| 业务口语 | 对应标准指标 | 处理 |
|---|---|---|
| 库存水位 / 库存量 / 现库存 | 当前库存 | 直接对应 |
| 安全库存 | 目标库存（业务常混用）；技术口径另有安全库存字段 | 先问清是指目标水位还是模型安全库存，再作答 |
| 周转天数 / 库存能卖多少天 | 周转天数 = 当前库存 ÷ 近 30 日日均发货量（回顾口径，唯一主口径） | 直接对应 |
| 转得慢 / 消化慢 | 动销偏慢（近 30 日动销量或日均动销低） | 不用周转天数替代排序 |
| 可发货天数 | 计划维度补充口径：当前可用库存 ÷ ((月度需求计划 + 月度调拨出库计划 × 0.5) ÷ 当月天数) | 与周转天数分开说明，不混称 |
| 大日期 / 超龄 | 基地货龄 60 天以上 | 分仓场景为 90 天以上，需区分 |
| 缺货量 | 当前订单缺口 | 不用「订单量 − 库存」近似 |
| 订单满足率 | 事后已发货完成口径 | 不用于当前风险 |
