# 基地库存偏差监控 — 规则与阈值

## 1. 计算公式

| 指标 | 公式 | 说明 |
|---|---|---|
| 库存差额 | 当前库存 − 目标库存 | **主口径**，单位件；正数高于目标，负数低于目标 |
| 偏差率 | (当前库存 − 目标库存) ÷ 目标库存 × 100% | 目标库存 > 0 时计算，带正负号 |
| 偏差金额 | 不使用 | P1 不做金额分层与金额排序 |

特殊情况：
- 目标库存 = 0：差额按「库存 − 0」计入，不算偏差率，标注「目标为 0」，不参与偏差率排名
- 目标缺失：差额按「库存 − 0」计入，偏差率不计算（分母 0），标注「目标缺失」，单列清单
- 当前库存为空：目标有值即参与，按「0 − 目标」计入，标注「库存记录缺失」；整批库存未到属数据异常，按数据说明处理
- 库存与目标都缺失：不参与差额计算，单列「数据缺失」清单
- 计划量为 0 或缺失：不输出该行的周转与目标天数结论（汇总时分子照常计入）

## 2. 目标版本取值规则（按基地维度）

| 日期区间 | 优先版本 | 次选版本 |
|---|---|---|
| 每月 1–20 日 | 当月纠偏版 | 当月月初版 |
| 每月 21 日–月末 | 次月月初版 | 次月滚动版 |

- 平台计划节奏：15–20 日纠偏当前月计划；20–25 日出 T+1 月初计划与 T+2 滚动计划；各基地不同步。
- 业务已确认：1–20 日优先当月纠偏版 → 当月月初版；21 日–月末优先次月月初版 → 次月滚动版。
- 不判断「是否最新版本」，只按上表取数；各基地版本不同则逐一标注；版本缺失单列。

## 3. 风险分层（受控配置默认值）

偏差率分层（默认，业务可在业务维护规则包中调整）：

| 层级 | 偏差率 | 标记 |
|---|---|---|
| 正常 | −15% ~ +15% | 🟢 |
| 关注 | −30% ~ −15% 或 +15% ~ +30% | 🟠 |
| 高风险 | < −30% 或 > +30% | 🔴 |

调整规则（调整需标注原因）：
- 降级：高于目标但动销达成 ≥ 100%；低于目标但订单满足且无当前订单缺口；偏差量绝对值很小
- 升级：高于目标且平均货龄 ≥ 41 天；低于目标且存在当前订单缺口；连续多期同向扩大

**偏差率不可计算时（目标为 0 或缺失）**：不套用偏差率分层，改按库存差额绝对值或库存量分层，并标注「无偏差率，按差额分层」；不得因缺偏差率把该对象整行置空。

风险等级命名与颜色全项目统一：高风险（红）/ 关注（橙）/ 正常（绿）。

## 4. 重点对象筛选

排序优先级：
1. 风险等级（高风险 > 关注 > 正常）
2. 库存差额绝对值（件）
3. 偏差率绝对值

必纳入对象（即使不在 TOP）：高风险对象、用户点名对象、低于目标且有当前订单缺口的对象、目标缺失且库存量大的对象。

## 5. 原因线索（最多 5 条，标注证据状态）

| 方向 | 子原因 | 触发条件 | 证据状态 |
|---|---|---|---|
| 需求端 | 动销超计划 | 近 30 日日均动销 > 日均计划量 × 120% | 有支撑未验证 |
| 需求端 | 动销不及计划 | 近 30 日日均动销 < 日均计划量 × 60% | 有支撑未验证 |
| 需求端 | 客户拉货不足 | 计划拉货量 > 实际拉货量 × 130% | 有支撑未验证 |
| 供给端 | 生产提前入库 | 入库日期早于计划 3 天以上 | 有支撑未验证 |
| 供给端 | 生产延迟 | 应入库未入库数量 > 0 | 已验证（有计划数据时） |
| 供给端 | 调拨延迟 | 在途时间超预计 | 推测 |
| 目标端 | 目标版本切换 | 近期目标版本发生切换 | 已验证（有记录时） |

禁止：推断「目标设置不合理」「目标偏高偏低」，不解释目标重算过程，不输出自算目标 / 安全库存数值。

## 6. 建议规则

| 建议 | 触发条件 | 优先级 |
|---|---|---|
| 目标库存复核 | 目标缺失 / 目标为 0 且有库存 / 偏差率持续 > 30% | 高 |
| 缺货复核 | 低于目标且存在当前订单缺口 | 高 |
| 滞库分析 | 高于目标且货龄 ≥ 41 天且动销达成 < 60% | 中 |
| 生产进度确认 | 低于目标且有未入库生产计划 | 中 |
| 需求复核 | 高于目标且动销达成 < 50% | 低 |

所有建议标注【待人工确认】；P1 不指定具体责任人与责任人指派，可给建议责任角色（角色级、不写人名），不派发任务。

## 7. 数据完整性校验

必备字段：SKU 编码、基地、当前库存、目标库存、数据截止时间。缺字段时按指标分别处理，**不整行作废**：库存与目标任一有值即参与差额（缺的按 0）、两者都缺则该行不参与差额并单列；偏差率仅在目标 > 0 时计算。但**基地级全量缺失（库存与目标都缺，或全部无目标且有库存）判数据异常**，该基地不出差额与偏差率结论，提示核查数据与目标版本，其余基地照常。

可选字段缺失时：无订单数据→不做订单影响分析；无动销→不做动销关联；无货龄→不做货龄关联；无计划量→不做周转判断。

## 8. 汇总与上卷规则

- **差额汇总**：默认 Σ当前库存 − Σ目标库存，直接相减、允许正负相抵；库存或目标缺失按 0 参与。用户明确要求或需说明结构时，再补「高于目标量 / 低于目标量 / 低于目标 SKU 数」作为风险提示，不作为默认必输出
- 偏差率 = 汇总库存差额 ÷ 汇总目标量（比率类用汇总分子 ÷ 汇总分母，禁止对 SKU 偏差率取平均）
- 目标周转天数 = Σ目标库存 ÷ Σ月日均计划量，**分子含全部有值行、分母只加有值行**；版本按 基地 + 月份 整体选取，不按 SKU 混用
- 目标为 0 或缺失的 SKU：差额按「库存 − 0」计入汇总，但不进偏差率分母（分母为 0 不计算），单独计数用于说明
- 汇总偏差率仅作参考，分析重点在 SKU 与基地×品类粒度
