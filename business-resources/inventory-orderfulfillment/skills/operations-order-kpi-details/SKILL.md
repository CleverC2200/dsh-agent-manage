# 订单工作台指标明细 Skill

## 适用边界

- 当用户问“作废率/改单率/满足率/准交率的明细、有哪些订单、为什么未达标、查看某周期订单”时使用。
- 当用户问“订单是否拆单、这个订单拆成了哪些单、拆单后的其他单据有哪些”时使用。
- 当用户问“某订单改了什么、改单商品明细、商品数量如何变更、改单前后数量”时使用。
- 当用户问“60天以上货龄占比明细、可发货天数全国/品项明细、某基地可发货天数、日均需求怎么算”时使用。
- 在工作台中提供指标对应的订单清单与统计周期，不重新定义四项指标的汇总口径。
- 60天以上货龄占比、可发货天数的库存计算由 [sku-inventory-shortage](../sku-inventory-shortage/SKILL.md) 提供；本 Skill 负责工作台的汇总与明细展示。
- 不修改订单、拆单、改单、作废或履约节点；仅查询与展示。

## 输入与前置条件

识别指标类型或订单号、统计周期、统计层级（全国/基地/销售省区/负责人/品项）、筛选条件、数据截至时间及当前用户权限。

- 指标明细未给出周期时，沿用用户当前打开的周报或月报周期；没有页面上下文时，追问周期。
- 单订单拆单或改单查询以订单号为必填条件；若已知订单但未指定周期，优先以该订单及其关联事件的有效时间范围查询，不因缺少报表周期拒绝查询。
- 货龄与可发货天数查询必须识别维度：全国、品项或基地；未指定维度时先按用户当前工作台筛选维度展示，并标明默认范围。
- 明细范围必须与指标卡相同：相同有效订单规则、去重键、基地/销售组织归属、目标版本及快照时间。
- 用户无明细权限时，只返回其权限范围内的汇总，明确说明限制。

## 工作步骤

1. 从 [operations-kpi-performance-analysis](../operations-kpi-performance-analysis/SKILL.md) 获取该指标的统计范围、分子/分母、计算口径和周期。
2. 通过 [order-fulfillment-risk](../order-fulfillment-risk/SKILL.md) 查询同一范围内的订单主数据、订单状态、改单记录、承诺/实际节点、订单需求量、满足量和最后一次发货时间。
3. 按订单唯一键去重；一个订单多次改单或多条履约事件只展示一行，并聚合为最新有效状态。
4. 按所查指标筛选或排序：
   - **作废率**：展示纳入作废率口径的订单，默认按作废订单优先；
   - **改单率**：展示发生有效改单的订单，默认按最近改单时间倒序；
   - **满足率**：展示全部纳入统计的订单，并优先显示满足率低、缺口大的订单；
   - **准交率**：展示可判定准交的订单，并优先显示不准交、超时或预警订单。
5. 返回“指标标题 + 统计周期 + 明细表 + 口径/缺项”，使表内订单能追溯到上方指标卡。

### 库存指标明细模式

1. 通过 [sku-inventory-shortage](../sku-inventory-shortage/SKILL.md) 获取同一周期、同一筛选范围内的总库存、60天以上库存、可用库存、月度需求计划、月度调拨需求出库计划、当月天数、日均需求及商品/基地归属。
2. 汇总区固定展示：`汇总总库存｜60天以上汇总库存件数｜60天以上货龄占比`；货龄占比的分子、分母必须使用同一库存范围。
3. 可发货天数严格调用已发布的计算模型，同时将公式、需求构成、系数和当月天数展示给用户；不根据页面样例值自行推导或覆盖业务公式。
4. 全国与品项维度使用全国/品项配置的需求口径；基地维度使用基地配置的需求口径及调拨折算系数。当前工作台已发布口径：全国/品项日均需求为月度需求计划 ÷ 当月天数，不加调拨；基地日均需求为（月度需求计划＋月度调拨出库计划 × 0.5）÷ 当月天数。其他配置版本以该页面已发布值为准。
5. 用户查看某一商品的日均需求时，在右侧展示或展开“某商品的日均需求内容”，至少包含月度需求计划、月度调拨需求出库计划、调拨系数、当月天数和最终日均需求。
6. 总库存、60天以上库存、日均需求或可发货天数任一字段缺失时，仅展示可用原始字段并标记“待确认”；不得用 0 补全。

### 拆单关联单据模式

1. 根据当前订单号查询拆单关系记录、拆单组 ID、父子订单/来源订单关系及生效状态；不得仅凭“是否拆单=是”推断具体关联单据。
2. 返回同一拆单组内的全部有效订单：当前查询订单必须排在第一行并标识为“本单”，其余订单标识为“关联单据”。
3. 若业务模型存在来源单、拆出单、合并单等方向，显示关系类型；没有可靠关系方向时仅显示“同一拆单组关联”，不虚构父子关系。
4. 同一订单在不同拆单组或发生多次拆单时，按拆单时间分组展示，不将不同批次的拆单关系混在一张表中。
5. 没有关系记录时明确显示“未发现拆单关系”；关系数据未接入或无权限时显示“暂无法判断”，不等同于“未拆单”。

### 改单商品明细模式

1. 根据当前订单号查询有效改单事件、改单版本及订单商品行；一个订单存在多次改单时，默认展示最新有效版本，并提供按改单时间/版本查看历史的入口。
2. 对每个 SKU 关联改单前后的数量与商品信息；商品新增、删除、替换和数量变更都应明确区分，不以当前订单商品清单替代历史变更事实。
3. 商品行按 `订单号 + 改单版本 + SKU/商品行标识` 去重；同一商品多次变更时，展示当前查询版本对应的变更，并提示该 SKU 的变更次数。
4. 原始数量、调整数量、实占数量、发货数量和下单数量必须来自各自业务定义；字段定义或单位不一致时，保留原值并标记“口径待确认”，不得自行相减或汇总。
5. 没有有效改单事件时显示“该订单未发现有效改单记录”；事件数据缺失或无权限时显示“暂无法判断”，不可误报“未改单”。

## 工作台展示规范

明细区域采用截图对应的订单清单样式：

- 顶部左侧显示红色标题：`作废率 / 改单率 / 满足率 / 准交率指标明细`；标题可随当前查询指标切换为单项名称。
- 顶部右侧固定显示：`统计周期：{周期}`，例如 `2026年10月（10/23–10/30）`；同时标注数据截至时间。
- 表头使用浅灰底；订单号、渠道/大区/省区/销售组、所属基地、单据新增时间、订单状态为基础列。
- 状态列使用统一图标与文字，不只显示颜色：
  - 是 / 达标 / 准交：`✓ 是`、`✓ 达标`、`✓ 准交`；
  - 否 / 未达标 / 不准交：`✕ 否`、`✕ 未达标`、`✕ 不准交`；
  - 数据缺失或不可判定：`— 待确认`。
- 可点击下钻字段（例如“是否拆单”）使用蓝色文字及展开图标；没有下钻数据时不可伪装成可点击。
- 订单状态（如“作废”）仍以订单系统当前/周期内有效状态展示，不以图标替代业务状态。

### 拆单数据展示

- 点击或询问“是否拆单”后，在当前明细区域展示标题为红色的 `拆单数据`，不跳转至无关页面。
- 表格保留截图中的订单基础字段：`订单号｜渠道/大区/省区/销售组｜所属基地｜单据新增时间｜订单状态｜是否改单｜是否准交｜是否拆单｜发货时间`。
- 在订单号前增加 `关联标识`：当前查询订单显示 `本单`；同组其他订单显示 `关联单据`。如有可靠数据，可额外展示 `拆单组 ID｜关系类型｜拆单时间｜拆单数量/金额`。
- 本单使用强调样式或 `本单` 标识，不以颜色作为唯一辨识方式；关联单据可分页，分页总数必须与当前拆单组匹配。
- “是否拆单”为是时以蓝色可展开图标/文字呈现；为否时不展示无效展开入口。

### 改单数据展示

- 点击或询问“是否改单”后，在当前明细区域显示红色标题 `改单数据`，展示该订单的商品明细，不跳转至无关页面。
- 表格采用截图字段顺序：`产品信息｜原始数量｜调整数量｜实占数量｜发货数量｜下单数量｜品项｜应责总监｜订单号｜渠道/大区/省区/销售组｜所属基地`。
- 产品信息至少显示 SKU/商品名称与商品编码；当前查询订单号必须显示在每一行，便于多订单场景核验。
- 有可靠数据时，可增加 `改单版本｜改单时间｜改单类型｜调整前数量｜调整后数量｜调整原因`；若页面宽度有限，放入商品行展开区域，不删除截图基础字段。
- 商品新增、删除、替换、数量增加、数量减少使用图标加文字标识；无变更字段或原因时显示 `— 待确认`，不使用默认值代替。
- 同一订单的商品较多时分页展示；页码和总条数仅统计当前订单、当前改单版本与当前权限范围内的商品行。

### 60天货龄占比、可发货天数展示

- 顶部使用红色标题，根据查询维度显示：
  - 全国或品项：`60天货龄占比、可发货天数—汇总（全国、品项）`；
  - 基地：`60天货龄占比、可发货天数（基地）`。
- 标题下方展示汇总卡：`汇总总库存｜60天以上汇总库存件数｜60天以上货龄占比`，并显示统计周期、库存快照时间及公式版本。
- 紧随其后展示“可发货天数”公式，公式中的月度需求计划、月度调拨需求出库计划、调拨系数、当月天数和计算结果都必须使用真实字段值或明确标为待确认。
- 全国/品项表格字段：`产品信息｜总库存｜60天以上库存件数｜可发货天数｜日均需求｜品项｜应责总监｜渠道/大区/省区/销售组`。
- 基地表格字段：`产品信息｜总库存｜60天以上库存件数｜可发货天数｜日均需求（基地口径）｜所属基地｜品项｜应责总监｜渠道/大区/省区/销售组`。
- 日均需求可点击或展开右侧详情面板；基地口径须额外显示调拨折算系数 `0.5`（或当前配置值）。无需求明细数据时不显示可点击入口。
- 库存或需求数据较多时分页；总条数仅统计当前维度、周期、库存范围和权限范围内的商品行。

## 字段与列规则

**所有指标的基础列**

`订单号｜渠道/大区/省区/销售组｜所属基地｜单据新增时间｜订单状态｜是否改单｜是否准交｜是否拆单｜最后一次发货时间`

**按指标补充列**

| 查询指标                      | 必须补充字段                                                                                     | 说明                                       |
| ----------------------------- | ------------------------------------------------------------------------------------------------ | ------------------------------------------ |
| 作废率                        | 作废时间、作废原因、作废前订单金额/数量（如已接入）                                              | 作废原因缺失时显示“待确认”                 |
| 改单率                        | 最近改单时间、改单类型、改单前后关键字段、改单原因                                               | 多次改单只展示最新有效记录，并提示改动次数 |
| 满足率                        | 订单需求量、已满足量、缺货量、订单满足率                                                         | 数量需带单位；无需求量时满足率不可计算     |
| 准交率                        | 承诺交付时间、实际交付/签收时间、准交判定、超时原因                                              | 节点或承诺时间缺失时为“待确认”             |
| 60天以上货龄占比 / 可发货天数 | 总库存、60天以上库存、可用库存、月度需求计划、月度调拨需求出库计划、调拨系数、当月天数、日均需求 | 按全国/品项或基地选择对应需求口径          |

**拆单关联查询补充字段**

`当前订单号｜拆单组 ID｜关联标识（本单/关联单据）｜关系类型｜拆单时间｜关联订单号｜拆单前后数量或金额（如已接入）`

**改单商品查询字段**

`产品名称｜SKU/商品编码｜原始数量｜调整数量｜实占数量｜发货数量｜下单数量｜单位｜品项｜应责总监｜订单号｜渠道/大区/省区/销售组｜所属基地｜改单版本｜改单时间｜改单类型｜改单原因`

**库存指标查询字段**

`产品名称｜SKU/商品编码｜库存范围｜总库存｜60天以上库存件数｜可用库存｜可发货天数｜月度需求计划｜月度调拨需求出库计划｜调拨折算系数｜当月天数｜日均需求｜所属基地｜品项｜应责总监｜渠道/大区/省区/销售组｜库存快照时间｜公式版本`

## 口径与异常处理

- 作废、改单、准交的规则必须使用已发布版本；规则缺失时可展示原始状态，但不可计算或判断指标。
- 满足率 = 实际满足数量 ÷ 订单需求数量；合计必须由数量重算，不平均订单百分率。
- 最后一次发货时间不等于签收时间；准交率的实际完成节点必须与业务规则一致。
- 查询结果为 0 时显示“本统计周期内无匹配订单”；数据源未接入时显示“无可用明细数据”，两者不得混淆。
- 订单属于多个基地、销售组织或周期边界不清时，显示归属规则与待确认项，禁止重复计入。
- 拆单关系以订单关系表或经确认的拆单事件为准；订单号相近、客户相同或创建时间接近都不能作为关联依据。
- 改单商品明细以有效改单事件及对应订单商品行版本为准；不能将后续发货变动、库存占用变动或人工备注自动认定为改单。
- 60天以上货龄占比 = 60天以上纳入统计的库存 ÷ 同一范围的纳入统计库存；汇总占比必须由汇总分子/分母重算，不平均商品或基地占比。
- 可发货天数的库存分子、需求口径与调拨折算系数必须与查询维度一致。若公式字段与页面展示值无法对账，展示原始字段、公式版本与差异，标记“待核验”，不输出伪精确天数。

## 当前页面口径与证据

本工作台货龄按 age_days≥60，库存按工厂仓＋工厂外租仓的 inv_qty 统计；同一截止日取期末快照，源记录先按完整批次字段去重。本期为本月1日至所选截止日，本周单独列示；周/月均以当前页面发布的实际边界和快照为准。百分率环比同比差使用 %，天数差使用天。页面上下文的有限明细不是完整清单，需通过当前 Agent 的受控查询取得同范围原始明细后输出表格；不得从汇总拼造订单或商品行。

## 当前安装能力边界

本 Skill 由订单工作台与订单履约 Agent 共用，技能描述不授予查询、人员范围或业务写入权限。只能使用当前 Agent 已安装、已授权的页面证据和工具；用户角色描述不代表实际授权。

订单履约只使用 order01 的当前用户受控只读能力，缺失指标和接口保持未知。订单工作台沿用其当前已发布能力；页面处于 mock 时，只分析明确标记的报告摘录、演示数据或用户提供的证据，不宣称已接入实时订单系统。

销售确认、每小时提醒、飞书消息、OMS 更新、WMS/TMS 下发及外部改善任务尚无本次新增的写入或调度接口。可以解释流程、分析证据和生成草案，不能因加载 Skill 就启动执行或声称已完成。实际操作仍需相应工具、有效权限和明确授权。
