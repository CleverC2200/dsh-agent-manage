# 同等水平验收

“同等”指可核验的数据能力和分析能力，不要求逐字相同。每项记录PASS/FAIL/UNVERIFIED、证据路径和差异。

1. 范围与身份：同期间、同版本、同订单池；主来源空值不被候选替换。
2. 指标语义：真实发货/等效分子分开，公式冲突显式；没有依据不发布正式率。
3. 数量与单位：所有顶卡和正文与来源一致；未知单位无擅自转换；初始/纠偏独立。
4. 完整性：分页稳定排序，键唯一，明细合计与全国及各基地相等；空值/空基地保留。
5. 需求分析：版本变化定位到有数据的组织；准确率按正式非加性规则，原生品类或可靠映射未取得即披露。
6. 生产分析：所有欠产基地、局部正差与净差、日期/SKU/产线/理由证据；不是只有原因标签排行。
7. 推理质量：机制有支撑，检查反证，不因月度超产或提报充足排除局部缺货；缺关系不编订单损失。
8. 交付：HTML/MD/JSON一致、明细全量、查询可追溯；DOM和视觉验收如实分开。

数字允许源展示四舍五入误差，基础量按源精度比较；源有未知或冲突时，两报告都应保留它。不可通过增加空值来逃避已能取到的数据；也不可为匹配基准强填数据。

先进行同证据独立复现，再进行新查询复现。来源返回改变时保留双快照，不把源变动记成模型推理失败。最终需真实目标模型运行记录，脚本测试不能替代。
