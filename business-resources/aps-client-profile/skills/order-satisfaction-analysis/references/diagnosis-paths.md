# 订单满足率诊断路径

本页是选路参考，不是必做清单，也不是封闭的原因分类。按当前缺口和证据选择分支，可并行、跳过或补充新机制；不要为凑分类展开。根因评级统一见[证据契约](evidence-and-output-contract.md)，指标和模型见[数据契约](metric-and-data-contract.md)。

| 分支 | 常见线索 | 有助于验证的记录与判断 |
|---|---|---|
| 需求变化 | 临时活动、补库、新品、改单、订单集中释放、提报传递晚 | 同 SKU 的提报/订单版本、变更时间、供给冻结及可调整窗口；判断变化是否及时传递、能否被供给吸收。不预设变化一定发生在冻结前或冻结后 |
| 库存 | 总量不足、结构错配、冻结/待检/效期、占用与分配冲突 | 订单需要或分配时点的 SKU×仓库×批次有效库存、占用和释放。当前库存只能说明当前事实，不能直接还原历史 |
| 自产 | 排产未覆盖、设备/人员/物料/工艺约束、换产、质量或入库延迟 | 日计划、实绩、生产单/批次及 `deviation_reason`；匹配缺口 SKU、基地、需要时间和供给关系，区分少产、晚产、已产未入库 |
| 物料 | 到料晚、不合格、BOM/替代/提前期异常、备料配送慢 | 物料需求、承诺、收货、质检、领料及关联生产单；核查库存、替代或调拨是否已弥补。不能把物料数量直接视为订单缺货量 |
| 外协 | 锁定能力不足、排产偏离、爬坡、质量封存、交付晚 | 区分承诺产能、确认排产、实产、到货和转可用；供应商承诺或拟增产能不等于已兑现 |
| 调拨 | 触发/审批晚、调出不足、占用、运输或接收延迟 | 两端需求与库存、调拨单及节点时间；其他仓有货不等于存在可及时调用的供给，追溯同一链不重复计量 |
| 仓配与订单执行 | 审核/信用拦截、分配异常、峰值积压、拣装/过账延迟、客户暂缓 | 订单下发与仓配事件、有效能力和需要窗口；单日峰值不能用月均能力解释。已全量发货但晚到主要属于准交问题 |

## 自产的特别注意

- 日计划首选模型与字段见数据契约；已核验的基地源值可复用，不必每次重查候选。
- 先看当前对象的计划与实际，再按相关记录核查理由；无需强行填满人员、设备、物料等固定原因卡。
- 基地总量达标不能排除局部 SKU 或时点缺货；生产偏差备注是线索，不自动成为订单根因。
- A–K 是生产备注打标字典，不等同上述业务诊断分支。计量和打标规则集中在[报告数据契约](report-contract.md)。

## 口径问题与业务原因分开

发现零发货遗漏、重复、退货/超发、时间归属或维表映射异常时，按受影响范围对账。必要时从汇总追至源记录，不要求所有任务都重做整条加工链审计。未核验部分写入分析边界，不作为业务缺货原因。
