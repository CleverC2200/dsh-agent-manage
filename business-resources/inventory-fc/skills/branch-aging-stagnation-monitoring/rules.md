# 分仓货龄与滞库监控 — 规则与阈值

## 1. 货龄计算与分段

| 项目 | 口径 |
|---|---|
| 批次货龄 | 统计日 − 批次生产日期或统一约定的库存起始日期 |
| 平均货龄 | Σ(批次库存数量 × 批次货龄) ÷ Σ批次库存数量（**加权，禁止简单平均**） |
| 货龄段 | 0-30 天正常 / 31-60 天关注 / 61-90 天重点消化 / 91 天及以上大日期重点 |
| 分段边界 | 全系统统一，**按整数日、含端点**：0–30 / 31–60 / 61–90 / ≥91；第 60 天属 31–60，第 90 天属 61–90，**第 91 天起计入大日期**；边界日不得重复计入两个区间 |
| 大日期 | 分仓货龄 **91 天及以上（即超过 90 天）**；基地为 61 天及以上（超过 60 天），不得混用 |
| 60 天以上 | 61-90 天与 91 天及以上两段之和，是风险区间，不等于全部滞库 |
| 平均货龄阈值 | 健康 < 20 天；预警 61-90 天；严重 ≥91 天 |
| 数据来源 | 平均货龄、大日期、滞库风险以**大数据标准库龄结果为准**，Agent 不重新制定阈值 |

时效规则：货龄以批次快照为准，至少每日一份；无生产日期的批次标注「货龄未知」，不参与货龄排名。

## 2. 库存结构指标

| 指标 | 公式 | 说明 |
|---|---|---|
| 大日期库存量 / 大日期 SKU 数 | 货龄超过 90 天的批次库存量 / 去重 SKU 数 | SKU 数按 SKU 去重，严禁各分仓相加 |
| 滞库风险库存量 / SKU 数 | 大数据标准库龄结果 | 与动销、货龄、计划、库存差额综合判断 |
| 风险库存量 | 大日期库存量 + 滞库风险库存量 | **同一批次重叠时只计一次** |
| 健康库存量 | max(当前可用库存量 − 风险库存量, 0) | 当前可用库存不含在途 |
| 健康库存占比 | 健康库存量 ÷ 当前可用库存量 | 库存为 0 时显示「无库存 / —」，不除零 |
| 各货龄段占比 | 该段库存量 ÷ 当前可用库存量 | 汇总比例先汇总分子分母再计算 |

## 3. 动销口径

- 使用**数量口径**：近 30 日动销量、日均动销、近 30 日实际出库量；**不使用动销率**
- 动销量按数量升序识别动销偏慢对象；动销慢 **不等于** 滞库风险
- 近 30 日动销量 = 0 → 单列「无动销」，先确认是否停产、未上市、替代品切换或统计不适用，不直接判滞库
- 动销数据缺失时：只输出库存与货龄事实，不判断消化速度，不给滞库级别

## 4. 滞库风险判定（必须多指标综合）

滞库风险是综合判断，**不由某一个阈值单独决定**。判断依据：

1. 当前可用库存与库存差额（订单扣减后可供库存口径）
2. 近 30 日动销、日均动销与是否无动销
3. 回顾与展望周转天数
4. 31-60、61-90、91 天及以上库存结构
5. 当前与未来计划消化能力
6. 客户库存信号、活动备货与业务例外

判定输入与输出方向：

| 观察到的组合 | 判断方向 | 必须同时说明 |
|---|---|---|
| 高于目标 + 动销明显偏慢 + 货龄 60 天以上 | 滞库风险偏高 | 具体证据与数据时间 |
| 高于目标 + 动销正常 | 暂不判滞库 | 需持续观察 |
| 高于目标 + 无动销 | 先确认停产品种 / 未上市 / 统计不适用 | 再判断风险 |
| 货龄 91 天及以上但动销正常 | 属大日期处理问题，不等同滞库 | 处理方案需业务确认 |
| 库存不高但货龄长 | 关注结构而非水位 | 结合计划与客户信号 |
| 周转天数高但动销数量正常 | 不判滞库 | 说明两个口径差异 |

业务维护规则包中的滞库关注阈值属受控参数；未维护时只做方向性提示，不自行编造阈值。

## 5. 重点对象筛选与排序

排序：风险等级 → 货龄 → 库存量。必纳入：91 天及以上批次、滞库风险 SKU、用户点名对象、同时存在缺货或无动销的对象。

## 6. 原因线索（最多 5 条，标注证据状态）

| 方向 | 子原因 | 触发条件 | 证据状态 |
|---|---|---|---|
| 需求端 | 动销明显下降 | 近 30 日动销显著低于计划或历史 | 有支撑未验证 |
| 需求端 | 客户侧库存积压 | 客户库存信号显示高库存 | 有支撑未验证 |
| 供给端 | 调拨集中到货 | 近期在途或入库集中 | 有支撑未验证 |
| 供给端 | 计划量偏高 | 出货计划高于实际动销 | 推测（有计划数据时为有支撑未验证） |
| 库存端 | 批次集中入库 | 批次生产日期集中 | 已验证（有批次数据时） |
| 库存端 | 产品结构变化 | 替代品、新品切换导致老 SKU 动销下降 | 有支撑未验证 |
| 业务端 | 活动备货或节令切换 | 活动窗口或节令产品标记未生效 | 数据缺失（标记缺失时） |
| 数据端 | 库龄结果或动销未接入 | 库龄结果缺失或动销缺失 | 数据缺失 |

不得仅凭货龄或仅凭库存高判定滞库，不做责任判定。

## 7. 消化方向建议（标注【待人工确认】与建议责任角色）

| 情形 | 方向建议 | 建议责任角色 |
|---|---|---|
| 91 天及以上大日期 | 优先安排去化，处理方案与可售性由品控与业务确认 | 分仓运营经理 |
| 60-90 天重点消化区间 | 优先出库、控制同 SKU 新增补货 | 分仓计划员 |
| 高库存低动销 | 转运营安排去化，控制新增补货 | 分仓运营经理 |
| 无动销 | 先确认品种状态（停产 / 未上市 / 替代 / 统计问题） | 平台计划员 |
| 多分仓均有同类风险 | 评估跨分仓调剂或基地侧消化 | 区域计划 |
| 客户侧库存高 | 核对客户提报与分仓补货节奏是否冲突 | 分仓计划员 |
| 活动备货或节令产品 | 标注需业务确认，不直接判异常 | 分仓运营经理 |

涉及报废、降价、清库等重大决策**必须业务确认**，P1 不给结论、不给金额测算。

## 8. 输出字段清单

分仓 / 仓库 / 品类 / 物料组 / SKU / 批次 / 数量 / 货龄 / 货龄段 / 当前可用库存 / 库存差额 / 近 30 日动销 / 是否无动销 / 风险类别（大日期 / 滞库风险 / 健康）/ 证据状态 / 状态【待人工确认】。

## 9. 数据完整性校验

必备字段：分仓、SKU 或批次、批次数量、货龄或生产日期、数据截止时间。缺字段时按指标分别处理，**不整行作废**：该指标缺数按 0 参与并标注，两个输入都缺的行单列；其余指标照常输出。

可选字段缺失时：无动销 → 不判断消化速度与滞库级别；无目标 → 不判断高于目标；无库龄结果 → 不输出滞库风险与大日期结论，只给可判断部分。

## 10. P2 承接

大日期专项台账与每月锁定、待办 / 事件闭环、历史反馈闭环、责任判定与协同角色推荐、升级审批、30 日超龄推演、费用与报废评估。
