# 未来 N 日预计超龄 Skill（分仓）

## 参考资源（按需加载）
- **先加载 `branch-policy` Skill**（共享规范：指标口径、数据边界、取数契约、证据与行动边界、输出规范；内部包，不单独回答用户）。涉口径、排名、取数、分析、报告之前必读。

- **`rules.md`**：推演口径、先进先出扣减规则、窗口与输出排序规则 → 第 3、4、5 步前读取
- **branch-policy 数据边界**：数据边界与分仓阈值区分 → 第 7 步前读取
- **branch-policy 证据与行动边界**：证据状态与行动边界（推演按【有支撑未验证】处理） → 第 2 步前确认
- **branch-policy 输出规范**：输出规范 → 第 8 步前读取
- **branch-policy 取数契约**：取数与知识查询契约（cube 查询模板、上卷铁律、权限、降级） → 取数前必读
- 与 `branch-aging-stagnation-monitoring` 配合：先看当前货龄结构，再看未来窗口新增

## 目标

按批次推演未来 7 / 14 日内将超过 **90 天**（分仓大日期阈值）货龄的库存，输出新增超龄对象、数量与批次，并明确说明推演窗口、是否扣减预计消耗、是否排除当前已超龄库存。

## 触发场景

- 「未来 7 日哪些库存会超龄」「未来 14 日新增多少大日期」
- 「未来 7 日预计超龄是什么意思」「怎么算的」
- 「当前 91 天及以上和未来 7 日预计超龄有什么区别」
- 日报 / 大日期报告中的未来窗口段

## 输入契约

| 输入项 | 说明 | 必填 |
|---|---|---|
| 分析范围 | 分仓、区域、品类、物料组、SKU、批次 | 是 |
| 批次数据 | 批次数量、生产日期或库存起始日期、当前货龄 | 是 |
| 消耗数据 | 窗口内预计出库 / 订单（优先）；近 30 日动销或日均出库（其次） | 是（缺失则标注未扣减） |
| 推演窗口 | 7 日 / 14 日（30 日暂不支持，属 P2） | 是 |
| 当前已超龄清单 | 用于排除，避免重复计入 | 是 |
| 数据截止时间 | 批次与消耗数据各自时间 | 是 |

**不扣减未来生产入库或未来调拨到货。** 窗口未指定时不擅自扩展为 30 日。

## 执行步骤

### 第 1 步：确认批次与消耗口径
确认批次粒度、生产日期完整性、消耗数据时间范围与来源（预计出库 / 订单 / 近 30 日动销），记录窗口（7 日或 14 日）。

### 第 2 步：排除当前已超龄库存
先取当前货龄 ≥91 天的批次清单，本次推演**不重复计入**，并在输出中明确说明。

### 第 3 步：逐批推演
对当前货龄 ≤ 90 天的批次：
1. 计算窗口结束时货龄 = 当前货龄 + 窗口天数
2. 按先进先出扣减窗口内预计消耗（优先预计出库 / 订单，其次近 30 日日均出库 × 窗口天数）
3. 扣减后仍有剩余且窗口结束时货龄 ≥91 天 → 计入「未来 N 日预计超龄」
4. 无消耗数据时按未扣减测算，并显式标注「本次未扣减预计消耗（保守口径）」

### 第 4 步：汇总与排序
按分仓 / 品类 / 物料组 / SKU / 批次汇总数量与占比；排序：预计超龄日期（升序）→ 数量（降序）。

### 第 5 步：与当前 91 天及以上区分说明
明确写出：当前 91 天及以上是存量风险，未来 N 日预计超龄是新增风险，两者**不能相加**。61-90 天重点消化区间单独列出，不与本表相加。

### 第 6 步：生成建议
对预计超龄对象给方向性建议（提前消化、优先出库、控制同 SKU 新增补货、关注动销与客户信号），标注【待人工确认】与建议责任角色；不做责任判定，不创建专项。

### 第 7 步：整理数据边界
窗口、是否扣减预计消耗、扣减依据、是否排除当前已超龄、批次与消耗数据时间、不可判断项。

### 第 8 步：形成交付结果
按 **branch-policy 输出规范** 输出；推演结果标注为**预警**，按【有支撑未验证】处理，不写成既定事实。

## 规则与阈值

详细规则见 `rules.md`。核心摘要：

- 粒度：分仓 + SKU + 批次；先进先出扣减
- 阈值：分仓 91 天（基地 60 天，不得混用）
- 窗口：P1 支持未来 7 日与 14 日；30 日属 P2
- 必须排除当前已超龄库存，不与存量相加
- 不扣减未来生产入库与未来调拨到货
- 无消耗数据时按未扣减测算并标注保守口径
- 推演属预警，按【有支撑未验证】标注，不直接创建事件（P2）

## 默认交付

1. 核心结论（未来 7 / 14 日预计新增超龄批次与数量）
2. 推演口径（窗口、扣减依据、是否排除当前已超龄）
3. 按分仓 / 品类汇总
4. 预计超龄清单（分仓 / 仓库 / SKU / 批次 / 数量 / 当前货龄 / 预计超龄日期）
5. 与当前 91 天及以上、60-90 天区间的关系说明
6. 建议与待确认（含建议责任角色）
7. 数据边界

## 边界与禁止动作

- 不与当前 91 天及以上相加；不把推演结果说成既定事实
- 不扣减未来生产入库与调拨到货；不做 30 日窗口
- 不创建大日期专项、不定责、不推荐责任人（P1）
- 不用基地 60 天阈值；不承诺处理结果与到货时间
