# 未来 N 日预计超龄（分仓） — 规则与阈值

## 1. 定义

未来 N 日预计超龄表示：当前尚未达到风险货龄的批次，按当前批次货龄与可用消耗数据推演，在未来 N 日窗口内预计达到**分仓大日期阈值 90 天**的新增库存。

```text
未来 N 日预计超龄
= 当前货龄 + N ≤ 90 天 的批次
  按先进先出扣减窗口内预计消耗后仍有剩余的库存
  且窗口结束时 当前货龄 + N ≥91 天
  且当前不属于已超龄库存
```

- **分仓阈值 90 天**；基地为 60 天，两套口径不得混用
- 只统计**新增**部分，当前已超龄库存不重复计入
- 属预警推演，不是既定事实

## 2. 推演窗口

| 窗口 | P1 是否支持 | 说明 |
|---|---|---|
| 未来 7 日 | 支持 | 用户指定后使用；未指定时不擅自扩展 |
| 未来 14 日 | 支持 | 同上 |
| 未来 30 日 | **不支持（P2）** | 明确说明当前不支持并给替代查看 |

窗口内自然日按日历日计算；跨月时不影响货龄推算，但需在数据说明中标注窗口起止日期。

## 3. 消耗扣减规则

| 优先级 | 消耗依据 | 说明 |
|---|---|---|
| 1 | 窗口内预计出库 / 订单 | 有则优先使用，口径需标注 |
| 2 | 近 30 日日均出库量 × 窗口天数 | 无预计出库时使用 |
| 3 | 无消耗数据 | 按**未扣减**测算，标注「保守口径，未扣减预计消耗」 |

规则要点：

1. 扣减按**先进先出**：先扣最早批次，扣完再扣下一批次
2. **不扣减未来生产入库与未来调拨到货**（避免高估消化能力）
3. 扣减只作用于窗口内的预计消耗，不改变当前库存快照
4. 同一批次不得被重复扣减；已满足订单占用的部分不重复扣减
5. 消耗数据口径与时间必须在数据说明中写明

## 4. 排除与叠加规则

| 对象 | 是否计入本推演 | 说明 |
|---|---|---|
| 当前货龄 ≥91 天 | 否 | 属存量风险，另行输出，**不得相加** |
| 当前货龄 60-90 天 | 是（若窗口结束时 ≥91 天） | 61-90 天是重点消化区间，单独列出 |
| 当前货龄 < 60 天 | 是（若窗口结束时 ≥91 天） | 可能出现在 14 日窗口 |
| 未来生产入库 / 调拨到货 | 否 | 不参与扣减，也不计入新增超龄 |

关系说明（输出中必须写清）：当前 91 天及以上是**已进入风险区间的存量**；未来 N 日预计超龄是**当前尚未超龄、预计在窗口内进入风险区间的新增**。两者不能相加。

## 5. 汇总、排序与输出字段

汇总：按分仓 / 品类 / 物料组 / SKU / 批次汇总数量与占比；占比分母为当前可用库存量。SKU 数按 SKU 去重，严禁各分仓相加。

排序：预计超龄日期（升序）→ 数量（降序）。

输出字段：分仓 / 仓库 / 品类 / 物料组 / SKU / 批次 / 批次数量 / 当前货龄 / 窗口天数 / 预计超龄日期 / 扣减依据 / 扣减后剩余 / 是否属于新增 / 证据状态 / 状态【待人工确认】。

## 6. 建议方向（标注【待人工确认】与建议责任角色）

| 情形 | 方向建议 | 建议责任角色 |
|---|---|---|
| 7 日内即将超龄且数量较大 | 优先出库或安排去化，控制同 SKU 新增补货 | 分仓运营经理 |
| 14 日窗口内集中超龄 | 提前安排消化节奏与库内调剂 | 分仓运营经理 + 分仓计划员 |
| 预计超龄与缺货并存 | 先核查规格、批次与需求匹配，避免一边补一边超龄 | 分仓计划员 |
| 消耗数据缺失（保守口径） | 建议补齐消耗数据后重算，避免高估新增 | 数据负责人 |
| 客户侧可承接 | 结合客户信号评估去化方向 | 分仓计划员 + 区域计划 |

**不给到货时间、不承诺处理结果、不创建专项或事件。**

## 7. 数据完整性校验

必备字段：分仓、SKU 或批次、批次数量、当前货龄或生产日期、推演窗口、当前已超龄清单。缺字段时按指标分别处理，**不整行作废**：该指标缺数按 0 参与并标注，两个输入都缺的行单列；其余指标照常输出。

缺失处理：无消耗数据 → 按未扣减测算并标注；无批次数据 → 不推演并说明；无当前已超龄清单 → 明确说明本次未排除存量，结果可能重复计入，不给确定结论。

## 8. 常见错误

| 错误做法 | 正确做法 |
|---|---|
| 未来 7 日预计超龄 = 当前 91 天及以上 + 未来 7 日新增 | 只统计当前尚未超龄、预计在窗口内进入 90 天的新增部分 |
| 扣减未来生产入库或调拨到货 | 不扣减未来入库，避免高估消化能力 |
| 无消耗数据时按 0 消耗却不说 | 按未扣减测算并标注保守口径 |
| 用基地 60 天阈值推演分仓 | 分仓一律用 90 天 |
| 把推演结果说成一定会超龄 | 标注为预计与预警，按【有支撑未验证】处理 |

## 9. P2 承接

30 日窗口推演、未来货龄风险转入待办 / 事件、大日期专项台账与锁定、责任判定与协同角色推荐、升级审批。
