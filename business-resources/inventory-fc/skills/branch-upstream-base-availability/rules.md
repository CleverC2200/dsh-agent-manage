# 分仓上游基地可供信号 — 规则与阈值

## 1. 基地可供信号的三个输入口径

| 输入口径 | 含义 | 口径要求 | 禁止 |
|---|---|---|---|
| 基地当前可用库存 | 基地当前可用于对外供给的库存 | 当前快照，须标数据时间；约 6 小时刷新 | 把基地可用库存直接等同于某分仓已锁定可得库存 |
| 基地调拨在途（基地在途未入库） | 基地侧已下达但尚未完成入库的供给 | 与分仓侧「调拨中」区分标注；不计入基地当前可用库存 | 把基地在途未入库当作分仓已入库库存；把基地在途与分仓调拨中混为一个数 |
| 未来 7 日排产 | 基地未来 7 日的计划产出（SKU 与数量） | 按 SKU 输出，须标明窗口与数据时间 | 当作已入库库存、当作已承诺库存、当作某分仓已锁定可得库存 |

三口径**分开列出、不合并、不相加**成一个「基地可供总量」；需要给综合判断时用第 3 节承接判断表达，不用一个合计数字代替。

**未来排产定性（铁律）**：未来排产是**计划供给**，既不是已承诺库存，也不是某分仓已锁定可得库存；排产能否落到某分仓，还需结合基地库存、其他分仓需求、调拨规则与到货安排确认，本 Skill 不承诺到货时间。

数据缺失处理：基地可用库存缺失时标注「基地可用库存缺失，无法判断承接能力」，该基地 + SKU 的承接结论给「待确认」而非结论性判断（基地可供属**供给信号**，缺失不等于 0，与库存/目标缺数按 0 的口径区分）；在途未入库缺失时标注「未纳入基地在途，承接判断可能偏保守」；未来排产缺失时只按当前库存与在途判断，并标注「未纳入未来 7 日排产」。

## 2. 分仓需求侧口径

| 指标 | 公式 | 说明 |
|---|---|---|
| 缺货量 | max(0, 备单中剩余未占用量 − 当前可用库存量) | 统一按正数表示；禁止用「订单总量 − 当前库存」近似 |
| 库存差额（净额，主口径） | 订单扣减后可供库存 − 目标库存量；正数高于目标、负数低于目标；汇总直接相减、允许正负抵消 |
| 低于目标量（补货用） | max(0, 目标库存量 − 订单扣减后可供库存量) | 基准是订单扣减后可供库存，不是物理现库存 |
| 建议补货量 | max(0, max(缺货量, 低于目标量) − 调拨中) | 订单缺口先独立计算，调拨中只在最终建议量统一扣减，结果不小于 0 |
| 调拨中 | 已下单未发货量 + 已发货未入库量 | 只含仍会到达分仓的有效调拨，不含已取消、已完成入库或失效调拨；同一批供给只计一次 |

**先算后汇总（铁律）**：缺货量与建议补货量都必须**先按 分仓 + SKU 算，再汇总**；禁止先汇总总量再算，禁止对下级结果取平均。上卷时个数量 SUM，SKU 个数按去重计数，分母为 0 时显示「—」。

在途拆分（铁律）：分仓口径 = 当前可用库存，**不含在途**；在途必须分为**已下单未发货**与**已发货未入库**两类，**禁止合并**为一个不可解释的在途量。

数据缺失处理：目标库存或生效计划缺失时不给精确库存差额与建议补货量，只按缺货量给参考量并标注「目标缺失，本量仅按缺口测算」；调拨中缺失时按 0 参与但必须标注「本次未扣除调拨中，实际建议量可能更低」；需求侧数据缺失则不进入承接判断，说明缺失范围。

## 3. 承接判断（可供 vs 需求）

按 **基地 + SKU** 比对基地可供与**权限范围内**分仓需求合计：

```text
缺口量 = 权限范围内分仓需求合计 − 基地当前可用库存（分仓侧在途不重复抵扣基地供给）
```

| 承接判断 | 判定 | 输出要求 |
|---|---|---|
| 可承接 | 基地当前可用库存可覆盖权限范围内分仓需求合计 | 说明可承接对象与覆盖比例，标注数据时间 |
| 部分可承接 | 基地当前可用库存只能覆盖部分需求，需靠基地在途未入库或未来 7 日排产补齐 | 给出缺口量与缺口对象；排产只能表述为计划供给信号 |
| 不足以承接 | 基地当前可用库存与在途未入库合计仍低于需求合计 | 给出缺口量、竞争分仓清单与协同方向 |

竞争关系（必须显式说明）：同一基地资源在多个分仓之间存在竞争，**基地可供不等于单一分仓可得**；当多个分仓需求同时指向同一基地 + SKU 时，必须列出竞争分仓与各自缺口，不得只对其中一个分仓给「可承接」。

排序口径：**缺口量降序 → 需求临近度（未来 7 日计划需求在前）**；不使用金额排序；分母为 0 显示「—」。

## 4. 冲突判定规则

| 现象 | 判定 | 处理 |
|---|---|---|
| 基地可用库存高，但分仓仍缺货 | 可能为规格/批次/提货点不匹配，或需求被其他分仓占用，或调拨未下单 | 核对基地 + SKU 规格口径与提货点归属；列出竞争分仓；确认是否已下调拨单 |
| 未来 7 日有排产，但当前缺货 | 排产是未来计划供给，不能解决当前缺口 | 按当前可用库存与在途判断承接；提示排产窗口与需求临近度，不承诺到货时间 |
| 基地在途未按计划入库 | 在途未入库使当前可供被高估 | 以当前可用库存为准重估承接；标注「基地在途未按计划入库」并给验证建议（证据状态最高为【推测】或【有支撑未验证】） |
| 同一基地 + SKU 被多个分仓同时申请 | 供给竞争 | 按缺口量与需求临近度排序，输出竞争清单，由业务确认分配 |
| 基地可用库存低于需求合计且无排产补充 | 供给不足 | 输出「不足以承接」；协同方向含跨基地替代评估（属业务确认） |
| 需求侧数据缺失 | 无法比对 | 终止该对象承接判断，说明缺失项 |

## 5. 优先级建议规则

优先顺序（同时满足越多项越优先）：

1. **存在缺货**（缺货量 > 0）；
2. **调拨中不足**（调拨中不足以覆盖缺货与库存差额的较大值）；
3. **未来需求较近**（未来 7 日计划需求靠前）。

输出要求：给出优先级分仓清单与依据（缺货量、库存差额、调拨中、未来计划），并写明本次排序口径。**不承诺到货时间、不给到货日期、不锁定分配量**；分配方案由业务确认。

## 6. 原因线索（最多 5 条，标注证据状态）

| 方向 | 子原因 | 触发条件 | 证据状态 |
|---|---|---|---|
| 供给端 | 基地可用库存不足 | 基地当前可用库存 < 权限范围内分仓需求合计 | 已验证 |
| 供给端 | 基地在途未按计划入库 | 基地在途未入库存在但当前可供未同步增加 | 推测 |
| 供给端 | 未来排产尚未落地 | 缺货当前存在且基地未来 7 日有排产 | 有支撑未验证 |
| 需求端 | 多分仓需求竞争 | 同一基地 + SKU 下多个分仓需求同时大于 0 | 已验证 |
| 匹配端 | 规格/批次/提货点不匹配 | 基地库存高但分仓仍缺货 | 有支撑未验证 |
| 流程端 | 调拨未下单 | 存在缺口且调拨中为 0 或明显偏低 | 有支撑未验证 |
| 数据端 | 关键数据缺失 | 基地可用库存、排产或需求侧字段缺失 | 数据缺失 |

标注方式：结论后用方括号标注，例如「原因线索：基地可用库存低于权限范围内分仓需求合计【已验证】」。**本回答内证据状态标记合计不超过 3 处**；【推测】不得写成结论，必须给验证建议。

## 7. 协同建议方向

| 协同对象 | 建议方向 | 优先级 | 状态 |
|---|---|---|---|
| 基地协同人员 | 反馈基地可用库存、在途未入库与未来 7 日排产能否承接分仓需求 | 高 | 【待人工确认】 |
| 平台计划员 | 复核需求侧口径与计划完整性，协调基地资源分配节奏 | 中 | 【待人工确认】 |
| 分仓计划员 | 核对缺货量与建议补货量构成，确认调拨下单状态与到货跟进 | 高 | 【待人工确认】 |
| 区域计划 | 评估跨分仓调配与跨基地替代可行性 | 中 | 【待人工确认】 |

**只给角色不给姓名**（P1）；建议格式为「建议内容 + 建议理由 + 优先级 + 建议责任角色 + 状态【待人工确认】」，多角色写「牵头 / 协同」；建议总数 ≤5 条，短期优先。

## 8. 输出字段清单

| 字段 | 说明 |
|---|---|
| 基地 | 供给主体，须在权限范围内 |
| 提货点 | 有提货点数据时输出；缺失时按分仓整体并标注 |
| 品类 | 汇总与筛选维度 |
| SKU | 比对最小对象 |
| 基地可用库存 | 当前快照 |
| 基地在途未入库 | 与基地可用库存分开列示 |
| 未来 7 日排产 | 标明计划供给属性与窗口 |
| 分仓需求 | 缺货量、建议补货量（先按 分仓 + SKU 算再汇总） |
| 调拨中 | 已下单未发货量 + 已发货未入库量，分开与合计均可但须可解释 |
| 承接判断 | 可承接 / 部分可承接 / 不足以承接 |
| 证据状态 | 【已验证】/【有支撑未验证】/【推测】/【数据缺失】 |
| 状态 | 统一【待人工确认】 |

输出约束：不出现表名、字段名、工具名；数量带单位（件），比率保留 1 位小数，缺失不显示为 0。

## 9. 数据完整性校验

必备字段：基地、SKU、基地可用库存、分仓需求（缺货量或建议补货量至少一项）、数据截止时间。**缺字段时不整行作废**：该指标缺数按 0 参与并标注，两个输入都缺的行单列，不用相近指标替代。

可选字段缺失时：无提货点 → 只做分仓级判断；无基地在途未入库 → 承接判断按当前可用库存，标注偏保守；无未来 7 日排产 → 只判断当前供给，标注未纳入排产；无调拨中 → 按 0 参与但必须标注未扣除。

补充校验：数据时间不一致时分别标注基地资源（约 6 小时刷新）与分仓库存与订单（约 2 小时）各自时间，以最接近分析时点的为主并建议在时间一致时复核；数据刷新失败或过期时展示最近有效快照并标注过期；覆盖不足时只输出可判断部分。

## 10. P2 承接

自动创建调拨单、到货时间承诺与到货计划锁定、跨基地替代方案审批、基地资源无法承接紧急补货的事件创建与升级闭环、责任角色推荐、历史反馈与样本回流。
