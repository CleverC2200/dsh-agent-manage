# 分仓库存指标口径与问数路由（指标能力矩阵）

版本：V1.0-261010
数据来源：《分仓库存运营监控 Agent 固化规则包 V1.0-260915》《分仓库存运营监控 Agent 数据与计算口径说明 V0.4-260828》《分仓库存Agent右侧问答指标能力与引导规则包 V1.0-260924》《分仓库存Agent-去DMS下单功能设计文档 V1.3-260929》。
冲突处理：指标定义、公式、计划版本优先级、权限与人机边界以**固化规则包 V1.0** 为准；数据说明 V0.4 与固化规则包不一致时按固化规则包执行（已知差异见第十三节）。

P1 边界：做问数、口径解释、看板分析、固定报告、库存差额与周转、缺货、补货需求、货龄与大日期、未来 7/14 日预计超龄、基地可供信号、客户库存信号、补货确认与去 DMS 下单的解释与状态查询（对话侧不执行写入）。
P2 承接：待办与事件闭环、历史反馈闭环、正式定责与责任角色推荐、升级审批、30 日超龄推演、大日期专项台账与锁定。

本 Agent 只回答**分仓口径**；基地口径（货龄 61 天及以上大日期、基地月度需求计划版本等）见基地库存 Agent，遇到基地口径问题说明归属并给分仓侧可比信息。

## 一、库存规模与库存水位类

| 指标 | 定义与公式 | 支持维度 | 时间 |
|---|---|---|---|
| 现库存 | 分仓仓库物理库存水位 | 分仓/区域/品类/物料组/SKU/批次 | 日快照 |
| 当前可用库存（看板「当前库存」） | 分仓当前可用于发货与订单满足的库存，**不含在途**；看板库存水位主值 | 分仓/区域/品类/物料组/SKU | 日快照（约 2 小时刷新，至少每日一份快照） |
| 在途量 | 已下单未发货量 / 已发货未入库量；**两个数分开显示，禁止合并为一个数** | 分仓/基地/品类/物料组/SKU/调拨单 | 日快照（约 2 小时） |
| 调拨中 | 已下调拨订单未发货量 + 已下单发货在途量（已发货未入库）；只含仍会到达分仓的有效调拨，不含已取消、已完成入库或失效调拨；同一批供给只能计入一次 | 分仓/基地/品类/物料组/SKU | 日快照 |
| 订单扣减后可供库存 | 当前可用库存 − 备单中剩余未占用量（Σ 订单层还需满足量）；可为负数，负数用于解释缺货原因 | 分仓/品类/物料组/SKU | 日快照 |
| 目标库存 / 安全库存 | 安全库存周转天数 × 日均出货计划；安全库存周转天数 = 已生效补货周期 + 3 天备货期；**日均出货计划 = 基准出货计划 ÷ 基准月自然日数**，基准出货计划按计算日切换（1–20 日用本月出货计划、21 日及以后用次月出货计划），出货计划导入版优先、无导入用系统版。目标库存结果与补货周期、基准月份、目标版本一并展示 | 分仓/品类/物料组/SKU | 补货周期、出货计划或基准月份变化后重算（含每月 21 日基准切换）；补货周期未配置时默认 7 天 |
| 库存差额 | max(0, 目标库存量 − 订单扣减后可供库存量)；**基准是订单扣减后可供库存，不是物理现库存** | 分仓/品类/物料组/SKU | 当前 |
| 健康库存占比 | 健康库存量 ÷ 当前可用库存量；健康库存量 = max(当前可用库存量 − 风险库存量, 0)；风险库存量 = 大日期库存量 + 滞库风险库存量（**同一批次重叠只计一次**）。当前可用库存为 0 时显示「无库存」或「—」 | 分仓/区域/品类/物料组/SKU | 当前 |
| 库存结构符合率 | 纳入范围：当前可用库存 ≠ 0 且 日均发货量 ≠ 0 的 SKU；单品偏差 dᵢ = ABS(库存ᵢ ÷ 总库存 − 日均发货ᵢ ÷ 总日均发货)；**库存结构符合率 = 1 − Σdᵢ ÷ 2**；无纳入 SKU 时显示「—」。指标只反映库存结构与发货结构的匹配度，**不含缺货与滞销**（这两类 SKU 被排除），须与缺货量、无动销库存同时看 | 分仓/区域/品类/物料组（按同一 SKU 集合整体计算，不支持按 SKU 单点解释） | 当前（依赖近 30 日日均发货） |

同义词：库存水位 / 现库存 / 库存量 → 需先区分「现库存」「当前可用库存」「订单扣减后可供库存」；安全库存 → 业务口语常与目标库存混用，按目标库存口径解释并说明二者关系。

## 二、周转与效率类

| 指标 | 定义与公式 | 说明 |
|---|---|---|
| 近 30 日日均出库量 | 近 30 日实际出库量 ÷ 30 | 回顾周转的分母 |
| 回顾周转天数 | 当前可用库存量 ÷ 近 30 日日均出库量 | 看历史实际出库速度，分母为 0 时显示「—」 |
| 本月剩余计划出货量 | max(本月出货计划 − 本月已发货量, 0) | 展望周转输入 |
| 次月日均出货量 | 次月出货计划 ÷ 次月自然日数 | 展望周转输入 |
| 展望 30 日日均出货量 | [本月剩余计划出货量 + 次月日均出货量 × (30 − 本月剩余自然日数)] ÷ 30 | 未来需求口径 |
| 展望周转天数 | (当前可用库存量 + 有效在途量) ÷ 展望 30 日日均出货量 | 结合计划与在途的覆盖能力；必须标明含在途 |
| 目标周转天数 | 前端配置（cube），月日均计划量 = 分仓未来 30 日日均出货计划；与目标库存同源 | 汇总用汇总分子 ÷ 汇总分母，禁止对 SKU 天数取平均 |

汇总规则：天数类与比率类一律「汇总分子 ÷ 汇总分母」，禁止对下级天数或比率取简单平均。周转天数高 ≠ 销量最少，两者不能互相替代排序。

## 三、货龄与结构类

| 指标 | 定义 | 阈值与口径 |
|---|---|---|
| 批次货龄 | 统计日 − 批次生产日期或统一约定的库存起始日期 | 批次级 |
| 平均货龄 | Σ(批次库存数量 × 批次货龄) ÷ Σ批次库存数量 | 加权，禁止简单平均；以大数据标准库龄结果为准 |
| 货龄分段（分仓四段） | 0-30 天正常 / 31-60 天关注 / 61-90 天重点消化 / 91 天及以上大日期重点 | **分仓阈值，整数日含端点（0–30 / 31–60 / 61–90 / ≥91）；第 60 天属 31–60、第 90 天属 61–90、第 91 天起计入大日期，边界日不得重复计入两个区间** |
| 平均货龄健康阈值（分仓） | 健康 < 20 天；预警 61-90 天；严重 ≥91 天 | 与基地口径（60 天）不同，不得混用 |
| 大日期库存量 / 大日期 SKU 数 | 货龄超过分仓阈值的批次库存量与其去重 SKU 数 | **分仓 > 90 天**；基地为 > 60 天，回答时须标明平台口径 |
| 60 天以上库存量 | 61-90 天与 91 天及以上两段之和 | 是风险区间，不等于全部滞库 |
| 滞库风险库存量 / SKU 数 | 大数据标准库龄结果，综合库存、动销、货龄、计划判断 | Agent 不自行制定风险阈值 |
| 未来 7 日 / 14 日预计超龄 | 当前尚未达到风险货龄，按批次货龄与可用消化数据推演，未来 N 日内预计达到 91 天阈值的**新增**库存 | 必须排除当前已超龄库存；未扣减未来消耗时必须标注保守口径 |

## 四、订单与履约类

| 指标 | 定义与公式 | 说明 |
|---|---|---|
| 备单量 | 备单中订单需求量（扣除已占用后的剩余未占用量参与缺货计算） | 备单完成状态已占用库存并下发 WMS，不得再次计入缺货需求 |
| 订单还需满足量（订单层） | max(该订单需求量 − 该订单已占用量, 0) | 只取备单中订单；改单 / 超额占用出现负数按 0；需求量与占用量必须同源同状态；若数据服务已把部分订单量扣减到可用库存，只扣尚未扣减的部分 |
| 备单中剩余未占用量（分仓 + SKU 层） | Σ 订单还需满足量 | 逐单相加，不再截零 |
| 当前未发货订单量（看板「客户订单」主值） | 备单中未发货量 + 备单完成未发货量 | 剔除已作废、已取消、短拨订单 |
| 缺货量（当前订单缺货） | 三层：①订单层 还需满足量 = max(需求量 − 该订单已占用量, 0)；②分仓+SKU 层 = max(Σ 还需满足量 − 当前可用库存量, 0)；③分仓层 = Σ 各 SKU 缺货量（不二次截零） | **统一按正数表示**；可用库存只在②减一次，不能摊到订单层；禁止用「订单总量 − 当前库存」近似 |
| 缺货 SKU 数 | 缺货数量大于 0 的 SKU 数 | COUNT DISTINCT |
| 缺货订单数 | 存在缺货的订单张数 | 与缺货量分开统计 |
| 本月已发货订单满足率（M2 主指标） | 本月已发货订单量 ÷ 本月有效订单总量，**订单张数口径** | 与看板展示一致 |
| 数量满足率（辅助） | 本月已发货量 ÷ 本月有效订单需求量 | 可在明细或解释中提供，**不得替换主 KPI** |
| 当前备单满足率 | 已备量 ÷ 当前备单量 | 与上面的满足率口径不同，必须分别标注 |
| 缺货订单占比 | 缺货订单数 ÷ 总有效订单张数 | 分母为 0 显示「—」 |

## 五、补货与计划类

| 指标 | 定义与公式 |
|---|---|
| 安全库存周转天数 | 已生效补货周期 + 3 天备货期（补货周期按分仓配置，未配置默认 7 天） |
| 日均出货计划 | **基准出货计划 ÷ 基准月自然日数**；基准出货计划：计算日 1–20 日用本月出货计划、21 日及以后用次月出货计划（本月计划用本月自然日数、次月计划用次月自然日数）；出货计划导入版优先，无导入用系统版 |
| 目标库存量 | 安全库存周转天数 × 日均出货计划 |
| 库存差额（净额，主口径） | 订单扣减后可供库存 − 目标库存量；正数高于目标、负数低于目标；汇总直接相减、允许正负抵消 |
| 低于目标量（补货用） | max(0, 目标库存量 − 订单扣减后可供库存量) |
| **建议补货量** | max(0, max(缺货量, 低于目标量) − 调拨中)；**订单缺口先独立计算，调拨中只在最终建议量统一扣减，结果不小于 0** |
| 补货 SKU 数 | 建议补货量 > 0 的 SKU 数 |
| 紧急补货量 / 紧急补货 SKU 数 | 同时满足「存在缺货」且「当前库存低于目标库存」的 SKU 建议补货量之和 / SKU 数 |
| 实际补货量 | 业务确认后准备提交的数量；可低于、等于或高于建议量，调整必须记录原因；**不覆盖系统建议量** |
| 本月/次月出货计划 | 本月出货计划(SKU) = 上月分仓实际出货量(SKU) × (1 + 分仓整体增长率)；次月出货计划(SKU) = 本月出货计划(SKU) × (1 + 分仓整体增长率) |
| 本月/次月调拨计划 | 本月调拨计划 = max(0, 目标库存量 − 当前可用库存量 + 本月出货计划)；预计本月末库存 = 当前可用库存量 + 本月调拨计划 − 本月出货计划；次月调拨计划 = max(0, 安全库存周转天数 × 次月日均出货量 − 预计本月末库存 + 次月出货计划) |
| 分仓整体增长率 | 目标环比增长率 × 40% + 历史同期增长率 × 40% + 近 3 个月平均增长率 × 20%；是**增长率**，实际倍数为 1 + 增长率；由大数据按分仓辐射客户月度目标金额总额计算，**不按 SKU 拆金额目标、不做金额到件数换算**；任一必要目标缺失时必须标记数据不完整，不得把缺失当 0 |

计划版本与来源优先级（固化，按「分仓 + 目标月份」整体确定，不按 SKU 混用）：

```text
目标月份存在月初版本 → 使用月初版本
目标月份不存在月初版本 → 使用滚动版本
选定版本存在完整有效人工计划 → 使用人工提报
选定版本不存在完整有效人工计划 → 使用 BI 计划
```

规则：人工计划缺 SKU 时标记「人工计划不完整」，不自动按 SKU 回退 BI；计划量整行为空或 0 时不形成有效提报，业务明确填 0 视为有效 0；页面临时修改只形成预览，保存或导入后才形成人工计划。

## 六、基地可供与客户信号类（分仓特有）

| 指标 | 定义 | 边界 |
|---|---|---|
| 基地可供信号 | 基地当前可用库存 + 基地调拨在途 + 未来 7 日排产结果 | 未来排产是**计划供给**，不是已承诺库存，也不是某分仓已锁定可得库存 |
| 分仓需求与基地供给冲突 | 分仓缺货/补货需求与基地可供、其他分仓需求之间的不足或竞争关系 | 没有分仓需求匹配关系时不给到货承诺 |
| 客户库存信号 | 分仓覆盖客户或提货点的最新库存提报或库存状态信号 | 不是全量、实时、准确的客户库存主账；未覆盖客户不得外推 |

## 七、上卷与汇总铁律

| # | 规则 |
|---|---|
| 1 | **可加和量**（库存、订单量、计划量、出库量）：逐级 SUM，批次 → SKU → 物料组 → 品类 → 分仓 → 区域/全国 |
| 2 | **比率 / 天数类**（周转天数、满足率、健康库存占比、增长率）：汇总分子 ÷ 汇总分母，禁止对下级比率或天数取平均 |
| 3 | **缺货与补货类**：三层计算——订单层 `max(需求量 − 该订单已占用量, 0)` → 分仓+SKU 层 `max(Σ 还需满足量 − 当前可用库存, 0)` → 分仓层 Σ（不二次截零）；可用库存只在分仓+SKU 层减一次，禁止摊到订单层；禁止先汇总总量再算 |
| 4 | **差额类**：库存差额（净额）= 订单扣减后可供库存 − 目标库存量；汇总直接相减、允许正负抵消；需说明结构时再补「高于目标量 / 低于目标量 / 低于目标 SKU 数」；补货用的「低于目标量」另算 |
| 5 | **去重计数类**（SKU 个数、缺货 SKU 数、大日期 SKU 数）：COUNT DISTINCT，全国/区域按 SKU 去重，严禁各分仓相加 |
| 6 | **平均货龄**：Σ(数量 × 货龄) ÷ Σ数量，加权，禁止简单平均 |
| 12 | **库存结构符合率**：只在目标层算一次（1 − Σdᵢ ÷ 2），**不可上卷**；跨分仓/品类必须用同一 SKU 集合重算，禁止对各层符合率取平均或把 Σd 相加 |
| 7 | **风险库存量**：大日期与滞库风险同一批次重叠时只计一次 |
| 8 | **计划版本一致性**：先按 分仓 + 目标月份 + 版本 + SKU 去重取唯一版本，再汇总；不能按 SKU 混用版本或来源 |
| 9 | **在途不重复抵扣**：在途用于库存水位、展望周转与补货风险判断，不在四个计划公式中重复抵扣 |
| 10 | 「全部分仓」= 用户权限范围内的全部分仓，不等于系统全部分仓 |
| 11 | **缺数按 0 与汇总口径**：明细缺数按 0 显示；汇总逐列求和（有值加、0 或无数不加）；比率 / 天数先汇总分子分母，分母为 0 或无数显示「—」；不因个别行缺数把整行或整个品类置空；两个输入都缺的行不参与、单列；整个分仓全量缺失判数据异常 |

## 八、数据形态与时间能力

| 数据形态 | 能否回答 | 说明 |
|---|---|---|
| 当前快照（库存、订单、在途、货龄） | 只能回答当前 | 无历史快照时不能回答月度趋势、同比环比、过去某日库存 |
| 历史窗口汇总（近 30 日动销 / 出库） | 回答该窗口 | 其他窗口无数据时不外推 |
| 事后履约（满足率） | 只能回答本月已发货订单 | 不能回答当前未完成订单，也不能用当前缺货倒推满足率 |
| 计划结果（四个计划） | 回答选定版本与目标月份 | 不能按 SKU 跨版本取值 |
| 推演结果（未来 7/14 日预计超龄） | P1 支持 7 日与 14 日窗口 | 必须标注窗口、是否扣减预计消耗、是否排除当前已超龄；30 日窗口属 P2 |

## 九、支持与不支持问题（能力边界）

| 指标 | 支持问题 | 不支持问题 |
|---|---|---|
| 当前分仓库存 / 可用库存 / 现库存 | 当前值、排行、按对象拆解 | 无历史快照时的月度趋势、过去某日库存 |
| 目标库存 / 安全库存 / 库存差额 | 目标值、目标计算依据（补货周期、基准出货计划与基准月份、日均出货计划、目标版本）、库存差额 | 无历史目标版本时的目标变化趋势；未配置时声称存在精确目标 |
| 库存差额 | 高于目标、低于目标、差额排行 | 把差额直接解释为订单缺货或补货量 |
| 回顾 / 展望周转天数 | 可消化天数、周转偏高对象、目标周转对比 | 用周转天数回答动销量排行；对下级天数取平均 |
| 近 30 日动销 / 动销量 | 动销量、日均动销、动销最慢排行 | 无数据时的 60/90 日趋势；用周转天数替代动销量排序 |
| 货龄结构 / 60 天以上 | 四段结构、60 天以上与 91 天及以上数量、SKU 数、占比、批次明细 | 无历史批次快照时的货龄趋势；把预计超龄当当前货龄 |
| 未来 7/14 日预计超龄 | 新增超龄 SKU、批次、预计超龄量 | 与当前已超龄相加；无推演结果时编造；30 日窗口 |
| 当前订单量 / 备单量 / 缺货量 | 缺货量、缺货 SKU、缺货订单、缺货排行 | 无历史订单快照时的趋势；用低于目标库存替代缺货 |
| 建议补货量 | 建议量构成（缺货量、库存差额、调拨中）、补货 SKU、紧急补货 | 无目标库存或在途数据时给精确结果；把建议量当正式订单；承诺到货时间 |
| 调拨在途 | 已下单未发货、已发货未入库、补货建议 | 把在途当现库存；对已取消或已入库调拨重复计算 |
| 四个计划 / 补货计划 | 月初/滚动版本、BI/人工来源、计划明细、导入结果、增长率解释 | 按 SKU 任意混用版本；直接发布正式计划；把增长率说成已验证预测 |
| 订单满足率 | 本月已发货订单满足率、数量满足率、低满足对象 | 用当前未发货订单推算满足率；把当前缺货当满足率 |
| 滞库风险 | 风险对象、主要证据、排行 | 只按库存高或只按周转天数单一判断；无动销/货龄数据时给确定风险级别 |
| 客户库存信号 | 提报范围、客户、区域、信号类型、与分仓库存冲突 | 把提报当全量实时库存；对未覆盖客户外推；替代分仓口径 |
| 上游基地可供 | 基地库存、基地在途、未来 7 日排产、承接冲突 | 把排产当已承诺到货；把基地库存直接等同某分仓可得；承诺到货时间 |
| 补货确认与去 DMS | 建议量与实际量差异、草稿与提交备份状态、DMS 单号回写状态、为什么不能自动下单 | 在 Agent 内创建或提交 DMS 正式订单；复制 DMS 库存/车型/交期校验；自动提交；声称可代为保存或提交 |

## 十、业务口语与指标意图消歧

### 10.1 动销、周转与销量

| 用户说法 | 默认理解 | 主排序指标 | 禁止行为 |
|---|---|---|---|
| 近 30 日周转最慢 | 默认理解为近 30 日动销慢；用户明确说「周转天数」时例外 | 近 30 日动销量或日均动销升序 | 默认按周转天数排序 |
| 动销量最慢 / 销量最少 / 出库最少 | 近 30 日实际动销量、销量或出库量最低 | 对应数量口径升序 | 用周转天数替代 |
| 周转天数最高 / 能卖多少天 / 可消化多少天 | 库存可消化周期最长 | 周转天数降序 | 回答成动销量最少或销量 |

用户只说「周转慢、转得慢」时，默认按近 30 日动销慢理解，并在回答中说明本次排序口径；问题不足以判断时，允许追问「您是要看近 30 日动销量，还是库存可消化周转天数」。

### 10.2 缺货、补货与风险

| 用户说法 | 默认理解 | 主指标 | 必须避免 |
|---|---|---|---|
| 缺货最多 | 当前订单缺货最高 | 缺货量 | 不用低于目标库存替代 |
| 补货最多 | 补货建议量最高 | 建议补货量 | 不用当前缺货量替代 |
| 库存风险最大 | 综合风险判断 | 库存、目标、动销、货龄、订单、补货、上游可供 | 不按单一指标直接下结论 |
| 库存不够 | 需先区分订单缺口与库存差额 | 缺货量与库存差额分别判断 | 不直接等于建议补货量 |
| 为什么库存高还要补货 | 订单或目标补货逻辑 | 订单扣减后可供库存、库存差额、调拨中 | 不只看物理现库存 |

### 10.3 计划与版本

| 用户说法 | 默认理解 | 必须避免 |
|---|---|---|
| 本月计划 / 下月计划 | 按分仓 + 目标月份取四个计划 | 把预览值当正式计划 |
| 最新计划 | 月初版本优先于滚动版本，人工优先于 BI | 按 SKU 混用版本或来源 |
| 计划为什么变了 | 解释增长率、参考实际、历史出货、补货周期、库存等输入 | 把增长率说成已验证预测准确结论 |

### 10.4 排序前的范围确认

未指定范围时使用当前权限范围内的全部分仓。未指定时间时：当前库存、当前订单、在途、缺货、补货使用最新有效快照；动销使用最近 30 日窗口；满足率使用本月已发货订单；计划使用当前生效版本与目标月份；预计超龄使用用户指定的 7 日或 14 日窗口，未指定时不擅自扩展窗口。

## 十二、同义词与口语映射

| 业务口语 | 对应标准指标 | 处理 |
|---|---|---|
| 库存量 / 现库存 / 库存水位 | 需区分现库存、当前可用库存、订单扣减后可供库存 | 先判断用户要看物理水位还是可用于订单的库存 |
| 安全库存 | 目标库存（业务常混用） | 按目标库存口径解释，说明安全库存周转天数 = 补货周期 + 3 天 |
| 含在途库存 / 已调拨含在途 | 当前可用库存 + 在途 | 必须标明口径含在途，不与现库存混称 |
| 缺货 / 缺货量 / 备单缺货 | 缺货量 = max(0, Σ 订单还需满足量 − 当前可用库存量)，先订单层后分仓+SKU 层 | 不用「订单量 − 库存」近似；可用库存不摊到订单层 |
| 紧急补货 | 存在缺货且当前库存低于目标库存的 SKU 建议补货量之和 | 与建议补货量区分 |
| 转得慢 / 消化慢 | 近 30 日动销偏慢 | 不用周转天数替代排序 |
| 大日期 / 超龄 | 分仓货龄 ≥91 天（超过 90 天）；基地为 ≥61 天（超过 60 天） | 必须区分平台口径 |
| 91 天及以上 / 60 天以上 | 分别对应大日期阈值与风险区间 | 60 天以上含 61-90 天与 91 天及以上两段 |
| 订单满足率 | 本月已发货订单满足率（订单张数口径） | 数量满足率、当前备单满足率另行标注 |
| 增长系数 | 分仓整体增长率 | 是增长率不是倍数，倍数为 1 + 增长率 |
| 分仓计划 | 本月/次月出货计划与本月/次月调拨计划 | 由大数据计算，Agent 只展示、解释、承接人工确认 |

| 补货确认与提交备份 | 看板留痕数据域（Agent 只读） | 建议补货量、实际补货量、草稿、提交备份、DMS 单号关联 | 分仓、客户、提货点、SKU、提交批次 | 业务在看板调整，必须记录原因；Agent 只读该结果 |
| 运营观察 | 运营数据域 | 仓储费、运输费、交付及时率、准交率、日均库存 | 分仓、品类 | 12 小时或每日；**不参与补货与计划计算** |

## 十六、口径取值规则（本次业务确认，全场景统一）

> 本节是全场景统一口径。与第一节至第六节的指标定义冲突时，**以本节为准**；数据说明与固化规则包冲突时以固化规则包为准并标注差异。

| 指标 | 口径 | 说明 |
|---|---|---|
| 现库存 | 分仓仓库物理库存水位 | 仅用于展示物理水位 |
| **当前可用库存**（看板「当前库存」） | 可用于发货与订单满足的库存 | **不含在途**；看板库存水位主值 |
| 在途量 | 已下单未发货量 / 已发货未入库量 | **两个数分开显示**，禁止合并 |
| **订单扣减后可供库存** | 当前可用库存 − 备单中剩余未占用量（Σ 订单层还需满足量） | 可为负数，用于解释缺货原因 |
| 目标库存（安全库存） | 安全库存周转天数 × 日均出货计划；安全库存周转天数 = 已生效补货周期 + 3 天备货期；日均出货计划 = 基准出货计划 ÷ 基准月自然日数（1–20 日本月计划、21 日起次月计划；导入版优先） | 补货周期按分仓配置，未配置默认 7 天 |
| **库存差额（净额，主口径）** | 订单扣减后可供库存 − 目标库存量；正数高于目标、负数低于目标 | **基准是订单扣减后可供库存，不是物理现库存**；汇总直接相减、允许正负抵消 |
| **低于目标量（补货用）** | max(0, 目标库存量 − 订单扣减后可供库存量) | 由净额推导，仅用于建议补货量 |
| **缺货量**（当前订单缺货） | 三层：①订单层 max(需求量 − 该订单已占用量, 0)；②分仓+SKU 层 max(Σ − 当前可用库存量, 0)；③分仓层 Σ（不二次截零） | 统一按正数；可用库存只减一次；禁止用「订单量 − 库存」近似 |
| 调拨中 | 已下单未发货量 + 已发货未入库量（仅仍会到达分仓的有效调拨） | 同一批供给只能计入一次；不含已取消、已入库、失效调拨 |
| **建议补货量** | max(0, max(缺货量, 低于目标量) − 调拨中) | 订单缺口先独立计算，调拨中只在最终建议量统一扣减 |
| 紧急补货量 | 同时满足「存在缺货」且「当前库存低于目标库存」的 SKU 建议补货量之和 | 与建议补货量区分 |
| 实际补货量 | 业务确认后的数量，可低于/等于/高于建议量 | 低于建议量必须填原因；不覆盖系统建议量 |
| 回顾周转天数 | 当前可用库存 ÷ 近 30 日日均出库量；日均出库量 = 近 30 日实际出库量 ÷ 30 | 分母为 0 显示「—」 |
| 展望周转天数 | (当前可用库存 + 有效在途) ÷ 展望 30 日日均出货量 | 必须标明含在途 |
| 展望 30 日日均出货量 | [本月剩余计划出货量 + 次月日均出货量 × (30 − 本月剩余自然日数)] ÷ 30 | 本月剩余计划出货量 = max(本月出货计划 − 本月已发货量, 0) |
| 平均货龄 | Σ(批次数量 × 批次货龄) ÷ Σ批次数量 | 加权；以大数据标准库龄结果为准 |
| 货龄分段 | 0-30 正常 / 31-60 关注 / 61-90 重点消化 / 91 天及以上大日期重点 | **分仓阈值**，边界日不得重复计入 |
| 大日期 | 分仓货龄 **≥91 天（超过 90 天）** | **基地为 ≥61 天（超过 60 天），不得混用**；不做效期比例推算（保质期统一 12 个月） |
| 健康库存占比 | 健康库存量 ÷ 当前可用库存量；健康库存量 = max(当前可用库存量 − 风险库存量, 0) | 风险库存量 = 大日期 + 滞库风险，**同一批次重叠只计一次**；库存为 0 时显示「无库存 / —」 |
| 库存结构符合率 | 1 − Σdᵢ ÷ 2，dᵢ = ABS(库存ᵢ ÷ 总库存 − 日均发货ᵢ ÷ 总日均发货)；只纳入库存 ≠ 0 且 日均发货 ≠ 0 的 SKU | 不可上卷；无纳入 SKU 显示「—」；不含缺货与滞销 |
| 订单满足率（主 KPI） | 本月已发货订单量 ÷ 本月有效订单总量，**订单张数口径** | 与看板一致；数量满足率（已发货量 ÷ 有效订单需求量）作辅助，不得替换主 KPI |
| 当前备单满足率 | 已备量 ÷ 当前备单量 | 与上面的满足率口径不同，必须分别标注 |
| 分仓整体增长率 | 目标环比增长率 × 40% + 历史同期增长率 × 40% + 近 3 个月平均增长率 × 20% | 是增长率不是倍数，倍数为 1 + 增长率；按分仓辐射客户月度目标金额总额计算，不按 SKU 拆金额目标；目标缺失时标记数据不完整 |

## 十七、关键消歧对照（高频错答防线）

| 容易混淆 | 正确处理 |
|---|---|
| 现库存 vs 当前可用库存 vs 订单扣减后可供库存 | 现库存只反映物理水位；缺货量与库存差额**必须**用订单扣减后可供库存计算 |
| 缺货量 vs 库存差额 | 缺货量看订单交付风险；库存差额看距离目标水位的差距；两者都不是建议补货量 |
| 缺货量 vs 建议补货量 | 建议补货量 = max(0, max(缺货量, 低于目标量) − 调拨中)，还要看目标与在途 |
| 库存高 vs 不需要补货 | 订单扣减后可供库存可能仍低于目标，备单中订单可能尚未占用 |
| 动销慢 vs 周转天数高 | 动销看近 30 日动销量与数量排序；周转天数看覆盖周期。两者不能互相替代排序 |
| 在途 vs 现库存 | 在途不计入当前可用库存；已下单未发货与已发货未入库必须分开显示 |
| 60 天以上 vs 91 天及以上 | 分仓大日期是 91 天及以上（超过 90 天）；61-90 天是重点消化区间。**不得与基地 60 天口径混用** |
| 当前 91 天及以上 vs 未来 7/14 日预计超龄 | 前者是存量风险，后者是窗口内新增风险，两者不能相加 |
| 低于目标 vs 缺货 | 低于目标是水位偏差；交付风险看缺货量与订单扣减后可供库存 |
| 订单满足率 vs 当前缺货 | 满足率是本月已发货订单的事后口径；当前交付风险看缺货量，两者不能互相倒推 |
| 月初版 vs 滚动版 vs 人工 vs BI | 月初优先滚动；人工优先 BI；按分仓 + 目标月份整体选定，不按 SKU 混用 |
| 分仓级建议 vs 客户级订单 | 补货建议是分仓—SKU 级；下单对象是客户、提货点级，映射关系由业务确认 |
| 客户库存信号 vs 分仓库存 | 客户信号是辅助输入，不能替代分仓库存、订单与目标口径 |
| 状态量 vs 流量量 | 状态量（当前未备单完成订单、当前备单中缺货量、当前可用库存、在途、货龄）**不受时间范围限制**，不得加日期区间；流量量按**订单归属月份**统计，必须标注归属月份；两者不得相加、互换或互相倒推 |
