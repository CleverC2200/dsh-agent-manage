# 分仓指标口径与问数路由 — 规则与阈值

## 1. 口径解释模板

```text
直接结论：{指标}用于判断{业务含义}。
计算依据：{公式或判断逻辑，用业务语言}
数据依据：使用{库存/订单/在途/动销/货龄/计划}数据，时间范围为{范围}，计划版本为{版本与来源}（如涉及）。
口径限制：它能说明{能说明的内容}，不能替代{相近但不同的指标}。
错误示例：错误：{常见错法}；正确：{正确做法}。
允许引导：{同一指标明细}、{相关支持指标}。
```

口径解释类必须给出「不能说明什么」与一个错误示例，避免用户把相近指标互相替代。

## 2. 一致性对照（回答「两个数为什么不一致」）

按以下顺序逐项排除，定位差异来源；不确定时说明候选原因并建议人工确认，不重新估算。

| 差异来源 | 典型表现 | 核对方式 |
|---|---|---|
| 口径不同 | 现库存 vs 当前可用库存 vs 订单扣减后可供库存 | 确认是否扣除备单中剩余未占用量、是否含在途 |
| 基准不同 | 缺货量 vs 库存差额 | 缺货量以订单需求为基准，库存差额以目标库存为基准 |
| 时间不同 | 库存、订单、在途、库龄、动销、计划各自时间不同 | 分别标注各源时间，以最接近分析时点为主 |
| 维度不同 | 分仓 vs 区域 vs 品类 vs SKU vs 客户 | 确认聚合层级与去重方式 |
| 汇总方式不同 | 比率或天数是否被平均、SKU 个数是否被相加 | 比率与天数须分子分母分别汇总；SKU 个数按 SKU 去重 |
| 版本或来源不同 | 月初版 vs 滚动版、人工 vs BI | 按分仓 + 目标月份整体选定，确认是否为预览值 |
| 范围不同 | 全部分仓 vs 权限范围内分仓 | 「全部分仓」= 授权分仓集合 |
| 状态不同 | 是否剔除作废、无效、短拨订单；调拨是否已取消或已入库 | 确认订单状态与调拨有效性口径 |

## 3. 高频口径速查

| 指标 | 标准口径（分仓） |
|---|---|
| 当前可用库存 | 可用于发货与订单满足的库存，不含在途 |
| 在途量 | 已下单未发货量 / 已发货未入库量，**分开显示** |
| 订单扣减后可供库存 | 当前可用库存 − 备单中剩余未占用量（可为负数） |
| 缺货量 | max(0, 备单中剩余未占用量 − 当前可用库存量)，先按分仓+SKU 算再汇总 |
| 目标库存 | （已生效补货周期 + 3 天）× 日均出货计划；日均出货计划 = 基准出货计划 ÷ 基准月自然日数（1–20 日本月计划、21 日起次月计划；导入版优先）；未配置周期默认 7 天 |
| 库存差额（净额，主口径） | 订单扣减后可供库存 − 目标库存量；正数高于目标、负数低于目标；汇总直接相减、允许正负抵消 |
| 低于目标量（补货用） | max(0, 目标库存量 − 订单扣减后可供库存量) |
| 调拨中 | 已下单未发货量 + 已发货未入库量 |
| 建议补货量 | max(0, max(缺货量, 低于目标量) − 调拨中) |
| 紧急补货量 | 存在缺货且当前库存低于目标库存的 SKU 建议补货量之和 |
| 回顾周转天数 | 当前可用库存 ÷ (近 30 日实际出库量 ÷ 30) |
| 展望周转天数 | (当前可用库存 + 有效在途) ÷ 展望 30 日日均出货量 |
| 平均货龄 | Σ(批次数量 × 批次货龄) ÷ Σ批次数量 |
| 大日期 | 货龄 91 天及以上（分仓口径；基地为 61 天及以上） |
| 健康库存占比 | 健康库存量 ÷ 当前可用库存量；重叠风险批次只计一次 |
| 库存结构符合率 | 1 − Σdᵢ ÷ 2；dᵢ = ABS(单品库存 ÷ 总库存 − 单品日均发货 ÷ 总日均发货)；只纳入库存 ≠ 0 且 日均发货 ≠ 0 的 SKU |
| 订单满足率（主 KPI） | 本月已发货订单量 ÷ 本月有效订单总量（订单张数口径） |
| 数量满足率（辅助） | 本月已发货量 ÷ 本月有效订单需求量 |
| 分仓整体增长率 | 目标环比 × 40% + 历史同期 × 40% + 近 3 个月平均 × 20% |

## 4. 多义说法与必须做的消歧

| 用户说法 | 处理 |
|---|---|
| 库存量 / 库存水位 | 先确认是现库存、当前可用库存，还是含在途口径 |
| 转得慢 / 消化慢 | 按近 30 日动销偏慢理解，并在回答中说明排序口径 |
| 缺货 / 库存不够 | 先区分缺货量与库存差额 |
| 安全库存 | 按目标库存口径解释，并说明安全库存周转天数 = 补货周期 + 3 天 |
| 大日期 | 明确本次为分仓 91 天及以上口径，不混用基地 61 天及以上 |
| 周转天数 | 先确认回顾口径还是展望口径；展望必须标明含在途 |
| 满足率 | 先确认是本月已发货订单满足率、数量满足率还是当前备单满足率 |
| 最新计划 | 按月初优先滚动、人工优先 BI 解释，并说明是否为预览 |

问题不足以判断时，允许一次追问（如「您是要看近 30 日动销量，还是库存可消化周转天数？」），并说明为什么需要。

## 5. 降级规则（三段式）

当前不支持的问题按三段回答：① 说明当前不支持什么；② 说明原因（数据形态、时间范围、权限范围、数据缺失或系统能力限制）；③ 给可替代查看的指标或明细。

| 不支持场景 | 标准说明 | 可替代查看 |
|---|---|---|
| 无历史快照问趋势 | 当前只有最新快照，没有对应历史快照 | 当前快照、近 30 日动销或已有历史结果 |
| 无推演结果问未来超龄 | 当前未生成对应 7 日 / 14 日推演结果 | 当前 91 天及以上库存与当前货龄批次 |
| 无生效计划问目标库存 | 缺少生效补货周期或计划结果 | 当前可用库存、缺货量、调拨中与配置状态 |
| 无客户覆盖问客户库存 | 客户库存信号未覆盖该客户或分仓 | 已覆盖客户信号与分仓订单数据 |
| 无权限问其他分仓 | 当前账号没有该分仓数据权限 | 当前权限范围内分仓 |
| 问自动创建正式动作 | 右侧问答只提供分析与建议，不执行正式动作 | 建议明细，在工作台由有权限人员确认提交 |
| 超出支持维度组合 | 当前结果不支持该指标与维度组合 | 改用支持的分仓、品类、物料组或 SKU 维度 |
| 数据刷新失败或过期 | 当前结果不是最新 | 最近有效快照与数据时间，刷新后重试 |

禁止用相近指标伪造替代：没有缺货量时不能用库存差额回答缺货；没有近 30 日动销时不能用周转天数回答动销最慢；没有客户信号时不能用分仓库存推断客户库存；没有历史快照时不能用当前结果拼接趋势。

## 6. 引导生成规则

- 每次 2-4 个，只能取自 **branch-policy 指标口径** 第十一节白名单
- 与当前指标同族，且在当前权限与能力范围内
- 禁止引导：无历史快照的趋势、超出支持维度的组合、P1 未实现能力（待办 / 事件 / 反馈闭环 / 责任与升级 / 30 日推演 / 大日期专项台账）、在 Agent 内自动创建补货单、调拨单、DMS 订单或事件

## 7. 简单问数的最短路径

只问一个数字时：取语义 → 取数 → 四段式回答（结论 / 数据依据 / 口径限制 / 引导），**不启动完整 Skill 流程**、不额外给原因线索与建议清单。涉及权限对象时先过滤权限再取数。

## 8. 数据完整性校验

必备字段：指标名与对象、可用库存或订单口径、数据截止时间、权限范围。缺字段时只输出可判断部分并说明缺失项；可用库存或占用量缺失按 0 参与并标注。

## 9. P2 承接

待办 / 事件与历史反馈闭环、责任判定与协同角色推荐、升级审批、30 日超龄推演、大日期专项台账与锁定、DMS 正式订单状态自动回传闭环。
