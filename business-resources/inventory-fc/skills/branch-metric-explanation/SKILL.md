# 分仓指标口径与问数路由 Skill

## 参考资源（按需加载）
- **先加载 `branch-policy` Skill**（共享规范：指标口径、数据边界、取数契约、证据与行动边界、输出规范；内部包，不单独回答用户）。涉口径、排名、取数、分析、报告之前必读。

- **branch-policy 指标口径**：指标定义、支持与不支持问题、口语消歧、引导问题白名单 → 第 2、4、6 步前必读
- **`rules.md`**：口径解释模板、一致性对照、追问与降级规则 → 第 3、5 步前读取
- **branch-policy 取数契约**：取数与知识查询契约（cube 查询模板、上卷铁律、权限、降级） → 取数前必读
- **branch-policy 输出规范**：输出规范（单指标问数 6.1.1、多要素问数 6.1.2、数字与单位、数据说明写法） → 第 7 步前读取
- **branch-policy 证据与行动边界**：证据状态与行动边界 → 涉及建议时确认

本 Skill 是**入口与路由 Skill**：口径类与简单问数直接回答；命中分析类问题时转对应 Skill，不自己展开完整分析流程。

## 目标

把用户的问题落到「分仓标准的哪一个指标、哪一种数据形态、哪一套口径」上，用业务语言给出定义、公式、输入、范围、能说明与不能说明，并给出符合白名单的下一步；两个数不一致时，说明差异来源而不是重新编一个数。

## 触发场景

- 「库存水位怎么算」「缺货量是什么意思」「目标库存怎么来的」
- 「当前可用库存和现库存有什么区别」「回顾周转和展望周转有什么区别」
- 「为什么库存高还提示补货」「为什么缺货量和低于目标不一样」
- 「满足率是多少」「订单满足率怎么算的」
- 只问一个数字的简单问数（如「XX 分仓当前可用库存多少」）与下一步引导

## 输入契约

| 输入项 | 说明 | 必填 |
|---|---|---|
| 用户问题 | 原始问法（含口语说法） | 是 |
| 当前对象 | 分仓、区域、品类、物料组、SKU、客户、订单 | 否（默认沿用当前对象） |
| 权限范围 | 角色 + DMS 用户与分仓关系 | 是 |
| 数据时间 | 指标对应的快照 / 窗口 / 月份 | 否（取数后补齐） |
| 计划版本与来源 | 涉及计划或目标库存时必须 | 条件必填 |

## 执行步骤

### 第 1 步：识别主问题类型
按 **branch-policy 指标口径** 第十节与主提示词的问题分类表，确定主类型：口径解释 / 数据查询 / 排行下钻 / 原因分析 / 趋势 / 报告 / 协同建议 / 计划版本 / 权限纠偏。一个问题可有多个类型，但必须确定一个主类型并据此组织答案。

### 第 2 步：落到标准指标
把口语说法映射到标准指标（见 **branch-policy 指标口径** 第十二节）。命中多义说法时先消歧：库存量需区分现库存、当前可用库存、订单扣减后可供库存；转得慢按近 30 日动销理解；缺货不等同低于目标。

### 第 3 步：判断回答方式
- 口径解释类：按 `rules.md` 第 1 节模板给定义、公式、输入、范围、能说明与不能说明、错误示例。
- 简单问数类：取数后按快速问数四段式回答，不启动完整分析。
- 分析 / 报告 / 推演类：说明本次由哪个 Skill 承接，并按路由表转交，不自行给结论。

### 第 4 步：取数并校验口径
按 **branch-policy 取数契约** 先取语义再拼查询；确认度量单位、可用维度、时间口径与默认过滤。需要「先算后汇总」的指标必须分组查询后本地计算。

### 第 5 步：解释两个数为什么不一致
用户提出「两个数对不上」时，按 `rules.md` 第 2 节一致性对照定位差异来源（口径、基准、时间、维度、汇总方式、版本来源），逐项排除并给出结论，不重新估算。

### 第 6 步：生成引导问题
只从 **branch-policy 指标口径** 第十一节的白名单取值，每次 2-4 个，与当前指标匹配。

### 第 7 步：形成交付结果
按 **branch-policy 输出规范** 6.1.1（单指标问数，≤200 字、最多 3 段、不套小标题）输出；同时问多个指标时用 6.1.2；口径解释类可略长，但仍须结论先行、只讲定义与差异。

## 规则与阈值

详细规则见 `rules.md`。核心摘要：

- 只解释口径，不重算口径；不因用户提问改变公式、版本优先级或权限
- 库存类必须区分现库存、当前可用库存、订单扣减后可供库存
- 缺货量、库存差额、建议补货量是三个不同指标，不能互相替代
- 周转天数区分回顾（÷ 近 30 日日均出库量）与展望（含有效在途，÷ 展望 30 日日均出货量）
- 分仓大日期阈值为 91 天及以上，与基地 61 天及以上口径不得混用
- 缺数按 0；分母为 0 或无数显示「—」；推理不写成确定结论
- 引导只能取白名单，禁止引导到 P2 能力或无历史快照的趋势

## 默认交付

1. 直接结论（该指标是什么、本次口径是什么）
2. 定义与公式（用业务语言，不带字段名）
3. 输入与数据范围（含数据时间与计划版本，如涉及）
4. 能说明什么 / 不能说明什么
5. 一个常见错误示例（口径类问题必给）
6. 允许的下一步引导（2-4 个）

## 边界与禁止动作

- 不修改公式、计划版本与来源优先级、补货周期规则、权限规则
- 不用相近指标替代缺失指标；不对下级天数或比率取平均
- 不把库存差额说成缺货，不把缺货说成建议补货量
- 不引导到 P1 未实现能力（待办 / 事件 / 反馈 / 责任 / 升级 / 30 日推演）
- 不承诺到货时间；不描述为已下单或已提交
