# 分仓库存水位与偏差 — 规则与阈值

## 1. 计算公式

| 指标 | 公式 | 说明 |
|---|---|---|
| 现库存 | 分仓仓库物理库存 | **仅用于展示物理水位，不作为缺货与库存差额的计算基准** |
| 当前可用库存 | 分仓可用于发货与订单满足的库存 | 不含在途；看板库存水位主值 |
| 在途量 | 已下单未发货量 / 已发货未入库量 | 两个数分别展示，禁止合并 |
| 订单扣减后可供库存 | 当前可用库存 − 备单中剩余未占用量 | 可为负数，负数用于解释缺货原因 |
| 备单中剩余未占用量 | max(备单中订单需求量 − 备单中已占用量, 0) | 已扣减部分不得重复扣减 |
| 安全库存周转天数 | 已生效补货周期 + 3 天备货期 | 周期按分仓配置，未配置默认 7 天 |
| 日均出货计划 | 基准出货计划 ÷ 基准月自然日数；基准按计算日切换：1–20 日用本月出货计划、21 日及以后用次月出货计划；出货计划导入版优先，无导入用系统版 | 基准月份与自然日数必须与所选计划一致 |
| 目标库存量 | 安全库存周转天数 × 日均出货计划 | 计划缺失或日均量为 0 时不给精确目标 |
| 库存差额（净额，主口径） | 订单扣减后可供库存 − 目标库存量；正数高于目标、负数低于目标；汇总直接相减、允许正负抵消 |
| 低于目标量（补货用） | max(0, 目标库存量 − 订单扣减后可供库存量) | **基准是订单扣减后可供库存** |
| 近 30 日日均出库量 | 近 30 日实际出库量 ÷ 30 | 回顾周转分母 |
| 回顾周转天数 | 当前可用库存量 ÷ 近 30 日日均出库量 | 分母为 0 显示「—」 |
| 本月剩余计划出货量 | max(本月出货计划 − 本月已发货量, 0) | 展望周转输入 |
| 次月日均出货量 | 次月出货计划 ÷ 次月自然日数 | 展望周转输入 |
| 展望 30 日日均出货量 | [本月剩余计划出货量 + 次月日均出货量 × (30 − 本月剩余自然日数)] ÷ 30 | 未来需求口径 |
| 展望周转天数 | (当前可用库存量 + 有效在途量) ÷ 展望 30 日日均出货量 | **必须标明含在途** |
| 健康库存量 | max(当前可用库存量 − 风险库存量, 0) | 风险库存量重叠批次只计一次 |
| 风险库存量 | 大日期库存量 + 滞库风险库存量（重叠只计一次） | 以大数据标准库龄结果为准 |
| 健康库存占比 | 健康库存量 ÷ 当前可用库存量 | 库存为 0 时显示「无库存 / —」 |
| 库存结构符合率 | 纳入范围：当前可用库存 ≠ 0 且 日均发货量 ≠ 0 的 SKU（库存为 0 或发货为 0 的行不计入分子、也不计入分母）；总库存 = Σ 纳入 SKU 库存，总日均发货 = Σ 纳入 SKU 日均发货；单品偏差 dᵢ = ABS(库存ᵢ ÷ 总库存 − 日均发货ᵢ ÷ 总日均发货)；**库存结构符合率 = 1 − Σdᵢ ÷ 2** | 单品层只算 dᵢ（保留 4 位），符合率只在目标层算一次（保留 1 位）；**不可上卷**：跨分仓/品类必须用同一 SKU 集合重算，不能对各层符合率取平均、也不能把各层 Σd 相加；无纳入 SKU 时显示「—」；解释时保留 dᵢ 符号（库存占比 − 发货占比），正=备货偏多、负=备货偏少 |

禁止口径：用现库存替代订单扣减后可供库存计算库存差额；把已下单未发货与已发货未入库合并为一个在途量；对下级周转天数取平均。

## 2. 目标库存与补货周期的特殊处理

| 情况 | 处理 |
|---|---|
| 分仓已生效补货周期 | 按周期 + 3 天计算并标注周期值与来源 |
| 未配置或已失效 | 按系统默认 7 天计算，标注「按默认 7 天」 |
| 前端临时修改周期 | 只影响当前预览，标注为预览，不影响定时预警 |
| 计划结果缺失或人工计划不完整 | 不给精确目标库存与建议补货量，说明缺失范围 |
| 基准出货计划为 0 | 不计算目标库存，说明缺少有效计划 |
| 计划为人工提报 | 标注目标月份、版本（月初 / 滚动）与来源（人工） |

## 3. 风险分层（受控配置默认值，待业务确认）

| 层级 | 参考条件（分仓） | 标记 |
|---|---|---|
| 正常 | 订单扣减后可供库存覆盖目标水位；货龄 30 天以内；周转与目标接近 | 绿 |
| 关注 | 库存差额明显；货龄 60-90 天；满足率低于业务下限；在途不足以覆盖缺口 | 橙 |
| 高风险 | 存在缺货且紧急补货；货龄 91 天及以上；滞库风险且动销偏慢 | 红 |

业务维护规则包中的紧急补货处理时限、大日期关注阈值、滞库阈值、满足率下限属受控参数；未维护时**只做方向性提示**，不自行编造阈值。

排序规则：风险等级 → 库存差额 → 周转天数 → 货龄。

## 4. 重点对象筛选

排序：风险等级 → 库存差额 → 周转天数。必纳入：用户点名对象、低于目标最多的对象、周转最高对象、同时存在缺货或大日期的对象。只问一个对象时直接回答，不生成排行榜。

## 5. 高低目标的联动判断

| 水位状态 | 需同时核对 | 结论方向 |
|---|---|---|
| 低于目标 | 缺货量、调拨中、基地可供 | 低于目标只说明水位偏差；是否存在交付风险看缺货量 |
| 高于目标 | 近 30 日动销、货龄结构、计划消化能力、客户信号 | 高于目标不等于滞库，需综合判断 |
| 高于目标但仍有缺货 | 备单中剩余未占用量、批次与规格、提货点需求 | 可能是结构性错配，建议核查规格 / 批次 / 客户要求 |
| 目标缺失 | 补货周期、计划结果 | 只输出可判断部分，不给精确目标 |

## 6. 原因线索（最多 5 条，标注证据状态）

| 方向 | 子原因 | 触发条件 | 证据状态 |
|---|---|---|---|
| 需求端 | 出货超出计划 | 本月已发货量 > 本月出货计划 | 有支撑未验证 |
| 需求端 | 计划偏低或未及时确认 | 人工计划不完整或计划量相比历史明显下降 | 推测（有计划数据时为有支撑未验证） |
| 供给端 | 调拨未按时到达 | 已下单未发货或已发货未入库量高于缺口量 | 已验证（有在途数据时） |
| 供给端 | 基地资源未承接 | 基地可供不足或无排产 | 有支撑未验证 |
| 库存端 | 备单占用偏高 | 备单中剩余未占用量接近或超过当前可用库存 | 已验证 |
| 库存端 | 结构错配 | 高于目标与缺货并存 | 有支撑未验证 |
| 数据端 | 补货周期或计划变更 | 周期或计划版本近期变化 | 已验证（有变更记录时） |

不做目标设置合理性的推断，不解释大数据的目标重算过程。

## 7. 建议方向（标注【待人工确认】与建议责任角色）

| 情形 | 方向建议 | 建议责任角色 |
|---|---|---|
| 低于目标且存在缺货 | 优先确认紧急补货与实际补货量 | 分仓计划员 |
| 低于目标但无缺货 | 核对调拨到货节奏与调拨中是否可覆盖 | 分仓计划员 + 基地协同人员 |
| 高于目标且动销正常 | 继续观察，不做去化动作 | 分仓运营经理 |
| 高于目标且动销偏慢、货龄偏长 | 转去化处理，控制新增补货 | 分仓运营经理 |
| 高于目标与缺货并存 | 核查规格、批次、提货点需求匹配 | 分仓计划员 + 区域计划 |
| 目标或周期缺失 | 反馈配置与计划完整性 | 平台计划员 |

建议总数 ≤5 条，短期优先；不写责任人姓名，不承诺到货时间。

## 8. 数据完整性校验

必备字段：分仓、SKU 或品类、当前可用库存、补货周期或默认说明、计划量、数据截止时间。缺字段时按指标分别处理，**不整行作废**：当前可用库存缺失按 0 参与并标注；两者都缺的行不参与、单列；其余指标照常输出。

可选字段缺失时：无出库数据 → 不给回顾周转；无在途 → 展望周转与补货判断标注未含在途；无库龄结果 → 不给健康库存占比与结构结论。

## 9. P2 承接

待办 / 事件与历史反馈闭环、责任判定与协同角色推荐、升级审批、历史水位趋势、目标库存与补货周期机制复盘。
