# GEA 插件 Cube 查询约定

首次业务取数时读本页；当前身份、环境、版本与范围仍适用的模型说明可复用。

## 发现与成员

- 使用实际注册的 `mcp__gea-gateway__inspect_cube_model` 读取说明，参数以当前 Schema 为准；检查与查询是两个独立工具，不把旧 `action: inspect` 或空 `queries` 发给查询工具。
- 读取 View 与业务说明，查询成员使用说明明确给出的完整底层 `aliasMember`。度量、维度、时间维度、分段、筛选、排序都使用该映射与实际类别；不照抄 View 成员名、不猜前缀、不按数值类型推断度量。未提供映射时说明缺口。
- 单条查询只使用一个底层模型，跨模型需求拆为独立具名查询；名称对齐按完整业务键精确匹配。
- 销售提报/计划结果使用授权说明中映射到 `data_service.agents_sales_plan_detail_mi` 的来源；来源缺失时停止该分支，不用在线计划或预测表替代。实时审批、日志和操作前版本走当前明确提供的在线只读能力；当前草稿仍用工作台证据。
- 不按模型前缀排除候选。配置模型按实际说明识别；未完整读取相关目录时不声称某能力不存在。目录无需落盘或运行 Python 才能使用。

## 请求

`query_business_data` 沿用服务端的 `action: "query"`、`response_mode: "inline_complete"`、`queries`。每项是 `{"name":"查询英文短名","query":{...}}`；字段、排序与分页放进内层 `query`。批量、行数与字节限制以实际 Schema 为准，不硬编码旧的 8 条/1000 行约定。

需要分页时显式给 `offset`、`limit` 和稳定排序，后续页保持其他条件一致。只读取回答所需范围；用户要求全量时才续至业务末页。合计使用同范围聚合度量；无数量度量时不以行数代替数量。分子分母先对齐组织、期间、快照、版本与单位，再计算比率；保留原始金额与编码精度。

## 响应与完整性

- 优先读本次结构化结果；仅有文本时选一份业务 JSON，两种表示不重复计数。直返不要求 URI、SHA 或本地文件；旧链接仅由宿主按原会话合同处理。
- 按查询 `name` 对应数据集；核执行数、`fields`、`rows`、`rowCount`、`dataStatus`、`offset`、`totalRowCount`、`hasMorePages`。有效空结果与失败、`partial` 分开处理；null 不当成零。
- `complete=true` 只表示本页完整，`hasMorePages=true` 表示还需业务续页；直返缺少旧 `complete/hasMore` 标记时不自行补写。字段矛盾或响应合同错误交由宿主拒绝，不凭 rows 推断成功。
- `totalRowCount` 是查询结果行数，不是金额、数量或去重对象数。排名前若干项不代表全量，各项占比无需凑满 100%；只有全量互斥分类才核占比合计。

## 错误、重试与时间

- 仅明确的参数校验错误允许依据真实说明修正后重试。`DATA_QUERY_MEMBER_NOT_PUBLISHED`、权限拒绝、会话失效及 `GEA_CUBE_NEW_*` 响应合同错误时停止受影响查询；不换成员、过滤条件、身份或通道继续试探。
- `AI_GATEWAY_MCP_RESULT_TOO_LARGE` 按服务端指引减列、缩小范围或分页，不原样重试、不回退 OSS；已缩小范围的答案只覆盖该范围。
- 「本月」用当前年月；未带年份的具体月份用最近一个不晚于当前月的该月，并注明年月。仅未明确年份且有效空结果时允许一次相邻年份同月消歧；明确年份、失败、拒权及响应异常不做跨年探测，其他年份结果不替代原月份。
- 普通问题通常 1–3 次调用；已足够回答就停止。必要分页不受这个建议次数限制，仍受实际预算约束。不要为凑齐明细重复取数。
- 只说明影响结论的数据缺口；只有宿主明确确认后台任务仍在运行时才承诺继续读取。
