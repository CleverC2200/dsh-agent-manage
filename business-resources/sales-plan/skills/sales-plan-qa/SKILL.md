# 销售计划业务问数

## 任务目标

按使用者所问的口径直接给出事实性答案，并标明数据来源与时间点。

- 口径正确、来源与时间点标明。
- 部分数据缺失时说明缺什么、影响哪一部分结论，其余照常回答。
- 超出使用者权限范围时说明可见范围与可执行路径。

## 所需知识与数据

**知识**：逾期口径——**未完成全流程审批，不是未提交**；异常类型口径（下市与预下市、非季节品、货龄超期、需复核、达成率极端值）；单位与概率的表达规则。

**数据**：所问指标的事实数据；提报过程数据；审批流转状态；既有健康度结论；异常判定所需的基础事实。

## 查询类型与取数口径

| 查询类型 | 数据源 | 口径要点 |
|---|---|---|
| 实际发货、同期、同比、环比 | 加工后的最终数据 | 比较双方须同范围、同期间、同口径；短周期比较用日均或等长窗口 |
| 库存与货龄 | 加工后的最终数据 | 现库存＝在库＋在途；可用／正常／临期分别合计，不合成一个数；覆盖天数与货龄是两件事，不可互换 |
| 达成、计划额、成长率 | 加工后的最终数据 | 比率用合计额重算；预估达成率＝计划额 ÷ 预算额，属计划口径、不是实际达成 |
| 政策与节令 | 规则来源与主数据 | 范围命中不等于下单可用；节令按已启用窗口判断 |
| 明细构成 | 加工后的最终数据 | 先钉住区分维度（快照、版本、批次、状态），否则同一对象被重复累加 |
| 提报比例、未提报名单、提报进度 | 提报过程数据 | 属运行态数据，最终数据中不存在 |
| 审批进度、逾期清单 | 审批流转状态 | 逾期＝未完成全流程审批，不是未提交 |
| 异常清单 | **按规则判定** | 无现成清单，按判定口径逐类生成（下市与预下市、非季节品、货龄超期、需复核、达成率极端值） |

跨类型的联合提问（例如「上月发了多少、本月提报了吗」）按各自口径分别取数，在回答里分区呈现，**不混算**。

## 输入内容

- **必需**：问题对象与指标。
- **条件必需**：时间范围与比较基准（同比、环比须明确基准）。
- **可选**：维度拆分。

使用者引用工作台内容时按工作台范围取数；未引用、由使用者点名其他组织或对象时按其指定范围取数 —— **问数不局限于当前工作台窗口**，以使用者的权限范围为硬边界。

## 工作步骤

1. **解析意图与工具可用性** —— 识别对象、指标、时间范围，判断问的是「现在」「提报过程」还是业务事实；确认所需能力可调用。能力不可用时停止受影响分支，不猜造替代名称。
2. **选源取数** —— 首次业务取数前读取本技能的 [Cube 查询约定](references/cube-query.md)，确认真实 Session 已选用可用业务资源。销售提报/计划结果取授权 Hive 销售计划来源；问实时审批或当前草稿时按当前可用的在线只读能力或工作台证据取数。**优先取聚合结果，不拉明细自己加总，不用最终结果倒推实时进度。**
3. **同口径比较** —— 确认比较双方同范围、同期间、同口径；金额与数量不混算；比率用合计额重算，不平均或相加各对象比率。
4. **输出（含出表前自校验）** —— 结论 → 关键数字（表格优先）→ 明细 → 来源行 → 下一步选项。**出表前逐项自校验**（见「呈现规范」第 3 条），对不上先修正，不修不出表。

## 呈现规范（展示层）

1. **结构与模板**：结论一句话 → 数字表格 →（必要时）分区分块 → 来源行 → 下一步选项。按题型套模板：
   - **对比类**（同比／环比／本期与基准）：给「对象｜本期｜基准期｜增减｜幅度」列；
   - **排名类**：给「名次｜对象｜数值｜占比」，按数值降序，注明排序口径；
   - **时间序列类**：按时间升序逐行；
   - **下钻类**（组织／商品明细）：逐行列出，末尾给**合计行**。
2. **数字与单位**：金额与数量按主提示词【十一】的换算与精度规则（万元／亿元、万件、占比 1 位小数）；**单位只写列名**（如「销售预算额（万元）」），表内数字不带单位后缀；同一张表内单位统一。
3. **出表前自校验（逐项过，对不上先修正）**：单位只在列名；全量且互斥明细与同范围聚合合计对齐；明细超过 6 行时直接使用聚合结果、不自行逐行求和；行数不当作业务对象去重数；仅完整互斥分类的占比合计＝100.0%（舍入 ±0.1 内），前若干名与部分覆盖不凑满 100%；对比双方同范围、同期间、同口径。**修正不了就只给能对齐的部分并说明，不带病出表。**
4. **缺失与占位**：缺失写「—」；确为 0 的写 0，不用 0 充当缺失；**不写「同上」「含于上行」这类代指**，重复值如实写出，或在表后注明归属。
5. **组织名称**：一律用组织字典中的中文名称；带「（不用）」等废弃标注的条目不作为现行名称；**按完整编码精确匹配；省区名称未匹配且上级归属已确认时，用上级中文名标注「未匹配到省区名称」；上级也未知则说明名称缺口，不按近似编码猜名**。
6. **口径并列**：多个口径（如销售组织口径与提货点口径）分行分列呈现，不相加、不互相替代；比率标明分子与分母。
7. **长清单**：超过 10 行按数值（或影响）降序截取并注明省略条数；使用者点名「列出全部／完整」时全列。
8. **来源行**：数据类写「时间点＋业务来源」（如「数据截至 2026-10-10，来源：业务系统实时数据」）；知识类写业务可读的制度或规则名称；**不写文档文件名、版本号、字段名**；来源行放在「下一步」之前。
9. **结尾**：给 2–3 个下一步选项，每条承接本轮的对象、月份或指标。

## 工具契约

数据查询使用本轮实际注册的 `mcp__gea-gateway__inspect_cube_model` 与 `mcp__gea-gateway__query_business_data`，参数按服务端 Schema，详细约定见 [Cube 查询约定](references/cube-query.md)。这两个工具不保证同时提供实时审批、草稿、健康度、知识检索或范围回执；分别检查当前实际能力，需要的分支缺失时说明缺口。

当前草稿、筛选与选择以工作台证据为准；实时审批通过对应在线只读能力读取；健康度只引用已有结论；制度与阈值使用实际获准的知识来源。数据与知识查询均只读。

安装插件、加载 Skill 或自定义 Agent 的工具白名单不授予业务身份。GEA 从真实 Session 绑定的受信任业务资源或个人 Agent 显式选择的可信 Cube 引用解析 Consumer，并重新核登录、来源启用状态及服务端权限；参数不传身份、Token、租户或路由。个人 Agent 未选择或已停用可信 Cube 时停止查询，引导在该 Agent 配置中选择已启用的销售 Cube 来源，不借用其他身份。Cube 引用只授予当前获准的只读数据能力，不附带原插件的页面动作或业务写入。

## 异常与降级

- 有效空结果、取数失败或口径不符时说明缺口，不换字段、模型、口径或通道试探。仅按查询约定处理有依据的参数更正、超限、正常续页与未明确年份的消歧；成员未发布、拒权、会话失效和响应合同错误停止受影响分支。
- 数据缺失：说明缺什么与影响范围。
- 权限外：说明可见范围与可执行路径，不说成技术故障。

## 输出规范与边界

- 只给事实，不给调整建议与审批结论。
- 需要处置动作时，说明该动作在工作台由相应角色完成。
- 非审批角色只获取事实与进度，不提供审批类判断。
- 金额与数量分别成列；比率标明分子与分母。
- 三个及以上数值时必须用表格承载。
- 结尾给 2–3 个下一步选项。

> | 口径 | 数量（万件） |
> |---|---:|
> | 上月实际发货 | 46.8 |
> | 上上月实际发货 | 49.9 |
> | 去年同期实际发货 | 45.4 |
>
> 数据截至 2026-10-01，来源：业务系统实时数据。
>
> 下一步
> - 看华南各区上月的发货明细
> - 对比华南本月计划与上月实际

> 数据截至 2026-10-01，来源：业务系统实时数据。
