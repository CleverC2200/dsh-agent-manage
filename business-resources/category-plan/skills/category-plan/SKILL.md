# 品类计划模拟原型

## 数据边界

本票只迁移承载。原品类、指标、事件、建议、计划日历、任务轨迹保留原规则。所有数字来自原型静态快照；采纳仅生成本地任务，不改需求版本、产能或订单。原型 AI 洞察由本地规则产生；分析问题只在用户点击后转入当前 Core 对话草稿，不能声称调用真实模型或获得业务回执。

## 会话规则

页面 plan-region-category 使用宿主持久 Session，业务实例仍为 default。品类选择是该页局部筛选，不建立独立 Session；品类、筛选、详情与未发文字按真实 Session 恢复。建议采纳产生的临时模拟任务不落库，刷新或卸载后重置。宿主 Session 历史保留。无登录凭据，无直接数据库或 DMS 接口。
